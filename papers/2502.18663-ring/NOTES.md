## 🗺 Образ и его точность

| Образ | Математика | Честность |
|---|---|---|
| кольцо, три хода | граф Кэли Sₙ, образующие L, R, X | буквально (L/R — поворот кольца, X — обмен позиций 0 и 1 = окошко) |
| этаж / потолок | расстояние до e / диаметр | буквально |
| зеркало | ℓn — осевая симметрия многоугольника через ребро 0–1 | буквально |
| тройка | циклический порядок трёх чисел; меняет только X | буквально (идея доказательства §4.2) |
| компас / фронт | нейросеть или бустинг по диффузионному расстоянию (+DQN) / beam search | как в ролике про кубики |
| вилка | доказанные нижняя и верхняя оценки | буквально; для 20 шариков 179…250 |
