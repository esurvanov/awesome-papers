# Проверка ударений: ролик integrals-film (narration.py)

Слов с 2+ слогами без «ё»: 534 форм. Метод: сверка каждой формы с нормой (Аванесов, РОС РАН/Лопатин, Зализняк, Викисловарь);
через сеть дополнительно проверены спорные: договор, дробь, длина, край, кривая, всё равно, Денеф. Остальные формы сверены по нормам
без отдельного обращения к словарю на каждую (нет офлайн-словаря; RUAccent на этой машине падает с ошибкой модели и по решению автора не используется).
Статус «верно» у слов без пометок означает: расхождений с нормой не найдено, но слух автора остаётся последней проверкой.
