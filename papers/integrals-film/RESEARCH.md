# Что после Ито: ветки, а не линия (исследование 31.10.2026)

Метки достоверности: ✅ — год и суть нашлись в источниках; ≈ — год из общих знаний, не перепроверен; ⚠ — источники расходятся или не нашлись.

## Ветка A — интеграл по шуму (продолжение Ито)

| Год | Кто | Что | Что решает | Метка |
|---|---|---|---|---|
| 1923 | Винер | мера на траекториях броуновского движения | строгая модель шума | ≈ |
| 1944 | Ито | ∫ f dW, левый край | шум нигде не гладкий, Стилтьес не работает | ✅ |
| 1960-е | Кунита–Ватанабэ, Мейер | интеграл по мартингалам и семимартингалам | шум не обязан быть броуновским | ≈ |
| 1963–66 | Фиск, Стратонович | середина куска | обычное правило цепочки | ✅ |
| 1970-е | Хенгги, Томас, Климонтович | правый край («анти-Ито», «обратный Ито», «кинетический») | физика: систематическая часть уравнения определена макрозаконом | ✅ спор не закрыт: статьи 2023–2026 расходятся |
| 1975–76 | Скороход, Маллявэн | интеграл как дивергенция производной Маллявэна; для броуновского движения совпадает с Ито на адаптированных | можно подглядывать в будущее (не адаптированные ставки), «инсайдер» | ≈ год; ✅ суть |
| 1975– | Хида; Ху–Эксендаль | белый шум, произведение Вика; интеграл по дробному броуновскому движению | интеграл там, где Ито нет | ✅ суть, год ≈ |
| 1978–81 | Маркус; 1995 Курц–Пардо–Протер | «канонический» интеграл для скачков: скачок — движение по потоку; на непрерывных совпадает со Стратоновичем | цепное правило при скачках | ✅ 1981 и 1995; ⚠ 1978 не нашёл |
| ≈1979–80 | Бихтелер, Деллашери | семимартингалы — наибольший класс «хороших» интеграторов | граница: шире нельзя, оставаясь адаптированным | ✅ суть, год ≈ |
| 1981 | Фёльмер | исчисление Ито без вероятностей, по одной траектории | интеграл для каждой линии отдельно | ✅ |
| 1993 | Руссо–Валуа | регуляризация: «прямой» интеграл (обобщает Ито), «симметричный» (обобщает Стратоновича) | интегралы для процессов, не семимартингалов | ✅ |
| 1984 | Хадсон–Партасарати | квантовый интеграл на фоковом пространстве, формула Ито для операторов | квантовый шум | ✅ |
| 1992; 2005–08 | Да Прато–Забчик; ван Нирвен–Верар–Вайс | значения в гильбертовых и банаховых (UMD) пространствах | стохастические уравнения в частных производных | ✅ суть, 1992 ≈ |
| 2009–13 | Дюпир; Конт–Фурнье | функциональное исчисление Ито: функции от всей траектории | зависимые от истории выплаты, уравнения на пространстве траекторий | ✅ (Ann. Probab. 2013) |
