## 🗺 Образ и его точность

| Образ | Математика | Честность |
|---|---|---|
| набор ходов / башня | образующие / граф Кэли Sₙ | буквально |
| этаж / потолок / рост | расстояние до e / диаметр / growth | буквально |
| перебор этажами | поиск в ширину (BFS), bitmask 3 бита на состояние | буквально |
| ритм | квазимногочлен: свой многочлен для каждого n mod s | буквально; «гипотеза 1» — крайне оптимистичная |
| кольцо Глушкова | LX: левый сдвиг и (1, 2), ориентированный граф | буквально; это кольцо прошлого ролика без поворота вправо |
| колокол / перекос | нормальное распределение (Диаконис) / асимметрия, похоже на Гумбеля | колокол — доказано для соседей; Гумбель — «not a bad fit» |
| качели | инволюция, g² = e | буквально; «в рекордах есть» — гипотеза 4 |
| квадрат с усами | граф на n точках: ход = цветные рёбра i → p(i); один 4-цикл и две ветви | буквально (рис. 5) |
| компас | диффузионное расстояние + поиск лучом (beam search) | как в прошлых роликах |
