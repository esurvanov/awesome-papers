## 🗺 Образ и его точность

| Образ | Математика | Почему честно |
|---|---|---|
| карта игры | граф Кэли группы | буквально он |
| шаг / лифт | образующие x / t | — |
| этаж | гомоморфизм G → ℤ, убивающий x | номер этажа = подъёмы минус спуски |
| разные круги наверху (C1 ≠ C3) | t⟨x⟩ ≠ x³t⟨x⟩ | по модулю x² группа = C₂ * ℤ, там t⁻¹xt ∉ ⟨x⟩ |
| спуск на другой круг (C2 ≠ C0) | t·x²·t⁻¹ ∉ ⟨x⟩ | по модулю x³ |
| игрок / бухгалтер | d_F(R) / d_ℤG(R/[R,R]) | два счёта из постановки задачи |
| петля → запись | соотношение → элемент модуля соотношений (первая гомология графа Кэли) | так и сказано в доказательстве |
| «друзья» | централизатор | теорема Ньюмана: у групп с одним соотношением и кручением централизаторы циклические |
| числа 3 и 2 | p и q взаимно просты | условие теоремы A |

## 📎 Приложение: формулы и аналогии

| Шаг | Формула | Аналогия |
|---|---|---|
| ходы | шаг = x, лифт = t, вниз = t⁻¹ | команды робота |
| правило 1 | x⁶ = 1 | шесть поворотов на 60° |
| правило 2 | x³·(t·x²·t⁻¹) = (t·x²·t⁻¹)·x³ | вправо-вверх = вверх-вправо |
| вся игра | ⟨x, t \| x⁶, [x³, t·x²·t⁻¹]⟩ | правила на одной карточке |
| игрок | 2 соотношения, x¹² = 1 — лишнее | короткий свод правил |
| бухгалтер | r + s = s + r, хватает 1 | банковская выписка |
| почему 2 | x⁶ = 1 и одно соотношение ⇒ друзья дружат; но x²·крюк ≠ крюк·x² | — |
| почему 1 | НОД(3, 2) = 1, 1 = 3 − 2 | монеты в 3 и 2 рубля, сдача |

Код (GAP):

```
F := FreeGroup("x", "t");;  x := F.1;;  t := F.2;;
G := F / [ x^6, Comm(x^3, t*x^2*t^-1) ];;
```

## 📣 Пост для Telegram (утверждённый вариант — без терминов)

> 🎬 **Задача, которой 50 лет, — в четырёхминутном ролике**
>
> Математики описывают сложные штуки как игры: есть ходы и правила. Правила можно посчитать честно, а можно быстро,
> «по-бухгалтерски». 50 лет никто не знал, могут ли эти два счёта разойтись. В октябре четверо математиков нашли игру
> всего с двумя ходами, где расходятся: честно нужно два правила, а быстрый счёт даёт одно. Доказательство занимает
> страницу, и авторы пишут, что пример помог найти ChatGPT.
>
> **Как сделан ролик**
> • Анимацию написал Claude Code на библиотеке 3Blue1Brown.
> • До отрисовки собирается «паспорт ролика»: какие слова, цвета и сцены, как одна сцена переходит в другую. Скрипт следит, чтобы ни одно слово не звучало раньше, чем его объяснили.
> • Голос — бесплатная нейросеть прямо на ноутбуке. Голоса OpenAI на русском звучали гнусаво.
> • Картинка сама подстраивается под темп речи.
