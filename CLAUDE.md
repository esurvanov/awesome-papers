# CLAUDE.md

Ролики по научным статьям «простыми словами». Порядок работы — **`PLAYBOOK.md`** (флоу, законы сценария, голос,
сборка, проблемы и решения, история замечаний автора с разметкой «ядро / статья»).

## Как работаем (действует в каждой сессии)

- **Автор оценивает готовый результат.** Частности — слова, способы проверки, произношение имён, инструменты — решаешь сам и не выносишь
  вопросами; в отчёте — что сделано, что может быть слабым, принятые решения одной строкой. Вопрос — только если решение меняет направление.
- **Замечания → первопричины → правило → проверка.** Перед переделкой — разбор агентами проекта (`.claude/agents/`), таблица
  «дефект → первопричина → правило → проверка»; правило — в `PLAYBOOK.md` (закон + «История замечаний»), конечная часть — программой,
  вкус и слух — сверка с автором.
- **Флоу ролика — навык `film`** (`.claude/skills/film/SKILL.md`). Памятка с воротами печатается в начале сессии (хук `.claude/settings.json`).
- **Ворота** (обходить нельзя): `check_passport.py` → `text_check.py` (ударения по реестру, обыденная лексика, текст на слух; без него
  `build.py` не начнёт озвучку) → озвучка → `speech_check.py` (тон вниз на концах фраз) → сцены → `build.py` (печатает опоздания кадров
  > 0,5 с и наложения — исправить и пересобрать).
- **Ролик понятен без подготовки** (законы 22–35): мир — сама математика, без придуманных историй; один герой; история по датам;
  названное = нарисованное; картинка вместе со словом; мостики на стыках; числа из рисунка; 3D только где третье измерение несёт смысл.

## Ядро и статьи

- **Ядро** — `core/` и `PLAYBOOK.md`: то, что верно для любого ролика. Основа сцен — `core/manimkit/film.py` (`film_base`: кадр = фраза,
  превращения по меткам, точный синхрон, начало с последнего кадра прошлой сцены, журнал наложений), помощники кадра —
  `core/manimkit/annot.py`, общие реестры ударений и лексики — `core/lang/`, шаблон нового ролика — `core/templates/paper/`.
- **Статья** — `papers/<arxiv-id>-<слово>/`: `passport.py`, `narration.py`, `scenes.py`, `scenario.md`, данные, `NOTES.md`.
  Всё, что верно только для этой статьи, — в её `NOTES.md`, не в ядре.
- Новое правило из замечания автора: решить, ядро это или статья, и записать в соответствующее место
  (и строкой в «Историю замечаний» в `PLAYBOOK.md`).

## Правила

- Движок — **ManimGL** (`import manimlib`), форк в `vendor/manim/` (правки — в `vendor/manim/UPSTREAM.md`). ManimCE не используем.
- LaTeX на машине нет: текст через `tx()` (степени — `x^6`), без `Tex`/`Brace`.
- Флоу — от зрителя к сценам (PLAYBOOK, «Флоу»): пересказ → мир с задачей → словарь «слово → картинка» → текст вслух →
  озвучка → раскадровка (`animatic.py`) → новый зритель → сцены по фразам (`self.beat`) → просмотр в полном размере.
- Каждый ролик начинается с паспорта; `uv run python core/pipeline/check_passport.py papers/<папка>` и
  `uv run python core/pipeline/text_check.py papers/<папка>` — 0 нарушений до озвучки.
  До озвучки — **статус после статьи** (`STATUS` в паспорте): что об утверждениях ролика известно на сегодня
  (PLAYBOOK, «Статус после статьи»).
- Голос выбирает автор на слух по длинным образцам; по умолчанию OpenAI `gpt-realtime-2.1`, голос `verse` (выбран автором 21.10.2026;
  отправка текста диктора в OpenAI для озвучки согласована). Указание голосу — блоки `VOICE_PARTS` в `core/pipeline/voice.py`
  (голос, регистр, ритм, фраза, темп, подача, согласные, ударения, интонация); не менять без нового образца и сверки на слух.
  Под другую манеру — заменить отдельный блок: `VOICE_OVERRIDE = {"tempo": "…"}` в `narration.py` статьи.
  Ударения — знаками в тексте диктора, каждая форма — из реестра (`core/lang/stress_registry.tsv` + реестр ролика; новая форма — по двум
  словарям агентом `stress-verifier`). Голосу уходит фонетическая запись трудных мест (`voice.for_voice`, `SAY_AS`). Запасной голос — Silero `xenia`.
  Отправка текста в другие внешние сервисы или для других целей — только с согласия автора.
- **Видео, кадры, озвучку не коммитим** (`videos/` в `.gitignore`); ключи — только в `.env.local`.
- `vendor/Animator` — вложенный репозиторий (форк esurvanov/Animator, upstream — ashishjamarkattel/Animator). **У Animator нет
  лицензии**: его код не копировать в этот репозиторий, правки — коммитами в форк (`git -C vendor/Animator …`), здесь — только
  обновлённая ссылка на коммит. Когда автор добавит лицензию — отметить в README «Сторонний код».
- Модули в `core/manimkit` задают `__all__`; файл сцен не править, пока идёт сборка.
- **README — витрина репозитория.** `README.md` — английский, `README.ru.md` — русский, в первой строке ссылки друг на друга. Эмодзи
  запрещены. Понятно любому без подготовки: что это, картинки и схемы (`docs/img`, схемы — `docs/make_diagrams.py`), каждая статья
  со ссылкой на arXiv, ролики и блог — со ссылками, все папки `papers/*`. Новая статья или опубликованный ролик — строка в обоих
  файлах; проверка — `uv run python core/pipeline/check_readme.py` (0 нарушений перед коммитом).
