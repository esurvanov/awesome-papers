# CLAUDE.md

Ролики по научным статьям «простыми словами». Порядок работы — **`PLAYBOOK.md`** (флоу, законы сценария, голос,
сборка, проблемы и решения, история замечаний автора с разметкой «ядро / статья»).

## Ядро и статьи

- **Ядро** — `core/` (manimkit, pipeline, templates) и `PLAYBOOK.md`: то, что верно для любого ролика.
- **Статья** — `papers/<arxiv-id>-<слово>/`: `passport.py`, `narration.py`, `scenes.py`, `scenario.md`, данные, `NOTES.md`.
  Всё, что верно только для этой статьи, — в её `NOTES.md`, не в ядре.
- Новое правило из замечания автора: решить, ядро это или статья, и записать в соответствующее место
  (и строкой в «Историю замечаний» в `PLAYBOOK.md`).

## Правила

- Движок — **ManimGL** (`import manimlib`), форк в `vendor/manim/` (правки — в `vendor/manim/UPSTREAM.md`). ManimCE не используем.
- LaTeX на машине нет: текст через `tx()` (степени — `x^6`), без `Tex`/`Brace`.
- Каждый ролик начинается с паспорта; паспорт и текст показать автору **до** отрисовки;
  `uv run python core/pipeline/check_passport.py papers/<папка>` — 0 нарушений.
- Голос выбирает автор на слух по длинным образцам; по умолчанию локальный Silero `xenia`.
  Перед отправкой текста внешним сервисам (OpenAI и др.) — согласие автора.
- **Видео, кадры, озвучку не коммитим** (`videos/` в `.gitignore`); ключи — только в `.env.local`.
- Модули в `core/manimkit` задают `__all__`; файл сцен не править, пока идёт сборка.
