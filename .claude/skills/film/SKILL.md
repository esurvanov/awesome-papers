# Флоу ролика (PLAYBOOK — законы 1–35, история замечаний)

Автор оценивает готовый результат. Частности (слова, способы проверки, произношение имён, инструменты) решаешь сам и не выносишь вопросами; показываешь итог и одной строкой — принятые решения. Вопрос автору — только если решение меняет направление и его нельзя вывести из правил и исследований.

## 0. Замечания автора → первопричины (перед любой переделкой)
1. Разложи замечания на пункты; извлеки кадры по таймкодам (`ffmpeg -ss <сек> -i … -frames:v 1`).
2. Запусти агентов параллельно (`.claude/agents/`): `root-cause-frames` (кадры → код → классы дефектов), `frame-standards` (графика кадра), `text-image-sync` (связь речи и картинки), `explainer-script` (объяснение без подготовки), `stress-verifier` (ударения), `pronunciation` (произношение и просодия), `plain-language` (обыденная лексика) — только те, что относятся к замечаниям.
3. Сведи в таблицу «дефект → первопричина → правило → проверка». Новое правило — в PLAYBOOK (закон + строка «Истории замечаний», «ядро / статья»), конечную часть — в программную проверку.

## 1. Замысел и текст
- Паспорт (`passport.py`): пересказ, вопрос, общая идея и сквозные сущности, станции, словарь WORDS, числа NUMBERS, сцены, стыки LINKS (связка = начало сцены), раскадровка STORYBOARD (кадр на каждую фразу).
- Мир — сама математика (график, фигуры), без придуманных историй; один герой на весь ролик; сквозное число, к которому приходят все способы.
- История — по датам; каждый объект вводится один раз, на примере, с подписью; названное = нарисованное; мостик на каждом стыке.
- Текст (`narration.py`): обыденный язык, фразы до 18 слов, без двоеточий и «не X, а Y», связки разные, числа и годы словами, имена на экране.
- Ударения: каждая форма — из реестра (`core/lang/stress_registry.tsv` + реестр ролика); новые формы — агентом `stress-verifier` по двум словарям, затем в общий реестр.
- Проверки: `uv run python core/pipeline/check_passport.py papers/<папка>`, `uv run python core/pipeline/text_check.py papers/<папка>` — 0 нарушений (кроме «нет класса сцены» и VIEWER_TEST до сцен).

## 2. Голос
- `uv run python core/pipeline/build.py papers/<папка> --voice-only` (сборка сама не начнёт без пройденной проверки текста).
- Голосу уходит фонетическая запись трудных мест (`voice.for_voice`, `SAY_AS`). Указание — блоки `VOICE_PARTS` и `VOICE_OVERRIDE`.
- `uv run python core/pipeline/speech_check.py papers/<папка> --reroll 2` — тон на концах фраз вниз; брак переозвучивается.

## 3. Мир и сцены
- `world.py` ролика: своя геометрия и числа из рисунка (суммы, площади считаются функциями, не вписываются руками); общие помощники кадра — `core/manimkit/annot.py`.
- `scenes.py`: `Film, Film3D = film_base(...)` из `core/manimkit/film.py`; один `self.show` на фразу; продолжающийся объект — с одной меткой `tagged(m, "имя")`; движение — `self.do(...)` на словах о движении; 3D — только если третье измерение несёт смысл (закон 26).
- Сцены пишутся параллельно агентами `scene-writer` блоками по 5–6 сцен (каждый — в свой файл, потом сборка в `scenes.py`); образец стиля — первые сцены, написанные самим.
- Каждую сцену: рендер `-l`, контактный лист, правка (до 3 итераций); предупреждений «⚠ кадр» быть не должно.

## 4. Сборка и разбор
- `uv run python core/pipeline/build.py papers/<папка>` — после сборки печатает ворота: опоздания кадров > 0,5 с, наложения, подъём тона. Исправить всё и пересобрать.
- Просмотр: листы кадров ключевых сцен; отчёт автору — что сделано и что может быть слабым (честно), без технины.
