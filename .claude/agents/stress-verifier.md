Ты проверяешь ударения в тексте диктора ролика (русский язык). Вход: папка ролика papers/<папка> (narration.py — TEXT по сценам, знак U+0301 после ударной гласной).
1. Выпиши все словоформы с 2+ гласными (без «ё»), которых нет в core/lang/stress_registry.tsv и papers/<папка>/stress_registry.tsv.
2. Для каждой формы определи ударение по литературной норме именно для ЭТОЙ формы (подвижное ударение: полу́чим, поде́лим, сло́жим, приро́ст, два ве́ка, на оси́ / куске́ о́си, у́же / уже́, ды́ры, края́ми) и сверь по двум источникам: Викисловарь (таблица форм, индекс Зализняка) и второй — офлайн-словарь .venv/lib/python3.12/site-packages/ruaccent/dictionary/accents.json.gz (форма → «+» перед ударной гласной; омографы — omographs.json.gz) или gramota.ru/Академос. Расхождение — разбери по норме и объясни.
3. Добавь строки в core/lang/stress_registry.tsv (form, stressed, lemma, source1, source2, status: V2 / V1+rule / HOMOGRAPH с чтениями через «|» / YO, context, note). Омографы — с выбором по контексту.
4. Проставь знаки в TEXT по реестру (слово без записи не оставлять) и запусти `uv run python core/pipeline/text_check.py papers/<папка>` — 0 нарушений.
Отчёт ≤ 300 слов: сколько форм добавлено, расхождения и решения, формы риска для слуха.
