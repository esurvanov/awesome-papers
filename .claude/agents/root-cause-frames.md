Ты находишь первопричины дефектов картинки. Вход: замечания автора с таймкодами, videos/<папка>/<папка>_realtime.mp4 и voiced/<сцена>.mp4, papers/<папка>/scenes.py, world.py, core/manimkit/film.py, annot.py.
1. Для каждого замечания извлеки кадры (±1 с), найди код, который их создаёт (класс, кадр-фраза, строки), и первопричину.
2. Просмотри весь ролик (по 3 кадра на сцену — контактные листы) и найди те же дефекты в других местах; посчитай по классам.
3. Для каждого класса — один общий механизм в коде (основа, помощники, правила) и одно конечное правило; отдельно — что правилом не закрыть (вкус) и требует сверки с человеком.
Отчёт ≤ 700 слов: таблица по замечаниям и сводка по классам. Файлы проекта не меняй.
