# Критерии оценки статей arXiv

Версия 1 · зафиксировано 2026-10-22.
Вход по каждой статье: заголовок, авторы, аннотация, пометки авторов, полный текст (HTML → текст).
Данные готовит `fetch_arxiv.py`. Источники критериев: https://claude.ai/artifact/HxWw1e53hdkJ4UiRxBeiSC

## Что и откуда смотрим

| Источник | Что проверяем |
|---|---|
| Заголовок | Отсев узких и чужих тем |
| Аннотация | Важность, новизна, широта: что авторы заявляют |
| Полный текст | Надёжность и готовность: подтверждено ли заявленное |
| Авторы и места работы | Только для справки, на балл не влияют |
| Пометки авторов | Принято ли на конференцию, есть ли код |

## 1. Важность задачи (0–2) — аннотация, введение

| Балл | Признак |
|---|---|
| 0 | Узкая ниша, одна прикладная задача |
| 1 | Задача важна для одной подобласти |
| 2 | Касается всех, кто строит или применяет ИИ: агенты, безопасность, обучение, оценка моделей |

## 2. Новизна (0–2) — аннотация, обзор похожих работ

| Балл | Признак |
|---|---|
| 0 | Небольшое улучшение известного метода или перенос его в новую область |
| 1 | Новый метод или новый набор тестов в уже насыщенной теме |
| 2 | Новый вопрос, новая угроза, опровержение привычного или важный отрицательный результат |

Проверка по тексту: действительно ли авторы сравнивают себя с ближайшими работами.

## 3. Надёжность (0–2) — полный текст

| # | Пункт | Где искать |
|---|---|---|
| 1 | Несколько моделей, а не одна | Раздел экспериментов |
| 2 | Несколько разных тестов | Таблицы результатов |
| 3 | Разброс результатов или повторные запуски | Таблицы и подписи к ним |
| 4 | Проверено, что даёт каждая часть метода | Раздел с отключением частей метода |
| 5 | Сильные и свежие аналоги для сравнения, включая простые | Список того, с чем сравнивают |
| 6 | Честный раздел ограничений | Раздел «Limitations» |
| 7 | Проверено, что тест не попал в обучение модели | Раздел о данных |
| 8 | Указаны затраты вычислений | Приложение, детали обучения |
| 9 | Выводы в аннотации не шире, чем показано в тексте | Сравнение аннотации и результатов |

- **Перевод в балл:** 0–3 пункта → 0, 4–6 пунктов → 1, 7–9 пунктов → 2.
- **Обнуление:** надёжность = 0, если громкое заявление из аннотации в тексте подтверждено слабо.

## 4. Широта (0–2) — результаты

| Балл | Признак |
|---|---|
| 0 | Одна задача или один набор данных |
| 1 | Один класс моделей или одна область |
| 2 | Вывод держится на разных моделях, задачах и данных |

## 5. Готовность к применению (0–2) — текст, пометки

| Балл | Признак |
|---|---|
| 0 | Игрушечный опыт или только теория |
| 1 | Стандартные тесты, кода нет |
| 2 | Реальные данные или внедрение, плюс открытый код или модель |

## 6. Внешние сигналы (0–1) — пометки, текст

| Балл | Признак |
|---|---|
| +1 | Принято на конференцию **или** открыты код и данные |

## Итог

Сумма 0–11:
- 🟢 **8–11** — читать целиком
- 🟡 **5–7** — хватит аннотации
- ⚪ **0–4** — пропустить

## Поправки

| | Признак | Поправка |
|---|---|---|
| ➖ | «Лучший результат» только на 1–2 тестах | −1 к надёжности |
| ➖ | Громкие слова: «как человек», «понимает» | −1 к надёжности |
| ➖ | Объяснение «почему работает» не проверено опытом | −1 к надёжности |
| ➖ | Формулы для солидности, не для вывода | −1 к надёжности |
| ➖ | Прирост на давно «решённом» тесте | −1 к новизне |
| ➕ | Отрицательный результат подан как вклад | +1 к новизне |

Баллы по критерию не выходят за его пределы (0–2 или 0–1).

## Страховки

| | Правило | Зачем |
|---|---|---|
| 🎲 | 10–20% необычных статей с низким баллом попадают в отдельную категорию «посмотреть» | Новаторское стартует медленно |
| 🙈 | Известная лаборатория не даёт баллов | Популярность раздувает внимание независимо от качества |
| 📄 | Статьи без полного текста оцениваются только по аннотации, с пометкой | Надёжность для них проверить нельзя |
| 🔁 | Через 1–2 недели баллы сверяются с голосами на Hugging Face и alphaXiv | Проверка, что фильтр не врёт |

## Выход по каждой статье

| Поле | Пример |
|---|---|
| Итог | 🟢 9 из 11, читать |
| Баллы по 6 критериям | Важность 2 · Новизна 2 · Надёжность 2 · Широта 1 · Готовность 1 · Сигналы 1 |
| Отмеченные пункты надёжности | 7 из 9 |
| Почему так | Одно предложение |
| Главный довод «за» и «против» | По одному пункту |
| Без полного текста | Пометка, если оценено только по аннотации |
