# 2610.28882 — inr2action: Encoding Robot Episodes as Neural Implicit Representations for Recall and Action
Authors: Leann Alhashishi, Christos Margadji, Sebastian William Pattinson
Comment: 
Categories: cs.RO, cs.AI

## ABSTRACT
Long-horizon robotic operation requires memory that scales with essential information rather than execution time. We present a parameter-space memory framework where each episode is stored as a separable object. A neural implicit representation is fitted to episode video from a shared, meta-learned initialization; the resulting weight delta constitutes the memory. Crucially, this delta remains a fixed size regardless of whether the episode spans a hundred or a hundred thousand frames. A learned projector maps the weight delta into token embeddings, conditioning a language model for question answering and a decoder for joint command regression, without frame retrieval at query time. On RoboMME, the language model exceeds chance across all question types, and the decoder achieves a mean $R^2$ of 0.51. Replacing the delta with matched noise drops performance by 11.4 points, while random-origin weights are non-decodable, proving the meta-learned initialization is essential for embedding episode content. By representing individual experiences as fixed-size weight deltas in a common parameter space, this approach decouples memory cost from time horizon and provides a basis for scalable streaming memory.

## I Introduction

Fig. 1: The overall system using weights as memory. An episode is encoded by fitting an INR from a meta-learned initialization $\theta$ ; the weight delta $\Delta$ is the memory and reconstructs the frames. With no frame access, the same $\Delta$ is decoded into the next joint command and a natural-language answer.

Robots that operate over extended horizons must remember what they have observed.
When the information that determines the correct action has already left the field of view, a robot without memory can only guess.
In robotic manipulation, the evidence that resolves such a decision can lie seconds, minutes, or in long-horizon deployments hours in the past, and by then the scene itself may no longer show it: a quantity that accumulated over time, a property visible only before it was occluded, a reference fixed at the outset of the episode.
Feeding the entire observation stream back into the policy is not a general answer, as its cost scales with how long the robot has been running rather than with how much of what it saw actually needs to be remembered.
We consider such settings non-Markovian, as the information needed at time $t$ is distributed across the episode rather than contained in any single frame, a gap that recent benchmarks make explicit [1].
Throughout, memory refers to a persistent representation of information that can be accessed independently of the original input that produced it.

Existing sequence models hold information in one of three places.
The first is transient activations: an LSTM’s hidden state [2] or a transformer’s key-value cache [3] compresses observed history, but the stored information is bound to the current computation, and once the forward pass ends or the context window closes it cannot be queried on its own terms.
The second is explicit external storage, from differentiable memory matrices [4] to retrieval over document collections [5], which decouples storage capacity from model capacity at the cost of memory becoming a record that must be retrieved before reasoning can proceed.
A third and more recent paradigm encodes memory directly into parameters: Titans [6] updates a dedicated memory module’s weights during inference, and GradMem [7] performs test-time gradient descent on learnable memory tokens, both showing that gradient-based optimization at inference time can construct persistent memory for a model.
These methods, however, have been developed primarily for language sequences, and they continually update a single running memory over an incoming stream rather than representing individual experiences as separable memories.

In this work, each robot episode is encoded as its own parameter-space memory: a neural implicit representation (INR) fitted to the episode from a shared meta-learned initialization, whose weights constitute the memory.
A learned projector maps these weights into token embeddings for a language model, which answers natural-language questions about the episode, and the same tokens condition an action decoder that predicts the robot’s next joint command.
No frame is stored, reconstructed, or retrieved at query time.
We evaluate on RoboMME [1], a benchmark of 16 non-Markovian manipulation tasks spanning temporal, spatial, object, and procedural memory, and show that a memory encoded in this way is legible to a downstream model without frame re-access.
The contributions of this work are:

• 

A formulation of episodic memory for robotics as INR weights, and a tensor-wise projector mapping them into the token space of pre-trained language backbones, yielding, to our knowledge, the first system to answer natural-language questions about a video episode from INR weights alone.

• 

An action decoder of the same weight-tokens that regresses the robot’s optimal next joint command, extending weight-space memory from recall to action.

• 

Matched noise and within-task controls, together with an initialization ablation, attributing both question answering and action decoding to episode content and establishing the shared meta-learned origin as the condition that renders the weights decodable.

## II Related work

## II-A Neural Implicit Networks

A neural implicit representation (INR) is a neural network trained to encode a signal as a continuous function, $f(x)\to y$ , mapping input coordinates directly to signal values rather than storing data on a discrete grid. Once trained, the network can then reconstruct the original signal through forward passes over the learned parameters. SIREN [8] established the basic feasibility of representing perceptual signals this way: its periodic sine activations counteract the spectral bias of ReLU networks, which limits the fine detail they can represent, and yield high-fidelity reconstructions of images, objects, and audio.

Subsequent work extended what fitted parameters can hold.
NeRF [9] extended implicit representations from two dimensions into three, so that scene geometry and appearance could be recovered directly from learned parameters.
LeRF [10] built on this by distilling CLIP and DINO feature embeddings into a NeRF’s weight space, allowing open-vocabulary semantic queries over the encoded scene.

Video, being a substantially larger signal than a static image or scene, makes fitting speed a practical bottleneck for these pixel-wise architectures. NeRV [11] represents video as a function of time $t$ , predicting a full RGB frame from a single temporal coordinate rather than querying spatial locations one at a time, which is considerably faster to fit and reconstruct than pixel-wise INRs [12].

Fitting cost has itself been a target, falling from hours to seconds through alternative parameterizations [13, 14], amortized prediction of weights in a single forward pass [15], or meta-learned initializations that converge in a handful of gradient steps [16], making per-instance fitting practical online rather than offline.
This literature establishes that perceptual detail, geometry, semantics, and temporal evolution can all be stored in INR parameters, but it largely treats fitted weights as a route to reconstruction and compression rather than as representations to be queried in their own right.

## II-B Weight Space Learning

Weight space learning treats the parameters of trained networks as a data modality in their own right [17].
Functa [18] (data as a function) introduced this framing for INRs, treating each fitted function as a data point in a learned representation space, with classifiers trained directly on these resulting modulation vectors generalizing to unseen instances.
This effect depends on all fitted functions sharing a common origin, an observation grounded via the Implicit Function Theorem [19].

A shared initialization is the standard means of supplying such an origin.
MAML [20] learns an initialization from which a few gradient updates produce task-specific parameters, which offers a way to produce fitted weights that remain comparable across instances.
COIN++ [21] applies this combination of shared initialization and fast per-instance fitting to INRs specifically by meta-learning a shared base network and representing each new signal through low-dimensional modulations fitted at inference time.
It is a close precedent for treating adaptation from a common origin as an encoding mechanism.
Gielisse et al. [22] show that meta-learned SIREN initializations combined with a transformer over the resulting weights can outperform permutation-equivariant alternatives on classification.

Once fitted weights sit in a shared coordinate system, standard learning algorithms can exploit that structure directly.
De Luigi et al. [23] show that an encoder trained over fitted INR weights for 3D shapes yields embeddings that support retrieval, clustering, and classification.
Weight-space representations have more recently begun serving as direct inputs to foundation models: LLaNA [24] projects fitted NeRF weights into the embedding space of a large language model, following the training scheme of LLaVA [25], so that the model answers natural-language queries about a 3D scene while conditioning on weights rather than on pixels, image features, or rendered views.

## II-C Memory in Robotic Manipulation

Robot manipulation systems store interaction history in the same three places identified in Section I: as an external record, in activations, or, far more rarely, in parameters. The first is the most common and takes two forms. Symbolic approaches derive non-differentiable abstractions from the interaction history, tracking object-centric states [26] or appending past actions to the input prompt [27], with recent systems using large vision-language models to write language-based subgoals or memory summaries [28, 29, 30]. Offloading memory and reasoning externally in this way is costly at inference and makes end-to-end optimization difficult. Perceptual approaches instead retain differentiable visual or multimodal features, either appended directly to the model input as context tokens [31] or cached in memory banks for later retrieval [32, 33]. Recurrent approaches compress history into a fixed-size latent state through iterative updates, from recurrent behavior-cloning policies [34] to recent state-space models [35, 36]. Each of these retains observations, derived features, or activation states.

## III Methods

## III-A Task definition

Given a video episode $\epsilon$ consisting of a sequence of frames $x_{1},\dots,x_{T}$ and a natural-language query about the episode, the system produces an output by factorizing this mapping through a weight-space memory representation. Each episode $\epsilon$ is mapped to its own parameter vector $\phi$ and, through the delta defined below, to its own memory representation $\Delta$ .

An episode is first encoded into the parameters of an INR by fitting it to reconstruct the video. Let $\phi$ denote the resulting parameter vector and $\theta$ a shared and task-agnostic initialization common to all episodes. The episode’s memory representation is the delta

 $\Delta=\phi-\theta,$ 

(1)

which isolates the change induced by that specific episode ( $\phi$ ) from the initialization shared across the dataset ( $\theta$ ). A learned projector $f_{\psi}$ maps $\Delta$ into a sequence of token embeddings compatible with a language model $g$ . We consider two ways of querying this representation (see Figure 2). For question answering, given a natural-language question $q$ ,

 $\hat{y}=g(f_{\psi}(\Delta),q),$ 

(2)

where the language model conditions on both the projected weight-tokens and the question. For action decoding, the linguistic decoding of $g$ ’s output is replaced by a regression head $h_{\omega}$ applied to its final hidden state,

 $\hat{a}=h_{\omega}\big(g(f_{\psi}(\Delta),\,q)\big)\approx a\in\mathbb{R}^{d},$ 

(3)

with $q$ given by the episode’s task instruction, $g$ instantiated separately per output head, and $a$ the absolute joint-space command at the point where the episode’s observation ends.

## III-B Dataset generation

All experiments use RoboMME [1], a benchmark of question-answering videos built on the ManiSkill simulator [37] with a 7-DOF Franka Panda arm. Each video shows the arm performing a tabletop manipulation task, and the accompanying questions probe aspects of the episode that no isolated frame can resolve. The 16 task types form four suites, each targeting a distinct form of memory: Counting (temporal), Permanence (spatial), Reference (object), and Imitation (procedural).

Each task type contributes 100 source episodes, giving a base corpus of 1,600 episodes split 70/15/15 into train, validation, and test partitions, with frames rendered at $64\times 64$  px. A single episode does not produce a single INR: for each episode, 10 random truncation points $T_{\text{cut}}$ are drawn from its timeline, and an INR is fit independently to the frames up to $T_{\text{cut}}$ . The label fields are extracted at that last frame, so each source episode supplies multiple temporally distinct memories, for 16,000 fitted INRs per configuration (Figure 3). Four label types are read out at each cut, ordered by increasing dependence on memory: gripper, whether the gripper is closed at the cut frame, resolvable from that frame alone. choice_action is the atomic action being performed. subgoal is a fine-grained sub-step the robot is currently executing, such as picking up a given cube for the third time, and task_goal, the instruction governing the episode, whose instances within a task are near-duplicates differing in a single attribute such as a color or a repetition count.

Every INR is fit from a common initialization $\theta$ , learned via MAML [20], which optimizes $\theta$ so that a small number of gradient steps produces a good per-episode fit on any episode from the training distribution. Per-episode fitting then adapts $\theta$ through 500 steps of full-batch Adam on the reconstruction objective of Section III-C. Because adapted and initialization weights are typically close in magnitude, with the initialization dominating the raw parameter values, we follow [22] in taking the difference $\Delta$ (Eq. 1) as the representation rather than the raw fitted weights, isolating the change induced by the specific episode. Fitting from a shared origin is also what makes deltas comparable across instances, per the shared-coordinate-system arguments of Section II-B.

Fig. 3: RoboMME ground truth at a single frame, illustrated on an example PickXtimes episode. Each frame is paired with the label fields read out when it serves as the cut frame $T_{\text{cut}}$ : the gripper state (gripper), the atomic action in progress (choice_action), the current sub-step (subgoal), the instruction governing the episode (task_goal), and the commanded joint vector (joint_action).

To verify that this construction yields organized weight representations, t-SNE embeddings were computed over the fitted deltas (Figure 4). No suite or task label was used in fitting the INRs or computing the embedding. Under the meta-learned initialization, Permanence and Imitation task-type weights form tight, well-separated clusters, while Counting and Reference weights interleave with one another but remain distinct from the other two suites. Coherent clusters form even for tasks that never appeared in meta-training, which uses only five of the 16 task types. Randomly initialized weights show no visible separation by suite. This is consistent with adaptation from the shared initialization inducing an organized common weight space, and it is the delta that the downstream experiments operate on.

## III-C System architecture

The system comprises three components, following Figure 2: the INR encoder producing each episode’s delta, the projector mapping the delta into weight-tokens, and two output heads (decoders) over the resulting token sequence.

## III-C1 INR Encoder

Each episode’s INR follows NeRV [11]: a positional encoding lifts the normalized timestep into a high-frequency sinusoidal embedding, a three-layer MLP stem maps it to a spatial feature map, a series of NeRV blocks progressively upsample it through a $3\times 3$ convolution, a PixelShuffle layer [38], and a GELU activation, and a final $1\times 1$ convolution produces the RGB frame (full architectural specifications follow Appendix A.1 of [11]). Each INR is fit by minimizing a weighted combination of $\mathcal{L}_{1}$ reconstruction and structural dissimilarity,

 $\mathcal{L}_{\text{NeRV}}=\lambda\|\hat{x}-x\|_{1}+(1-\lambda)(1-\text{SSIM}(\hat{x},x)),$ 

(4)

with $\lambda=0.7$ : the $\mathcal{L}_{1}$ term encourages pixel-accurate reconstruction, while the SSIM term preserves local structural patterns that $\mathcal{L}_{1}$ alone can blur. During meta-training, the inner-loop learning rate is a per-parameter vector learned jointly with $\theta$ over $K=3$ inner steps, following the MetaSDF formulation of [16].

## CONCLUSION
Experimental results establish projected INR weight-delta tokens as a queryable episode representation: a language model answers memory-dependent questions from the weight-tokens alone, an action decoder predicts the robot’s next joint command from the same tokens, and meta-learned parameter origins are shown to be necessary for such information to be decodable. The weight delta $\Delta$ thereby functions as a persistent and individually addressable memory object, a property no activation-bound representation offers, and one that complements continually overwritten parametric memories such as Titans [6] wherever individual episodes must remain separable. For robotics, where RoboMME identifies memory as a binding constraint on generalist policies [1], our results suggest memory representations, rather than frame retention alone, as a design axis for vision-language-action systems [42].

There are several limitations. All accuracies rest on two training seeds and a limited corpus of source episodes, so differences of one to three points between adjacent configurations should not be over-read. Scoring a closed candidate set by likelihood establishes discrimination, not free-form generation, and the memory construction is offline, with no external baseline such as a vision-language model given the frames directly. Scaling INR capacity and resolution, evaluating open-ended generation, and moving the INR fit and language model updates online as test-time training in the sense of Titans [6] are delegated to future work.
