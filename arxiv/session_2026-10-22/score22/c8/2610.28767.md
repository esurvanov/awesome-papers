## ABSTRACT
Current evaluation of LLMs on benchmarks typically aggregates performance over individual examples into a single scalar score. This approach is overly coarse and ignores the diverse scope of skills covered by benchmark datasets. To address this limitation and better exploit benchmark data, we propose SkillEval, a new evaluation framework that performs cross-model, skill-level analysis. The framework integrates advances from two areas: (1) it leverages the meta-cognitive capabilities of LLMs to automatically discover interpretable skills from questions, and (2) it applies cognitive diagnosis models (CDMs) from psychometrics to estimate per-skill abilities of LLMs. We conduct experiments on 3,811 LLMs evaluated on 9,523 items across five benchmarks spanning diverse domains (MATH, BBH, GPQA, MuSR, IFEval). Compared to the traditional average-based evaluation paradigm, SkillEval produces reliable, more calibrated and informative yet concise model profiles that more accurately predict model behavior on unseen items. We also demonstrate the utility of SkillEval in two downstream tasks: (1) LLM routing, which dynamically assigns each query to a capable but efficient model, reducing inference cost by over 60% while achieving improved performance, and (2) Computerized Adaptive Testing (CAT), where an unseen model can be efficiently evaluated using a trained CDM. Furthermore, we show that these skill profiles provide useful insights, for example, how benchmarks share skills and how instruction-tuned models differ from their base models.

## 1 Introduction

Benchmarks for large language models (LLMs) have rapidly proliferated in recent years. While this creates new opportunities, it also raises a key challenge: how to effectively leverage a large collection of benchmarks for comprehensive LLM evaluation?
Current evaluation practices remain quite raw.
The common approach is to evaluate a model on all items in a benchmark and then report the average score.
This naive statistical way collapses performance across items into a single number, which obscures fine-grained capability differences (Cui et al., 2026a).
For example, two LLMs with similar overall accuracy on a math benchmark (0.63 vs. 0.65) may exhibit very different profiles across sub-skills such as algebra and geometry.
This leads to a natural question: Given a set of test items, how can we go beyond a scalar score to a more informative, human-understandable capability estimate?

To answer this, we develop a new evaluation framework that aims to assess the latent abilities underlying observed item scores, and represents them as fine-grained skill profiles of LLMs.
This problem has long been studied in psychometrics and the education community using various latent variable models.
A representative family of approaches is Item Response Theory (Lord and Novick, 1968, IRT;), which jointly models test-taker traits (e.g., ability) and item traits (e.g., difficulty and discrimination).
IRT models are also increasingly used in machine learning, but typically for data-centric tasks such as dataset analysis or distillation (Kipnis et al., 2025; Maia Polo et al., 2024; Zouhar et al., 2025; Rodriguez et al., 2021; Cui et al., 2026b), and less often for LLM evaluation as it still produces a scalar overall ability score that suffers from capability collapse.
Some recent work explores multidimensional-IRT (Reckase, 2006) and its neural variants that learn ability vectors (Chen et al., 2025; Cui and Sachan, 2025; Song et al., 2025; Gor et al., 2024).
However, these multidimensional models are known to suffer from poor interpretability and non-identifiability, making them less suitable for reliable evaluation.

In this study, we propose SkillEval, a new evaluation framework that identifies latent skills and estimates LLM abilities at the skill level.
The framework consists of a skill discovery module, which extracts shared skills from problems, and a neural cognitive diagnosis model (Wang et al., 2020, CDM;), which estimates per-skill abilities based on model performance on skill-associated items.
We evaluate SkillEval on a large-scale dataset of 36M model–item response records, covering 3,811 models and 9,523 items across five benchmarks from various domains, including MATH (Hendrycks et al., 2021), BBH (Suzgun et al., 2023), GPQA (Rein et al., 2024), MuSR (Sprague et al., 2024), and IFEval (Zhou et al., 2023).
We conduct extensive experiments and demonstrate the superiority of SkillEval from various aspects:

• 

Compared to MIRT-style methods, SkillEval extracts high-quality, human-understandable skills and produces stable ability estimates across runs, ensuring reproducible and robust evaluation.

• 

SkillEval accurately predicts model performance at both the item (with ${\rm AUC}=81.73$ ) and benchmark (with Pearson $r=0.989$ ) levels, outperforming strong baselines. In a downstream routing task where the goal is to assign queries to a cheap yet capable model, SkillEval matches the strongest LLM at $25\%$ of the cost ( $\tau{=}0.80$ , $99.9\%$ of strongest accuracy), and exceeds it by $3.7$ points at $37\%$ of the cost ( $\tau{=}0.95$ ). It also profiles previously unseen LLMs efficiently without retraining the shared network: $20$ adaptively chosen answers yield a mean benchmark-score error comparable to $100$ randomly chosen answers.

• 

In addition, SkillEval serves as a useful tool for analyzing dataset structure and model behavior, such as skill coverage across benchmarks, co-mastery patterns among skills, and skill-level differences between base and instruction-tuned models, offering useful insights into data curation and model training.

## 2 Profiling LLMs’ Skills with Cognitive Diagnostic Models

## 2.1 Problem Statement

Given a set of models to be evaluated $\{\mathcal{M}_{1},...,\mathcal{M}_{M}\}$ and a collection of test items $\{x_{1},...,x_{N}\}$ from one or multiple benchmarks, we represent their performance using a matrix $\mathcal{S}\in\mathbb{R}^{M\times N}$ , where each entry $\mathcal{S}_{ij}$ denotes the score of the $i$ -th model on the $j$ -th item.
We formulate LLM profiling as a function $\mathcal{F}$ that takes $\mathcal{S}$ as input and outputs some estimates for each model’s capabilities, i.e., $\mathcal{F}(\mathcal{S})\rightarrow\{\theta_{1},...,\theta_{M}\}$ , where $\theta_{i}$ is a quantitative measurement of the capabilities of model $i$ .

The common practice in evaluation is to model $\mathcal{F}$ as a simple average over individual items, i.e., $\theta_{i}=\frac{1}{n}\sum_{j=1}^{n}S_{ij}$ .
While this provides a concise summary of model performance, it suffers from two key limitations. First, it compresses the model’s performance into a single scalar metric, failing to capture variations across fine-grained skills.
Second, the naive average can be affected by bias induced by the difficulty distribution of the test items, and may not faithfully reflect the model’s true ability. Indeed, this type of ability modeling assumes that all items in a given benchmark contribute equally to the estimation of a single ability dimension, which is typically an implausible assumption.

To address these limitations, we propose a new paradigm for profiling LLMs.
We assume that the items in the benchmark are associated with a set of underlying latent skills $\mathcal{C}=\{c_{1},\ldots,c_{K}\}$ .
Inspired by psychometric approaches for assessing latent traits, we use Cognitive Diagnosis Models (CDMs) to construct the profiling function $\mathcal{F}_{\rm CD}(\mathcal{S})\rightarrow\Theta\in\mathbb{R}^{M\times K}$ , where the profile $\theta_{i}$ for each model is a $k$ -dimensional vector representing its proficiency over the set of skills.
An overview of our method is shown in Figure 1.

## 2.2 Q-Matrix Construction

We use a binary Q-matrix $\mathcal{Q}\in\{0,1\}^{N\times K}$ to denote the mapping between $N$ items and $K$ skills, where each entry $\mathcal{Q}_{ij}=1$ indicates the $i$ -th item is associated with the $j$ -th skill and 0 otherwise.
Manually defining and annotating skills is challenging, costly, and difficult to scale.
Recent work shows that LLMs can automatically identify meaningful skills from problem content (Didolkar et al., 2024; He et al., 2026).
We adapt this approach to our setting, consisting of two main steps: skill labeling and skill clustering.

## Skill labeling.

For each item $j$ , we prompt GPT-4o-mini with the question stem and ask
for (i) a single primary skill and (ii) the full list of skills
required for the solution (exact prompt in Appendix D).
We use the full list rather than only the primary skill: primary-skill assignments produce Q-matrix rows
of mean row-sum $1.0$ , which under-constrains NCDM.
Full-list extraction yields a mean of $2.9$ skills per item and $13{,}276$ unique skill strings
across $9{,}523$ items.

## Skill clustering.

Because skills are extracted independently from different problems, they may contain redundancy and noise.
To obtain a more compact and coherent skill set, we cluster similar skills and merge them accordingly.
Didolkar et al. (2024) employ an LLM to perform this grouping process; however, such approaches may not scale well to a large number of skills. Therefore, we adopt an embedding-based clustering method, which is more efficient and scalable.
Each unique skill string is first encoded by the pretrained SBERT
all-mpnet-base-v2 (Reimers and Gurevych, 2019) into
 $\mathbb{R}^{768}$ .
Then, we use the hierarchical agglomerative clustering (HAC) algorithm with cosine distance and average linkage, specifying the number of final clusters as $K$ .

## Q-matrix assembly.

We set $\mathcal{Q}_{jk}=1$ iff at least one of item $j$ ’s extracted skills falls
into cluster $k$ . This multi-skill assignment reduces the fraction of
clusters with fewer than ten items from $43\%$ under primary-skill assignment to $36\%$ at

## 2.3 Neural CDM

We adopt the Neural Cognitive Diagnosis Model
(Wang et al., 2020). The probability that LLM $s$ answers item $j$ correctly
is estimated as:

 $p(\mathcal{S}_{ij}=1)\;=\;{\rm sigmoid}\!\Big(f\!\big(\,\alpha_{j}\,({\bm{\theta}}_{i}-\bm{d}_{j})\odot\bm{q}_{j}\,\big)\Big),$ 

(1)

where $\bm{\theta}_{i}\in[0,1]^{K}$ represents the learned skill mastery of model $\mathcal{M}_{i}$ , $\alpha_{j}\in[0,1]$ is the discrimination parameter of item $j$ , $\bm{d}_{j}\in[0,1]^{K}$ is its per-skill difficulty vector, and $\bm{q}_{j}\in\{0,1\}^{K}$ is the corresponding Q-matrix row.
The scalar $\alpha_{j}$ scales all skill dimensions equally. The function $f$ is a three-layer MLP with ${\rm PosLinear}$ layers. Each ${\rm PosLinear}$ layer uses non-negative weights, $\mathbf{W}^{+}=\max(\mathbf{W},0)$ .
Together with the non-decreasing sigmoid activations, this ensures that increasing any mastery component cannot decrease the predicted probability, holding all other inputs fixed.

## 2.4 Learning Item Parameters from Text

The original NCDM treats item discrimination $\alpha_{j}$ and difficulty $\bm{d}_{j}$ as model parameters learned during training, preventing predictions on unseen items.
To overcome this limitation, we follow previous context-aware approaches (Gor et al., 2024; Cui and Sachan, 2025) to use a lightweight neural network to learn item parameters based on their text features.
Specifically, for a given item $x_{j}$ , we first use a pretrained encoder to obtain its embedding $\bm{e}_{j}$ .
Then, we compute $\alpha_{j}$ and $\bm{d}_{j}$ via:

 $\alpha_{j}=\sigma\!\big(\mathbf{w}_{\alpha}^{\top}\bm{e}_{j}+b_{\alpha}\big),\qquad\bm{d}_{j}=\sigma\!\big(\mathbf{W}_{d}\,\bm{e}_{j}+{b}_{d}\big).$ 

(2)

To maintain computational efficiency, we freeze the pretrained encoder and only optimize the projection parameters $\mathbf{w}_{\alpha},\mathbf{W}_{d}$ and $b_{\alpha},{b}_{d}$ .

## 3 Evaluation of Skill Profiles

## Experiment Setup.

We train our text-conditioned NCDM on a subset of the RouterEval dataset (Huang et al., 2025), including 3,811 LLMs evaluated on 9,523 items from five benchmarks: MATH, BBH, GPQA, MuSR, and IFEval.
For the number of skills, we set $K{=}100$ as the main experimental configuration, as it achieves a better balance between interpretability and performance. We provide comparisons with other values of $K$ in Appendix F.

## 3.1 Quality of Discovered Skills

Since our evaluation is centered around skills, it is crucial to assess the quality of these LLM-discovered skills.
We consider the following three criteria:
(1) Semantic clarity, which measures whether a skill description is clear, unambiguous, and self-contained;
(2) Level of abstraction, which captures the granularity of a skill, where a good skill should be neither overly broad nor overly specific to particular questions;
(3) Diversity, which evaluates whether different skills are non-redundant and capture distinct aspects.
For the first two criteria, we adopt LLM-as-a-judge.
For the last one, we use intra-list diversity defined as averaged pair-wise dissimilarities, which is widely used in recommendation systems.

## Human validation of skill–question assignments.

Clear skill descriptions do not by themselves establish that the skills are relevant to their assigned questions. We therefore evaluate the skill–question assignments through human annotation. Three annotators, each holding an MSc in engineering, evaluated $780$ skill–question pairs covering all $100$ skills. We sampled up to $10$ questions uniformly at random from each skill’s assigned items, retaining all items for smaller clusters. Annotators were shown revised descriptive skill names and question text, and judged whether answering each question required the named skill. Majority voting accepted $652$ of $780$ assignments ( $83.6\%$ ), with an acceptance rate of $81.7\%$ when averaged equally across skills. Inter-annotator agreement was $0.715$ in mean pairwise Cohen’s kappa and $0.714$ in Krippendorff’s nominal alpha; both measures equal $1$ for perfect agreement and $0$ for agreement expected by chance. These judgments provide evidence for the semantic relevance of the sampled assignments.

## 3.2 Stability

For an evaluation method, the stability of its results is essential.
However, multidimensional latent ability models commonly suffer from non-identifiability: the $\theta$ vectors learned in repeated training runs are inconsistent, as they are affected by rotation, permutation, and random initialization.
This prevents such models from serving as a reliable and reproducible means of evaluation.
SkillEval instead ties each dimension of $\theta$ to a named skill through a fixed Q-matrix, which anchors the coordinate system across runs.

We test whether ability profiles remain consistent across retraining, and compare SkillEval with IRTNet (Chen et al., 2025), a high-dimensional neural IRT model that represents each LLM with a $d$ -dimensional latent ability vector.
We train SkillEval with five random seeds and IRTNet with different dimensionalities.
We compute Pearson correlations across learned $\mathbf{\Theta}$ across different runs in Table 2.
Averaged over dimensions and run pairs, the correlation is $0.96$ for SkillEval and $\approx 0.00$ for each IRTNet configuration.
To rule out differences that arise merely from different coordinate systems, we also compare runs after Procrustes alignment, which finds the rotation that best maps one run’s $\theta$ vectors onto another’s.
Despite this, IRTNet’s mean correlations rise only to $0.10$ – $0.43$ .
Thus, SkillEval supports more reliable and consistent evaluation of LLMs.

## CONCLUSION
SkillEval applies a Neural Cognitive Diagnostic Model to
 $3{,}811$ LLMs across $9{,}523$ items and five benchmarks, producing
interpretable mastery profiles over $K{=}100$ named skills. Unlike IRTNet’s latent dimensions, these profiles are stable across retraining: each skill’s estimates correlate at $0.96$ on average between runs.
Skill-conditioned routing reaches $\mathrm{Acc@}1{=}65.67\%$ (vs. $61.57\%$ for the strongest single LLM, $62.05\%$ for KNN, $63.08\%$ for IRTNet over three runs and $61.10\%$ for the IRT 2PL router) and matches the strongest LLM at $4{\times}$ lower inference cost. SkillEval also profiles previously unseen LLMs without retraining the shared network: $20$ adaptively chosen answers give a mean benchmark-score error comparable to $100$ randomly chosen answers. Skill profiles recover
benchmark-level scores at Pearson $r{=}0.989$ . The framework surfaces
diagnostic findings invisible to aggregate scores: differences between base and instruction-tuned models that are statistically significant after Bonferroni correction on $14/100$ skills, and overlapping skill coverage across benchmarks. An exploratory analysis in Appendix L examines asymmetric co-mastery: LLMs mastering one skill often also master another, while the reverse is less common. Testing how these patterns generalise across LLM populations is a direction for future work. Limitations are in Appendix O.
