## ABSTRACT
World models are increasingly used for planning, where a planner ranks candidate actions by returns imagined by the model. However, these models are judged mainly by how well they render frames, even though a visually faithful rollout can still assign the wrong return. To identify where this mismatch arises, we introduce a transition-level diagnostic that replaces imagined transitions with real ones and measures the reduction in return error against a budget-matched random control. Our analysis yields two findings. (1) Event transitions, the few steps where a reward is earned or an episode ends, are rendered as well as other steps (median pixel-error ratio 0.85), yet restoring them removes a median of 70% of the return error. In contrast, restoring transitions with the largest MSE, SSIM or LPIPS error removes less than a random choice. Across the 44 Atari-100k model--collection pairs that pass our reliability checks, including three released families, event patches outperform random patches in 39 (sign test p=1.4 x 10^{-7}), with a median gain of +44 percentage points. (2) The remaining error is structured: a complementary patch separates errors at true events from those elsewhere, while an eight-step timing tolerance recovers few events missed by our deterministic models. This structure also guides repair: a rule recorded before four repair outcomes were known predicts when a diffusion model repairs these failures. Event patches improve plan ranking, and the same concentration appears on control tasks with rare reward events.

## 1 Introduction

World models let an agent imagine the consequences of an action before taking
it [18]. A planner rolls candidate action sequences forward inside the model and
acts on the ordering of their imagined
returns [11, 20, 48, 23, 22, 2, 36]. Released pixel world models
support this pipeline in Atari, continuous control, and
manipulation [12, 60, 52], and their progress is mainly
measured by how faithfully they render the
future [59, 65, 53].

Rendering quality, however, is only loosely tied to what a planner needs. A return often hinges on
a few transitions that carry a reward or end an episode, so a model can render a rollout well yet
misprice it by missing a single paddle contact. Model-level studies expose this mismatch:
rankings by visual quality can disagree with rankings by task
success [33, 64], and whole-model oracle substitutions find that
average prediction accuracy does not consistently explain planning
performance [41, 49, 7]. Yet neither these
analyses nor compounding-error bounds [26] reveal where that error occurs: is it
spread across all sixty steps of a rollout, or concentrated in only a few? We therefore ask:

Where inside an imagined rollout does the error that changes a planner’s decision occur?

To answer this question, we introduce a transition-level substitution diagnostic
(Fig. 1). Each imagined rollout is paired with a real rollout that starts from
the same context and follows the same recorded actions, so the two differ only in who drew the
frames. A frozen, memoryless detector, trained once per game, reads reward and termination from
each pair of consecutive frames; replacing one imagined pair with the real one therefore changes
the return only at that step. We patch the pairs at true events, the same number of random pairs,
all non-event pairs, or every pair. These four patches isolate the targeting effect, its
budget-matched control, the error away from events, and an all-real reference.

Our analysis yields two findings. First, return error concentrates at events that do not
look wrong. In Fig. 1D, restoring three transitions around a Seaquest reward
removes almost all return error; three random ones remove little. Across 44 reliable
Atari model–collection pairs, event patches beat random patches in 39 by a median of
+44 points, and the advantage appears within a few patches (Fig. 2).
Event frames are rendered as well as others (median pixel-error ratio 0.85), yet
restoring them removes a median of 70% of the return error; the same pattern holds on
eighteen games added after our predictions were recorded. Second, the remaining error
is structured rather than merely mistimed. Complementary patches separate errors at true events
from errors elsewhere, and timing-tolerant recall shows that temporal offset explains little
of the events our deterministic models miss. This structure also predicts where a diffusion
model helps; event patches improve plan ranking and carry over to control tasks with rare reward events.

We summarise our contributions as follows:

• 

We introduce a per-transition substitution diagnostic with a budget-matched random control.
It treats the world model as a black box, and we apply it to three released model families on all 26 Atari-100k games.

• 

We show, for the first time on released pixel world models, that return error concentrates
at reward and termination transitions, also under each model’s own reward head and without the
score display, and that a complementary patch separates errors at true events from other errors.

• 

We show that a temporal offset explains little of the events missed by deterministic
models, predict all four repair outcomes with a rule recorded in advance, and show that event
patches improve plan ranking in every counted pair and carry over to control tasks with rare reward events.

Pixel world models support prediction and control in
games [40, 10, 29, 21, 46, 66, 36, 37, 2, 12]
and interactive video
simulators [62, 6, 54, 60]. Yet visual fidelity can
diverge from physical correctness [38] and task
success [33, 64, 58]; the same disconnect appears for
training likelihood [31, 13, 16], synthetic
training data [1], and token pruning [57].
Concurrent work weights error by decision-relevant state dimensions [56], while
DIAMOND shows that visual details matter [2]. We instead locate where
decision-relevant error occurs inside a rollout.

Oracle substitution localises such failures. Cloning Deterministic Worlds [61]
substitutes true states for learned representations, while whole-model oracle interventions relate
accuracy to planning [41, 49, 7]; a concurrent
diagnostic uses a kinematic null [47]. Closest to ours, counterfactual
debugging [32] assigns Shapley credit over time steps to a policy’s
sim-to-real gap under injected faults, and agent explanations identify steps that decide a
return [17, 8, 3]. We instead operate directly on
released world-model rollouts, replacing individual transition pairs under a budget-matched
random control. This brings perturbation-based
attribution [63, 14, 44, 25],
used and tested on Atari agents [15, 4], from pixels
to time steps.

Other work improves prediction with multi-step
training [50, 55], goal-aware
objectives [39], keyframe
targets [27, 43], region- and event-aware
objectives [34, 42], causal rollout structure [67], and
architecture-level probing [28]. Conditional-mean effects are also
studied in video prediction [35] and perception and driving
models [45]. We test which explanation accounts for missed events using event
survival, a diffusion model, and the same network trained deterministically.

## Return from a Predicted Trajectory.

A probe is a real context with fixed actions $a_{1:H}$ (Fig. 1A); from it, a model produces imagined observations
 $\hat{o}_{1:H}$ . A frozen detector, shared by all world models of a game, reads each transition pair and its action as a reward sign and
a termination flag, $(\hat{r}_{t},\hat{d}_{t})=D(\hat{o}_{t},\hat{o}_{t+1},a_{t})$ for $t<H$ ; the last frame
has no successor, so $\hat{r}_{H}=\hat{d}_{H}=0$ . The emulator, replaying the same actions, supplies $r_{1:H}$ and $d_{1:H}$ ,
and both returns stop at the first termination. Rewards enter through their sign, as in
Atari-100k training, so all games share one scale:

 $\hat{G}=\sum_{t=1}^{H}\gamma^{t-1}\operatorname{sgn}(\hat{r}_{t})\prod_{j<t}(1-\hat{d}_{j}),\quad E=\mathbb{E}\lvert\hat{G}-G\rvert,$ 

(1)

where $G$ is computed in the same way from $r$ and $d$ , and $\mathbb{E}$ averages over probes.
Atari uses $H=60$ and $\gamma=0.99$ .

## Substitutions and Their Controls.

For channel $c$ (observation $o$ , reward $r$ or termination $d$ ) and a binary mask $m$ , let $\hat{G}^{c,m}$ be the return after
substituting the selected real information (Fig. 1). Observation patches replace both frames of
the selected transition before detection, so no pair mixes real and generated frames; unselected pairs keep their predictions.
Reward and termination interventions replace $\hat{r}$ or $\hat{d}$ .
We report the fractional reduction in mean absolute return error:

 $R(c,m)=1-\frac{\mathbb{E}[|\hat{G}^{c,m}-G|]}{\mathbb{E}[|\hat{G}-G|]}.$ 

(2)

The all-frame value
 $R(o,\mathbf{1})$ measures performance when the detector sees only real transition pairs.

The event mask starts from nonzero real reward or termination and is dilated by one step, i.e., the
transitions just before and after are also selected, to cover delays in the visual markers. We report its realised coverage
 $q=\penalty\mathbb{E}[H^{-1}\sum_{t}m_{t}^{\rm ev}]$ , which includes dilation. The random mask selects the same number of steps in each
rollout.
The targeting advantage is

 $L=R(o,m^{\rm ev})-R(o,m^{\rm rnd}).$ 

(3)

The complementary mask $\bar{m}^{\rm ev}$ measures errors away from the selected events, and
its contrast with the event patch classifies the failure pattern of each model.

## 4 Localising the Return Error

We localise the return error with one frozen, memoryless detector per game, shared by every
world model of that game. A random patch also hits true events, and more of them as coverage
grows, so the lift of Eq. (3) credits the event patch only with what it adds beyond chance.

Figure 2 widens the event neighbourhood step by step and plots the lift against the
resulting coverage. In 8 of 9 sweeps over three games and three released
families, the event curve stays well above the random curve. For DIAMOND on Freeway, patching
2.8 of sixty steps removes 69% of the error, against
 $-4{}$ % for random patches and 86% when every frame is real; on Pong,
2.1 steps remove 43% against 5%. The sweep also exposes a
timing effect: without dilation the Freeway event patch is negative, consistent with the reward
digit appearing after the transition that earns it, so we treat the neighbourhood as part of the
measurement.

The sweep also shows why the random control is needed. For DIAMOND and Simulus on Seaquest, both
patches remove more error as coverage grows while the lift stays flat, so the event-patch
reduction alone would overstate the targeting effect. Table 1 reports every game at
a one-step neighbourhood, and Fig. 3 shows events beyond Atari.

Localisation shows where the return error lies, not why. We ask why imagined events are missed
and whether another model class draws them.

## 5.1 Absent or Mistimed Events

A detector can miss an event in imagined frames for two reasons: the model draws it at a
neighbouring step, or it does not draw it in a form the detector reads. The two predict different
curves. If events are only mistimed, recall should rise with the alignment tolerance faster than
for a displaced-prediction null; if they are not drawn readably, recall should stay low at every
tolerance.

## 5.2 A Rule Recorded Before the Outcomes

If events are not drawn readably, a model that draws them should reduce the return error, most
where the baseline misses most events. As a repair, we replace our deterministic MSE predictor
with a diffusion model trained on the same data [24, 30, 2],
which samples each next observation instead of regressing it (“sampling” in figures and tables).
A sampled future can differ from the realised one, so we evaluate event recall, return error, and
plan ranking.

Before observing the remaining outcomes, we pre-specified this rule: a baseline event recall at
 $\tau=0$ below $0.50$ predicts a return-error reduction larger than the declared floor of that
game, and a recall at or above $0.50$ predicts no such reduction. The threshold is a heuristic for
the headroom left by missing events; floors and failure conditions were fixed at the same stage.
Freeway had already been scored, so the prospective score covers Pong and the three unrun sampling
arms. The MSE baseline gets more training, 30k updates against 8k, because at 8k updates it
detects no return on Freeway and Pong; data, sequence length, batch size, learning rate, and seeds
match (supplement).
