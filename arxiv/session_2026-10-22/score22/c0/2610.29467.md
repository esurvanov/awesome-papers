## ABSTRACT
Long-horizon dialogue agents need to keep user memories stable enough for personalization while adapting when the user genuinely changes. Existing memory systems often append every observation or overwrite old entries by heuristic rules, which makes transient noise hard to distinguish from real belief drift. We introduce PreCoMem, a memory consolidation framework inspired by predictive coding that represents memory as confidence-weighted beliefs about the user's state. Its core signal, Effective Surprisal, combines semantic deviation and contradiction evidence, then downweights this signal when retrieval is diffuse and unreliable. According to effective surprisal, a two-threshold gate maps each turn to one of three deterministic updates: MAINTAIN reinforces supported beliefs, PROFILE stores ambiguous cues as low-confidence hypotheses, and CORRECT softly decays reliably contradicted facts. The PROFILE stage acts as an explicit waiting room, preventing premature commitment to noisy evidence. Experiments on LoCoMo, LongMemEval-S, and PersonaMem-v2 show consistent state-of-the-art accuracy; our new DiMoBench confirms that PreCoMem adapts to non-stationary belief drift without over-reacting to noise. The code is available at https://github.com/ZhongWishing/PreCoMem.

## 1 Introduction

Figure 1: Memory evolution case study (coffee $\rightarrow$ tea). PreCoMem autonomously manages the lifecycle of facts and hypotheses, achieving a stable transition between conflicting belief states without manual intervention.

Large Language Models (LLMs) are moving from stateless responders toward long-term partners that interact with the user over hundreds or thousands of turns [32, 39, 44]. Such partners need more than stored transcripts; they require a user model to sustain personalized interaction [51, 15].
To formalize the core units of this user model, we define a belief as a compact, actionable claim about the user’s preferences, goals, or life context, paired with a confidence weight that can be reinforced or revised over time.
This user model underpins both agent personalization and behavioral self-correction, thereby redefining the role of long-term memory: rather than merely serving as simple context extension [30, 41], long-term memory enables the agent to maintain consistent behavior across sessions.

The harder question is not whether information can be stored, but how it should be consolidated and revised. A practical memory consolidation mechanism must decide which observations to retain, how strongly to trust them, and when to maintain, revise, or correct stored items without explicit supervision. We refer to this as the memory stability–plasticity problem: the agent should preserve stable user traits while remaining plastic enough to adapt when those traits change [6]. Long-horizon interaction makes the problem hard for three coupled reasons. First, most turns carry little signal, while a small fraction may contain cues indicative of more persistent user states. Second, user preferences and life facts evolve over time [5], so the system must adapt under non-stationarity and belief drift [49, 7]. Third, corrective feedback is rarely explicit [14], and noisy retrieval over long contexts further blurs the picture [48, 25, 4, 43]. Therefore, the brittle memory update mechanism causes two opposite failures: premature correction from noise, or persistent over-reliance on outdated memories, which we call old-memory pull, a phenomenon related to loss of plasticity and retrieval interference in continual adaptation systems [6, 11].

Recent memory systems have made impressive progress on retrieval and storage organization. Hierarchical and OS-style stores [30, 23, 10], structured indices with timestamps or topic shards [34, 40, 21, 38], and agentic retrievers [45, 46] all sharpen what the system can recall. However, the question of when to update is still often handled by recency overwriting, fixed-threshold importance, or one-shot append rules [51, 2]. These triggers cannot reliably separate persistent drift from transient noise [11], so they collapse the stability–plasticity trade-off precisely where long-horizon dialogue stresses it most. A fuller literature discussion is provided in Appendix Appendix A.

We draw inspiration from predictive coding, which posits that learning is driven by mismatch between expectation and reality, i.e., prediction error [8, 3]. In information theory the same quantity is called surprisal [19, 29]. We use this view as a design principle for the update path rather than as a claim that dialogue memory is a fully specified probabilistic model. The resulting criterion is simple: events consistent with current memory should be reinforced, while surprising events may require learning or correction [33, 36]. Crucially, surprisal must be paired with a measure of retrieval reliability, so that update decisions stay conservative when recall itself is uncertain or noisy [18, 48].

Building on this view, we propose PreCoMem (Predictive Cognitive Memory), a self-evolving long-term memory framework for conversational LLM agents. PreCoMem operates in two active phases over a shared memory store. In memory leveraging, it retrieves confidence-weighted beliefs to condition response generation. In memory evolution, it compares new observations with recalled evidence and computes Effective Surprisal $S_{\mathrm{eff}}$ , a reliability-adjusted mismatch score. A two-threshold gate then routes each update to MAINTAIN, PROFILE, or CORRECT, corresponding to consistent, ambiguous, and reliably contradictory evidence. Figure 1 illustrates this loop on a coffee-to-tea preference shift, where a low-confidence hypothesis is gradually promoted to a fact while the contradicted old fact is softly decayed.

In summary, we (i) propose PreCoMem, a memory consolidation framework that casts long-term memory as a dynamic prediction of the user’s state; (ii) introduce a reliability-weighted surprisal signal that gates each update through MAINTAIN, PROFILE, or CORRECT; and (iii) evaluate on LoCoMo, LongMemEval-S, PersonaMem-v2, and DiMoBench/DiMoBench-XL, controlled write-path stress tests with gradual drift and decoy retrieval. PreCoMem outperforms the strongest contemporary baselines while keeping effective memory stable across 1050 turns.

## 2 PreCoMem

## 2.1 Framework overview

Figure 2: The PreCoMem framework. Two active phases operate over a shared memory store. Phase 1, Memory Leveraging: a confidence-modulated retrieval score combines semantic, lexical, and topic signals to select Top- $K$ beliefs $\mathcal{C}_{t}$ for response generation. Phase 2, Memory Evolution: the effective surprisal $S_{\mathrm{eff}}$ and a two-threshold gate route each turn to MAINTAIN, PROFILE, or CORRECT, illustrated by representative low/medium/high- $S_{\mathrm{eff}}$ turns. Memory Store: an editable Belief Store $\mathcal{B}$ of FACT/HYPO nodes with confidence weights, linked by provenance to an immutable Episodic Cache $\mathcal{E}$ under a shared topic index; belief items are updated independently, and the drawn links are provenance pointers and topic groupings (Appendix Section C.11).

As illustrated in Figure 2, PreCoMem operates as a closed loop of two active phases around a shared memory store. Memory Leveraging retrieves confidence-weighted beliefs and uses them to condition response generation. Memory Evolution then revises the memory state in light of the new interaction: it computes Effective Surprisal $S_{\mathrm{eff}}$ against recalled evidence, and routes the update to one of three deterministic operators—MAINTAIN, PROFILE, or CORRECT. This read–write loop differs from prior memory systems in two ways. First, every belief item carries a continuous confidence weight $w_{t}(m)\!\in\![0,1]$ that is reinforced or softly decayed by the operators, instead of relying on discrete commit decisions such as Add/Ignore/Update in O-Mem [40] or binary expiry intervals in EverMemOS [10]. Second, PROFILE buffers ambiguous observations as low-confidence hypotheses, letting weak evidence accumulate across turns before it is committed or discarded.

In implementation, each operator pairs a closed-form update rule with a fixed-prompt LLM sub-agent. The sub-agent only identifies which items are relevant and emits one bounded scalar, such as evidence_strength, severity, or initial_confidence. The deterministic layer then plugs these scalars into Equations 7, 8 and 10. Thus the LLM proposes local magnitudes, while the gate, confidence bounds, and closed-form $w$ updates control when and how memory changes accumulate. Algorithm 1 (Appendix Section B.4) gives the per-turn pipeline.

## 2.2 Memory primitives

Dialogue and memory state. At turn $t=1,2,\ldots$ , the user input is $u_{t}$ , the agent response is $y_{t}$ , and $Q_{t-1}$ is a rolling working-memory window. Long-term memory is $\mathcal{M}_{t}=(\mathcal{B}_{t},\mathcal{E}_{t},\mathcal{T}_{t})$ . The belief store $\mathcal{B}_{t}$ contains editable facts and hypotheses with confidence weights. The episodic cache $\mathcal{E}_{t}$ stores immutable raw dialogue traces with source pointers. The optional topic table $\mathcal{T}_{t}$ is only a retrieval prior. This keeps beliefs editable and evidence traceable.

Items, confidence, and hypothesis lifecycle. A memory item $m$ has content $c(m)$ , type $\tau(m)\in\{\texttt{FACT},\texttt{HYPOTHESIS}\}$ , and retrieval metadata such as embeddings, topic labels, entities, timestamps, and source pointers into $\mathcal{E}_{t}$ . For belief items, $w_{t}(m)\in[0,1]$ is an operational support score. Episodic traces are fixed at $w_{t}(e)\equiv 1$ and used only as provenance, not in confidence-weighted Top- $K$ ranking. A HYPOTHESIS is a provisional belief: it is reinforced under supporting evidence, decayed when evidence stays absent, and promoted to FACT when confidence crosses $\tau_{\mathrm{promote}}$ . Type transitions are one-way. Contradicted facts are softly decayed by CORRECT (Section 2.4) rather than demoted, yielding low-confidence “deprecated” facts that confidence-weighted retrieval naturally deprioritizes. Appendix Section C.7 confirms this retention is accuracy-neutral.

## 2.3 Memory leveraging: evidence recall and response generation

In Memory Leveraging, PreCoMem recalls a compact evidence set from long-term memory and leverages it to generate the current response.

Evidence recall. Given $u_{t}$ and short-term context $Q_{t-1}$ , PreCoMem ranks candidates in $\mathcal{B}_{t}$ with a confidence-modulated score. The score combines three retrieval signals: semantic similarity, lexical overlap (BM25), and topic relevance. Omitting $Q_{t-1}$ in the notation,

 $s(u_{t},m)=w_{t}(m)\sum_{j=1}^{3}\alpha_{j}s_{j}(u_{t},m),\quad m\in\mathcal{B}_{t},$ 

(1)

where $(s_{1},s_{2},s_{3})=(s_{\mathrm{sem}},s_{\mathrm{fact}},s_{\mathrm{topic}})$ and $\boldsymbol{\alpha}=(\alpha_{1},\alpha_{2},\alpha_{3})^{\top}$ is a convex weight vector. The multiplier $w_{t}(m)$ biases retrieval toward high-confidence items. The Top- $K$ belief items form $\mathcal{C}_{t}=\{m_{i}\}_{i=1}^{K}$ with retrieval scores $\mathbf{s}_{t}$ . Linked episodic traces from $\mathcal{E}_{t}$ are appended as provenance context, but they do not participate in Top- $K$ ranking. The same scores $\mathbf{s}_{t}$ are retained for the reliability estimate in Section 2.4.

Evidence-conditioned response. The recalled evidence texts $\{c(m)\mid m\in\mathcal{C}_{t}\}$ , together with $u_{t}$ and the short-term window $Q_{t-1}$ , condition the response model:

 $y_{t}=\texttt{Respond}(u_{t},Q_{t-1},\mathcal{C}_{t}).$ 

(2)

We reuse the same recall outputs $(\mathcal{C}_{t},\mathbf{s}_{t})$ to perform memory evolution in Section 2.4.

## 2.4 Memory evolution: regime-gated belief updating

Given the recall outputs $(\mathcal{C}_{t},\mathbf{s}_{t})$ and the new interaction $(u_{t},y_{t})$ ,
PreCoMem computes a prediction-error signal adjusted by retrieval reliability,
and applies a regime-gated update to the belief store.
It also writes the new turn back into the episodic cache for future provenance and recall.

Retrieval reliability. Surprisal computed against recalled evidence can be misleading when recall is uncertain, so we derive a reliability coefficient from the entropy of retrieval scores. Let $\mathbf{s}_{t}=\{s_{i}\}_{i=1}^{|\mathcal{C}_{t}|}$ denote the Top- $K$ retrieval scores returned with $\mathcal{C}_{t}$ , and let $\hat{s}_{i}=(s_{i}+\epsilon)/\sum_{j}(s_{j}+\epsilon)$ be the smoothed normalization. We define the normalized entropy $H_{t}$ and the reliability coefficient $\rho_{t}$ as

 $H_{t}=\frac{-\sum_{i}\hat{s}_{i}\log\hat{s}_{i}}{\log\max\{|\mathcal{C}_{t}|,2\}}\in[0,1],\qquad\rho_{t}=1-H_{t}.$ 

(3)

Because $H_{t}$ is minimized when one item dominates and maximized under near-uniform scores, $\rho_{t}$ measures score concentration as a proxy for evidence precision. Diffuse recall (small $\rho_{t}$ ) downweights deviation signals to avoid over-updating; concentrated recall (large $\rho_{t}$ ) preserves them for correction. Thus the gate becomes aggressive only when recall is concentrated and the raw contradiction/deviation signal is large. Since $\rho_{t}$ enters only multiplicatively, it can defer an update but never trigger one on its own; whether CORRECT fires still depends on the contradiction term below, and Appendix Section C.8 verifies empirically that $\rho_{t}$ tracks evidence precision. The constant $\epsilon>0$ ensures numerical stability.

Raw surprisal proxy. We define:

 $S_{\mathrm{raw}}(u_{t})=\lambda\,d_{\mathrm{sem}}(u_{t},\mathcal{C}_{t})+(1-\lambda)\,d_{\mathrm{conf}}(u_{t},\mathcal{C}_{t}),$ 

(4)

where $\lambda\in(0,1)$ , $d_{\mathrm{sem}}$ is the normalized semantic deviation between $u_{t}$ and score-weighted recalled evidence, and $d_{\mathrm{conf}}$ is a verifier-based contradiction score quantifying how strongly $u_{t}$ conflicts with recalled beliefs (see Appendix Section B.2).

Effective surprisal. We define:

 $S_{\mathrm{eff}}(u_{t})=\rho_{t}\,S_{\mathrm{raw}}(u_{t}),$ 

(5)

which corresponds to a precision-weighted prediction error that becomes conservative when recall is unreliable.
We use $x_{t}:=S_{\mathrm{eff}}(u_{t})$ as the scalar gate score below. Appendix Section B.1 gives an optimization view that interprets $x_{t}$ as a Monte Carlo surrogate of a long-horizon predictive objective.

Regime-gated evolution. Given two ordered thresholds $\theta_{\mathrm{low}}<\theta_{\mathrm{high}}$ , PreCoMem maps the gate score $x_{t}$ into three regimes:

 $a_{t}=\begin{cases}\texttt{MAINTAIN},&x_{t}\leq\theta_{\mathrm{low}}\\
\texttt{PROFILE},&\theta_{\mathrm{low}}<x_{t}\leq\theta_{\mathrm{high}}\\
\texttt{CORRECT},&x_{t}>\theta_{\mathrm{high}}.\end{cases}$ 

(6)

Two-threshold gate. Low, medium, and high $x_{t}$ correspond to consistent, ambiguous, and reliably contradictory evidence. PROFILE handles the middle regime that a binary maintain/correct rule must either ignore or overwrite. We fix $(\theta_{\mathrm{low}},\theta_{\mathrm{high}})=(0.2,0.6)$ throughout the main experiments to keep behavior controllable and the comparison reproducible across benchmarks; the cost-sensitive break-even derivation, operator ablations, threshold sensitivity, and dynamic-threshold variant are in Appendix Sections B.3, C.4, C.5 and C.5.

## MAINTAIN (reinforcement).

When surprisal is low, PreCoMem strengthens supported beliefs in $\mathcal{C}_{t}$ via:

 $w_{t+1}(m)=w_{t}(m)+\eta_{t}(m)\,(1-w_{t}(m)),\quad m\in\mathcal{C}_{t}\cap\mathcal{B}_{t},$ 

(7)

where $\eta_{t}(m)\in(0,1]$ is the per-item evidence_strength returned by the Maintain-Agent; weakly supported items barely move, while strongly supported ones are pulled toward $1$ . The optimization view in Appendix Section B.3 treats $\eta_{t}(m)$ as a scalar step size.

## CONCLUSION
PreCoMem treats long-horizon conversational memory not as a transcript to be stored, but as confidence-weighted beliefs about the user’s state that must be continually checked. A reliability-adjusted surprisal signal routes each turn into MAINTAIN (reinforce supported beliefs), PROFILE (buffer ambiguous cues as low-confidence hypotheses), or CORRECT (softly decay contradicted facts). The PROFILE waiting room is the central design choice: it lets evidence accumulate before commitment, so the agent stays consistent under noise without freezing under genuine drift. Across LoCoMo, LongMemEval-S, PersonaMem-v2, and DiMoBench, this discipline yields the best overall accuracy while keeping memory bounded over a thousand turns; qualitative case studies (Appendix Section C.11) show calibrated recommendations beyond retrieval-only baselines. We see continuous confidence and explicit hypothesis lifecycles as a useful baseline for long-term memory systems, where what to commit matters as much as what to recall. Our evaluation covers English dialogue benchmarks; other languages and modalities are left for future work.
