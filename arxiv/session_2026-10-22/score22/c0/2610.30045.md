## ABSTRACT
Decision models map stated rules and observed states to discrete answers. Aggregate accuracy leaves unresolved which rule and information changes guide those answers. We connect controlled input changes to transfer, joint reliability, and directed information use through executable arithmetic rules. Semantic rule separation and crossed rule and state tests make transfer and joint success separately measurable. We compare equivalent wordings, calibrate joint correctness through marginal-preserving reassociation, and alter tables to define alternative answer targets. Adaptation gains increase with nearest-source answer agreement; fully conflicting quartets yield small pooled gains and different gain signs across source splits. Equivalent rewrites have opposing task-level effects, linking transfer gains to rule presentation. Joint-score departures depend on which rule and state associations the reference preserves. A decision service changes answers more across equivalent wordings than across identical-text repeats and usually follows the answer targets implied by altered table values or mappings.

## 1 Introduction

“A difference which makes a difference”

— Gregory Bateson, Form, Substance and Difference (1970)

Decision models turn stated rules and observed states into labels, ratings, or selected records. Accuracy measures agreement with the prescribed answer, but equal scores can conceal different responses to the inputs. In an archived routing example, two models answer half the questions correctly. One ignores both rule and state changes; the other responds to states alone. Valid option selection can also coexist with answer-symbol binding errors (Balepur et al., 2025; Xue et al., 2024). Understanding success therefore requires testing which input changes guide each rule-based decision.

Research Question

How can we determine which rule and information changes guide a decision model's answers?

A gain on unfamiliar rules can still depend on familiar wording. Low all-four correctness can follow from individual errors, so its magnitude alone does not establish unusual joint behavior. Better performance with an external table also leaves open whether its values and mappings direct the answers. Behavioral tests and contrast sets motivate controlled input changes (Ribeiro et al., 2020; Gardner et al., 2020); rule-following benchmarks examine inference, counterfactual rules, and regulations (Parmar et al., 2024; Sun et al., 2025; Zhou et al., 2025). We connect these controls to the specific ambiguities in interpreting decision accuracy.

Executable arithmetic rules make intended answers and controlled changes checkable. We separate rules by finite-domain behavior to evaluate transfer to semantic components excluded from training. Equivalent rewrites hold those behaviors fixed while changing presentation. Crossing rules and states tests responses to each factor. Marginal-preserving reassociation calibrates all-four correctness against the observed individual predictions. More restrictive references retain rule or state associations to identify what drives departures from that calibration. Finally, changing table values or mappings defines alternative answer targets. Transitions toward those targets reveal directed information use beyond an arbitrary answer change. Figure 1 links input changes to behavioral diagnostics.

Low-rank adaptation (LoRA) improves accuracy on reserved rules, with larger gains at higher nearest-source answer agreement. Fully conflicting quartets have low joint success and opposite gain signs across source splits. Equivalent wording increases the adaptation advantage on binary decisions and reduces it on the other tasks. Joint-score departures further depend on the rule and state associations retained by the calibration reference. The decision service Jev changes answers more across equivalent wordings than across identical-text repeats. It benefits from complete value tables and follows the alternative targets implied by altered values and mappings. These diagnostics distinguish conflict-conditioned transfer, joint reliability, and directed information use in model decisions.

• 

We establish an oracle-checked evaluation that uses semantic rule separation and paired input changes to distinguish transfer, wording sensitivity, and responses to rules and states.

• 

We show that transfer gains depend on source-answer agreement and the source split under complete conflict. Joint-score departures depend on the associations retained by different marginal-preserving calibration references.

• 

We identify directed use of external values through paired answer transitions under value and mapping interventions, complementing the evidence from aggregate accuracy gains.

## 2 Related Work

## Behavioral evaluation and explicit rules.

Behavioral evaluation tests whether predictions respond correctly to controlled input changes. CheckList and contrast sets target capabilities through local perturbations (Ribeiro et al., 2020; Gardner et al., 2020). Metric rankings also depend on the evaluation context (Deviyani and Diaz, 2025). RuleTaker and ProofWriter evaluate inference from stated facts and rules (Clark et al., 2020; Tafjord et al., 2021). LogicBench spans logical systems; RuleArena separates rule selection from application in regulations (Parmar et al., 2024; Zhou et al., 2025). RuleBench and IRFT extend inferential rule-following evaluation and training (Sun et al., 2025). These designs motivate testing which inputs guide decisions. Our executable grammar combines finite-domain semantic separation with crossed rule and state changes, linking success to responses along each input axis. Appendix Table 28 compares these paired evaluation designs.

## Generalization, wording, and answer interfaces.

Generalization benchmarks vary combinations, presentations, and answer interfaces. CFQ and COGS test composition; Ordered CommonGen tests requested concept order (Keysers et al., 2020; Kim and Linzen, 2020; Sakai et al., 2025). Prompt-format and answer-symbol binding studies document interface effects (Voronov et al., 2024; Xue et al., 2024). LoRA supports adaptation tests (Hu et al., 2022). Cacheable-model studies test rule following with independently encoded inputs (Rajput et al., 2026). Choice2Seq measures correctness retained from complete-answer selection to sequential construction on matched problems (Lai et al., 2026). These studies motivate paired evaluations of generalization and presentation sensitivity. Our semantic rule separation and equivalent rewrites measure how adaptation to unfamiliar rule behavior changes across presentations of identical questions with fixed model weights and intended answers.

## Information use and internal mechanisms.

Information-use studies examine how context and representations influence decisions. Performance depends on where relevant context appears (Liu et al., 2024). Probing separates recoverable information from information used to answer (Hewitt and Liang, 2019; Belinkov, 2022). Causal abstraction and interchange-intervention training connect representations to high-level variables (Geiger et al., 2021; Geiger et al., 2022). Logit inspection and attention modification examine factual recall under contextual counterfactuals (Ortu et al., 2024). Accuracy gains from supplied values leave their influence on individual answers unresolved. We alter table values and mappings to define alternative targets. Paired transitions toward those targets test directed information use. Source-selected donor replacements separately test whether recovered rule-value information influences the final selected answer.

Takeaway

Choose input interventions that distinguish the behavioral properties behind a score. Separate evidence of transfer, responsiveness, and information use when designing each evaluation.

## 3 Controlled Rule–State Evaluation

## 3.1 States, Rules, and Decisions

A decision instance is $(s,r,t,O)$ : a state $s$ , an explicitly specified rule $r$ , a task family $t$ , and an ordered option set $O$ of size $K$ . A programmatic oracle returns the semantic answer $y=g_{t}(r,s)$ and its index in $O$ . A model predicts an option index. The semantic answers align option permutations.

Each record has three integer fields $(x,y,z)\in\{-12,\ldots,12\}^{3}$ . Rules follow

 $f_{r}(x,y,z)=o_{0}\bigl(o_{1}(x,y),o_{2}(y,z)\bigr),$ 

(1)

where each operator belongs to $\{+,-,\times,\min,\max\}$ . Eligible rules depend on all three fields and retain the same three-operator, depth-two structure. Binary decisions test whether $f_{r}>0$ . Ordinal ratings count how many prescribed thresholds the score strictly exceeds, so equality remains in the lower category. Minimum routing selects the record with the lowest rule value. Maximum selection selects the record with the highest value. Record identifiers resolve ties. The option counts are 2 for binary decisions, 3/5/7 for ratings, and 2/4/8 for routing and selection.

## 3.2 Semantic Separation and State Sampling

Syntactically different expressions can implement the same decision. We compare numeric, sign, rating, and ranking signatures over the finite record domain, including field permutations. Matching any signature creates an edge between rules. Connected components conservatively keep linked rules in one pool, even when the link is transitive rather than a direct match. The separation covers executable behavior on all records in the enumerated domain.

Replication excludes historically exposed components, then assigns disjoint source and development pools by root-operator quotas and rule characteristics. Reserved components support evaluation of fixed models. Natural sampling draws complete states before labeling. Previously used complete states are excluded across roles, while individual records may recur in different multi-record states. Appendix Algorithm 1 summarizes the construction. Appendix A.4 specifies the exact eligibility checks, allocation quotas, and constraints used to construct the paired diagnostic evaluation inputs.

## 4 Behavioral Transfer and Information Use

Three paired diagnostics address the central question by testing transfer, joint correctness, and directed use of the supplied external information.

Key Findings

Conflict-conditioned transfer: Gains increase with nearest-source answer agreement. Fully conflicting quartets have low pooled joint success and opposite gain signs across source splits. Equivalent wording changes task-level adaptation gains with the same fixed model weights.
Joint reliability: Pooled QAcc lies within the primary reference ranges. Maximum-selection departures shrink when calibration preserves ordered rule pairs. Joint-score interpretation depends on the associations retained in the chosen marginal-preserving reassociation reference.
Directed information use: Jev benefits from correct tables and switches from correct answers to altered-table targets. Paired value and mapping changes distinguish directed information use from an arbitrary response change under paired original and altered-table conditions.

## LIMITATIONS SECTION
The findings concern the tested rule families and evaluation conditions. 
The core grammar uses fixed-depth arithmetic rules on three bounded integer fields. Semantic separation is established within this finite domain. Boolean and finite-state extensions test additional rule formats rather than broad natural-language policy coverage. Fully conflicting cohorts contain 39 and 32 quartet memberships with different task coverage. Their opposing gains describe source-dependent transfer within the observed task coverage under complete conflict.

LoRA–readout comparisons estimate outcomes of the selected training procedures, because independent source-audit competence remains unmatched. The larger-model comparison also changes system identity, so the observed effects cannot be attributed to parameter count alone.

QAcc describes joint success on the constructed rule–state quartets. Calibration departures concern the associations removed by each reassociation reference. Small or constant-prediction strata restrict the available reassociations. Multi-record second states use swapped winning-record fields, so the state-vector reference does not establish reliability under independently sampled pairs of input states.

Wording results compare the original rendering with two equivalent templates. Jev’s adjacent repeats estimate variability within the observed service window, rather than performance across service versions or observation periods. Table interventions establish directed use of supplied information in answers; they do not identify an internal decision mechanism. Model comparisons concern these controlled diagnostics, rather than comparative detection rates across existing behavioral tests.

## CONCLUSION
We asked which input differences guide decision models’ answers. Controlled tests distinguish conflict-conditioned transfer, all-four reliability, and directed information use. Adaptation gains increase with nearest-source answer agreement, while complete conflict yields opposite gain signs across source splits and low pooled QAcc. Equivalent wording changes task-level gains, and calibration conclusions depend on the associations retained by the reference. Paired value and mapping interventions identify directed use of supplied information. Evaluation and method design should distinguish source-consistent success from correct decisions under conflict and preserve correct answers across equivalent wording. Report joint success with explicitly specified prediction-reassociation calibration conditions. Method comparisons should report attained source competence alongside target scores. Joint reliability remains a design objective even when individual decision accuracy improves under unfamiliar rules or supplied information.
