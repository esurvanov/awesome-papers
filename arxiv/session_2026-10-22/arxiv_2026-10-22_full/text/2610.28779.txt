## Second Thoughts: Exploring and Planning through Comparative Imagination in World Models

Hieu Tran

Email: hieutran@umass.edu

Hong Yu

Affiliation: University of Massachusetts Amherst University of Massachusetts Lowell

Abstract

World models let agents compare imagined outcomes before acting, but an agent
must still decide which alternatives to explore and when a proposed plan should
replace its learned policy. We introduce SDI(Sibling Disagreement in Imagination), which connects these decisions through a shared actor-based reference.
SDI compares action sequences imagined from the same model state, using repeated
rollouts of the actor’s own sequence to measure variation under fixed behavior.
This reference scales both the spread across candidate returns, which provides
an exploration signal, and a proposed plan’s predicted advantage, which governs
action acceptance. The agent executes a planned action when its advantage exceeds
the reference variability by a fixed factor; otherwise, it follows the actor.
SDI reuses the base agent’s world model, actor, and critic without requiring an
additional disagreement ensemble. Exploration and planning guide training data
collection, while evaluation uses the learned actor alone. Across
Meta-World, Adroit, and
DM-Control, SDI achieves a higher observed
task-average score than every compared baseline in each suite and matches or
exceeds the strongest baseline’s performance on $15$ of $18$ tasks.
Component ablations and robustness analyses further examine the roles of
exploration, planning exposure, and action acceptance. Paired evaluations from
identical simulator states show that the gate improves both recovery from actor
failures and preservation of successful behavior relative to ungated planning,
while substantially reducing return degradation. Together, these results support
comparing imagined alternatives against a shared actor reference as a unified approach
to exploring and planning with world models.11

## 1 Introduction

Learned world models support two complementary ways to improve control. Agents such as
Dreamer train a fast actor on imagined experience (Hafner et al., 2020; Hafner et al., 2025),
whereas PlaNet and TD-MPC2 search through predicted futures when an action is needed
(Hafner et al., 2019; Hansen et al., 2024). Hybrid approaches use a learned actor or
value function to guide online search (Sikchi et al., 2022). These approaches make
imagination useful both for learning a policy and for revising its decisions. An actor
acts quickly, whereas a planner searches at each step. During online learning, planned
actions also change the actor’s training data. When learning stalls, when should a
searched action replace the actor’s choice?

A planner optimizes predictions from an imperfect model. Its highest-scoring sequence
can therefore exploit errors in those predictions rather than improve the real outcome
(Talvitie, 2017; Lambert et al., 2020; Sims et al., 2024).
Searching many alternatives can favor prediction errors, and even an accurately
predicted high return offers little reason to intervene if the actor would do as well.
Probabilistic ensembles and short model rollouts limit some forms of this risk
(Chua et al., 2018; Janner et al., 2019), but a decision still requires comparing a proposed
plan with the action the agent would otherwise take. During training, that choice also
changes the experience from which the actor learns. It is thus important to distinguish
the effect of planning on the eventual policy from the effect of a particular
intervention (Hamrick et al., 2021).

Exploration poses a related problem. Prediction error, novelty, and model disagreement
can direct an agent toward unfamiliar experience
(Pathak et al., 2017; Burda et al., 2019; Pathak et al., 2019; Sekar et al., 2020).
These signals are valuable for learning the environment, but familiarity with the
dynamics and progress on a particular task are different properties. Even a predictable
state may offer actions with very different task outcomes.
When a task reward is specified, the agent may therefore seek
actions with meaningfully different predicted returns. A large spread across imagined
actions is hard to interpret on its own, however: stochastic rollouts can also disagree
about the return of one fixed action sequence. A useful comparison needs to account for
that variation while remaining relevant to the actor’s current behavior.

We introduce SDI(Sibling Disagreement in Imagination), which compares imagined
action sequences with repeated rollouts of the actor’s fixed sequence from the same
model state. This actor-based reference guides exploration and plan acceptance during
data collection; evaluation uses the actor alone. SDI reuses the existing world model
and search optimizer. Across Meta-World (Yu et al., 2020a), Adroit (Rajeswaran et al., 2018), and
DM-Control (Tassa et al., 2018), SDI matches or exceeds the strongest compared
baseline on $15$ of $18$ tasks. In a replicated, matched-occupancy ablation, it raises
mean precision-manipulation success from $32\%$ with ungated planning to $53\%$ .

Our contributions are:

• 

A task-directed measure of imagined disagreement. We define sibling
disagreement as variation in predicted task returns across action sequences imagined
from the same latent state, measured relative to repeated rollouts of the actor’s
fixed sequence. This comparison separates action-dependent return variation from
stochastic variation under fixed behavior.

• 

A unified rule for exploration and selective planning. We introduce
SDI, which uses the same actor-repeat reference to reward informative imagined
alternatives and to accept a planned action only when its predicted advantage exceeds
local actor variability. SDI requires no additional disagreement ensemble, guides
data collection during training, and retains actor-only evaluation.

• 

Broad and intervention-level empirical evidence. We demonstrate that
SDI achieves the highest observed task-average score among compared methods in each
of three benchmark suites and matches or exceeds the strongest baseline mean on
 $15$ of $18$ tasks. Matched-occupancy ablations and paired-state executions further
show improved actor learning, recovery, success preservation, and return retention
relative to ungated planning.

## 2 Related work

World-model learning and planning. Dreamer trains an actor in imagined rollouts and executes it without further search
(Hafner et al., 2020; Hafner et al., 2021; Hafner et al., 2025); R2-Dreamer provides the primary base agent in our experiments (Morihira et al., 2026). Decision-time planners instead search through model-based imagination (Hafner et al., 2019; Schrittwieser et al., 2020; Ye et al., 2021; Hansen et al., 2022; Hansen et al., 2024; Nagabandi et al., 2020; Zhou et al., 2025),
while hybrid methods combine search with learned policies or values
(Sikchi et al., 2022; Anthony et al., 2017). LOOP combines finite-horizon model lookahead with
an off-policy terminal value and constrains search relative to an actor
(Sikchi et al., 2022). SDI adds an explicit post-search comparison against repeated
actor rollouts and uses that same reference construction for exploration. This targets
the acceptance of a proposal as well as the experience collected through planning
(Hamrick et al., 2021).

Model error and uncertainty.
Model error can compound over a rollout (Talvitie, 2017), prediction objectives
need not align with control (Lambert et al., 2020), and planning can exploit poorly
covered regions (Sims et al., 2024). Short rollouts, ensembles, and uncertainty-aware
updates address these problems in different ways
(Janner et al., 2019; Chua et al., 2018; Buckman et al., 2018; Yu et al., 2020b; Pan et al., 2020; Frauenknecht et al., 2024).
PETS propagates uncertainty through probabilistic ensembles and trajectory sampling
(Chua et al., 2018). SDI obtains its reference from stochastic repeats within the
base world model. This estimates rollout variability for a fixed actor sequence;
model bias remains possible (Berger et al., 2026). Our paired-state experiments
test whether a margin scaled by that reference identifies executed improvements.

Exploration and action comparisons.
Intrinsic rewards use prediction error, novelty, information gain, or ensemble disagreement
to encourage exploration
(Pathak et al., 2017; Pathak et al., 2019; Burda et al., 2019; Houthooft et al., 2016; Sekar et al., 2020; Kauvar et al., 2023).
Other signals measure action influence or reward disagreement
(Seitzer et al., 2021; Bierling et al., 2025). Adaptive mechanisms switch exploration
modes or balance intrinsic and extrinsic rewards (Pîslar et al., 2022; Chen et al., 2022),
while dormant-representation diagnostics provide a different basis for adapting training
interventions (Sokar et al., 2023; Xu et al., 2024).
Plan2Explore rewards disagreement among predictions of the next observation embedding
to seek expected information gain (Sekar et al., 2020). SDI instead compares
task-return predictions across action sequences, relative to actor-repeat variability.
This makes the signal task-directed and ties it to the reference used for plan acceptance.
The construction relates to interventional advantage, counterfactual credit assignment,
and twin models (Pan et al., 2022; Pan and Schölkopf, 2024; Mesnard et al., 2021; Balke and Pearl, 1994; Vlontzos et al., 2023);
interventional causal representation learning likewise studies information obtained
under interventions (Ahuja et al., 2023). We therefore evaluate SDI’s predictions using executed alternatives.

## 3 Method

SDI augments a world-model actor–critic during training while leaving the
base learning objectives unchanged. At each latent state, it constructs a local actor
reference from repeated imagined rollouts of a fixed actor sequence. The same reference
scales a task-directed exploration bonus and the advantage required to execute a planned
action. Planning changes the experience collected for learning; evaluation executes the
learned actor’s mode without planning. Algorithm 1 summarizes the complete
training-time interaction.

## 3.1 Actor-referenced imagined returns

The base agent provides a recurrent latent dynamics model
 $z_{\tau+1}=f_{\mathrm{img}}(z_{\tau},a_{\tau})$ , reward head $r$ , continuation head
 $\mathrm{cont}$ , actor $\pi$ , and critic $V$ . For an $H$ -step action sequence, its
continuation-weighted imagined return is

 $G(a_{0:H-1})=\sum_{\tau<H}d_{\tau}r(z_{\tau+1})+d_{H}V(z_{H}),\qquad d_{0}=1,\quad d_{\tau+1}=d_{\tau}\gamma\,\mathrm{cont}(z_{\tau+1}).$ 

Model predictive path integral (MPPI) search in latent space (Williams et al., 2016) evaluates candidate
action sequences by averaging stochastic model rollouts. After search, SDI
re-evaluates the selected plan and the actor’s fixed mode sequence with $R_{g}$ fresh
rollouts each. Let $\overline{G}_{\mathrm{plan}}$ and $\overline{G}_{\pi}$ denote their
mean returns, and let $s_{\pi}$ denote the standard deviation across actor-sequence
rollouts. The imagined advantage and its normalized score are

 $\hat{g}(z)=\overline{G}_{\mathrm{plan}}-\overline{G}_{\pi},\qquad\mathrm{IU}(z)=\frac{\hat{g}(z)}{s_{\pi}(z)}.$ 

(1)

Both sequences start from the same latent state, so their mean-return gap compares
the proposed change in behavior against what the actor would do there. The denominator
answers a different question: how much can the predicted return vary when the action
sequence is held fixed? A plan whose advantage is small relative to that local variation
provides less reason to replace the actor than the same raw gap in a stable state.
This scale does not correct model errors shared by the two sequences or turn
 $\mathrm{IU}$ into a calibrated probability of improvement.
The actor sequence is generated once and held fixed across its repeated rollouts, so
 $s_{\pi}$ measures return variation under fixed behavior. Exploration and action gating
share the actor-referenced comparison, not the sampled trajectories: exploration uses
short sibling rollouts and its own actor repeats, whereas the gate freshly re-scores a
selected plan and actor sequence over the planning horizon. All imagined rollouts use
independent model noise; Appendix A.1
distinguishes this sampling from the paired simulator randomness used only for analysis.

Sibling disagreement for exploration.
Before the first successful environment transition, SDI evaluates $K$ action
sequences imagined from the same latent state. We call these sequences siblings.
With $\hat{G}_{k}$ the estimated mean return of sibling $k$ , their normalized return spread is

 $\mathrm{sib}(z)=\mathrm{std}_{k}(\hat{G}_{k}),\qquad b(z)=\frac{\mathrm{sib}(z)}{s_{\pi}(z)}.$ 

(2)

The sibling means summarize differences among action choices, whereas $s_{\pi}$ 
summarizes variation from repeating one choice. Their ratio favors states where
imagined actions differ in task return relative to that fixed-behavior variation.
The bonus affects the actor–critic update in imagination; it is not added to the
environment reward or used as the gate’s plan advantage.
We divide this score by its running mean, clip it to $[0,3]$ , and add it to the first
reward of the imagined actor–critic rollout with weight $\beta=0.5$ . Exploration uses
 $K=5$ siblings, $K_{r}=3$ actor-reference repeats, and horizon $3$ . The first training
transition carrying the environment’s success flag starts an anneal over $20$ k optimizer
updates. The environment reward itself is unchanged. The anneal gradually removes the
auxiliary signal after discovery, leaving the original task reward to guide later learning.

## 3.2 Search, fresh rescoring, and plan acceptance

SDI separates proposing a plan from deciding whether to execute it. MPPI first searches
for a high-return sequence by iteratively sampling candidates and refitting its action
distribution to the elites. Because the selected sequence is optimized on these search
rollouts, their returns are not reused as evidence for acceptance. Instead, SDI
re-evaluates the selected plan and the actor’s fixed mode sequence from the same latent
state using independent model noise and $R_{g}=4$ fresh rollouts per sequence. This
post-search comparison supplies $\hat{g}_{t}$ and $s_{\pi}(z_{t})$ in Eq. 1; the
complete MPPI update and initialization appear in Appendix A.
Using the actor’s repeats to set the threshold also keeps acceptance tied to the
current policy, rather than to the spread of candidates that search has already
optimized.

Scoring holds the actor’s mode sequence fixed, while a rejected plan executes a fresh
actor sample. This separates the gate’s repeatable reference from stochastic training
behavior.

At a planning step, the agent executes the first planned action $\mu_{0}$ only when the
freshly estimated advantage exceeds the actor-reference variability by a factor
 $\kappa$ :

 $a_{t}=\begin{cases}\mu_{0},&\hat{g}_{t}>\kappa s_{\pi}(z_{t}),\\
a_{t}^{\mathrm{actor}}\sim\pi(\cdot\mid z_{t}),&\text{otherwise},\end{cases}\qquad\kappa=2.$ 

(3)

When a plan is rejected, the agent samples a fresh actor action. Because $s_{\pi}$ 
is a rollout standard deviation rather than a standard error, $\kappa$ is an empirical
operating threshold rather than a statistical confidence level.
Only the first planned action is executed; the agent re-plans from its next latent state.
These two uses of the actor reference address different decisions. Sibling disagreement
identifies states where alternative actions have meaningfully different imagined returns;
the gate tests whether a selected plan clears the actor’s local return variability.
The scores use separate rollout batches and horizons. A state can therefore be useful
to explore even when no proposed plan warrants replacing the actor at that step.
Exploration changes the actor’s imagined learning signal; an accepted plan changes
the next environment transition and the experience stored in replay.

## 3.3 Training schedule and planner configuration

Planning is disabled for the first $t_{\min}=20$ k environment steps to allow initial
model learning. Thereafter, a return-based predicate compares an exponential average
of episode return with its value $W=50$ k steps earlier and activates planning when
relative improvement falls below $.05$ . Once activated, planning remains available.
We call the fraction of acting steps with planner availability occupancy; this is
distinct from the fraction on which a planned action passes the acceptance rule.

The planner uses $N=256$ candidates, horizon $H=8$ , $I=4$ refinement iterations,
 $E=32$ elites, and $R=4$ stochastic rollouts per candidate. The selected plan and actor
reference are then evaluated with $R_{g}=4$ fresh rollouts each. These settings and
 $\kappa$ are fixed across domains. Search and re-scoring occur before acceptance, so a
rejected proposal still requires the full planning computation. Appendix A
provides optimizer updates, initialization, action bounds, and variant configurations.

## 4 Experimental setup

Benchmarks and budgets.
Table 1 covers three pixel-based suites.
Meta-World v3 (Yu et al., 2020a) uses $64\times 64$ observations and sparse
success rewards. The pre-specified discovery set comprises box-close, sweep-into, and
hammer, where vanilla DreamerV3 (Hafner et al., 2025) has no success by $150$ k
steps. The precision-plateau set comprises hand-insert, assembly, and disassemble.
The Meta-World budget is $700$ k, except for pick-out-of-hole, which uses
 $500$ k. Adroit (Rajeswaran et al., 2018) includes hammer, door, and pen with dense
training rewards and success-based evaluation at $1$ M steps.
DM-Control (Tassa et al., 2018) includes five tasks at a nominal $500$ k budget;
comparisons use each task’s common observed depth.

Baselines and evaluation.
We compare with DreamerV3 (Hafner et al., 2025),

and Adroit (Rajeswaran et al., 2018), the endpoint is mean success over the final
 $100$ evaluation episodes (the last $10$ evaluation calls); an episode succeeds if
its success flag is set at any step. DM-Control (Tassa et al., 2018) averages episode
return over five evaluation calls at a common scoring depth for each task.
Crossing means reaching a last- $10$ evaluation success rate of at least $0.5$

## 5 Results

## 5.1 Cross-domain benchmark performance

Meta-World.
Table 1 shows that across the ten Meta-World
tasks (Yu et al., 2020a), SDI achieves the
highest observed suite mean at both the half and full training budgets, improving
from $.43$ to $.84$ ; the strongest baseline means are $.42$ and $.60$ , respectively,
from R2-Dreamer (Morihira et al., 2026). At the full budget, SDI is highest or
tied highest on every task. Its largest gains over the strongest alternative occur
on assembly ( $.75$ versus $.09$ ), pick-out-of-hole ( $.96$ versus $.41$ ), and
hand-insert ( $.49$ versus $.34$ ).

Adroit.
On Adroit (Rajeswaran et al., 2018), SDI also has the highest observed suite
mean at both budgets, reaching $.60$ halfway through training and $.76$ at the full
budget, compared with $.33$ and $.40$ for the strongest baseline, R2-Dreamer. At the
full budget, it ties the best reported result on hammer ( $.99$ ) and door ( $.85$ ), and
leads on pen with $.44$ , versus $.23$ for the strongest alternative. Thus,
SDI matches or exceeds the best baseline endpoint on all three tasks.

DM-Control.
DM-Control (Tassa et al., 2018) shows a more mixed task-level ranking despite the
strongest suite averages. SDI obtains means of $359.3$ and $546.2$ at the
half and full budgets, compared with $241.8$ and $521.6$ for the strongest baseline,
R2-Dreamer. At the full budget, it leads on cartpole-swingup ( $279$ ) and reacher-hard
( $896$ ), and remains close to the best result on ball-in-cup-catch ( $961$ versus
 $973$ ). It trails DreamerV3 (Hafner et al., 2025) on acrobot-swingup ( $16$ versus
 $69$ ) and finger-turn-hard ( $579$ versus $616$ ). Across all three domains, these
results correspond to matching or exceeding the strongest reported baseline mean on
 $15$ of $18$ tasks.

## 5.2 Training dynamics across domains

Figure 2 shows how the endpoint comparisons in Table 1
emerge over training; black triangles mark the half- and full-budget scoring depths.
On several Meta-World (Yu et al., 2020a) tasks, endpoint convergence masks different routes to high
success. On box-close and sweep-into, SDI enters the near-saturated regime
after an initial learning phase and then remains stable. On hammer,
TD-MPC2 (Hansen et al., 2024) and R2-Dreamer (Morihira et al., 2026) solve the task earlier, whereas SDI first plateaus near intermediate
success and makes a second, late transition to saturation. The ordering is reversed on
lever-pull: SDI rises rapidly to near-perfect success and maintains it while
the alternatives improve more slowly. On bin-picking and peg-insert-side,
R2-Dreamer (Morihira et al., 2026)
makes earlier progress, but SDI continues improving and reaches the strongest
full-budget performance.

The precision-manipulation tasks show the clearest separation. SDI remains
near zero early on assembly and pick-out-of-hole, then undergoes a sustained late rise;
hand-insert improves more gradually across the second half of training. Disassemble is
different again: DreamerV3 (Hafner et al., 2025) improves first, but SDI’s final increase produces
the best endpoint. The Adroit (Rajeswaran et al., 2018) curves also distinguish early learning from eventual
performance. R2-Dreamer (Morihira et al., 2026) reaches high hammer success fastest and SDI catches up
later, while SDI continues to gain on door and pen despite visible fluctuations
in the rolling success curves.

The DM-Control (Tassa et al., 2018) trajectories reflect the mixed endpoint pattern. Ball-in-cup-catch is
largely an early-saturation task for the strongest methods, whereas cartpole-swingup
and reacher-hard continue to separate methods later in training; on reacher-hard,
SDI’s advantage appears early and is largely maintained. By contrast,
DreamerV3 (Hafner et al., 2025) exhibits the strongest late-stage rise on acrobot-swingup and narrowly exceeds
SDI at the finger-turn-hard scoring depth. Thus, the suite-level averages
summarize task-dependent learning dynamics, including early breakthroughs,delayed transitions, and differences in plateau stability, rather than
uniform dominance throughout training.

## 5.4 Paired-state analysis

## Gate reliability and selectivity.

For Figure 3a, we sample $500$ decisions from each of $18$ checkpoints
across five Meta-World (Yu et al., 2020a) tasks and execute the actor and planned branches from the same
state. A decision is counted as beneficial only when the planned branch produces a strictly
positive realized return difference. This probability rises monotonically from about
 $.24$ in the lowest normalized-margin decile to $.42$ in the highest, crossing the
all-plan rate of $.33$ in the upper half of the ranking. The imagined margin therefore
contains useful ordinal information about realized improvement. Figure 3b shows the corresponding operating points. Always executing uses
every proposal, a positive-margin rule uses $91\%$ , the SDI gate uses $47\%$ ,
and the constant-spread rule uses $14\%$ . SDI thus occupies an intermediate
regime, rejecting a slight majority of proposals without becoming as restrictive as
the constant-spread rule. These execution shares measure selectivity rather than quality;
comparisons among rules must also account for which decisions each rule retains.

## Recovery and success preservation.

The sustained-planning study in Figure 3c uses $1{,}800$ restored states
with planning available throughout each $50$ -step continuation. Among the $1{,}054$ 
states where the actor fails, gated planning recovers success in $4.2\%$ of cases,
compared with $2.4\%$ for ungated planning: $44$ versus $25$ recoveries. Among the $746$ 
states where the actor succeeds, the gate preserves $98.3\%$ of successes, compared
with $95.8\%$ under ungated planning, corresponding to $13$ versus $31$ lost successes.
Selective execution therefore improves both sides of the intervention tradeoff: it
recovers more actor failures while damaging fewer actor successes. The pooled net
success change is $+.0172$ for gated planning, compared with $-.0033$ for ungated
planning. Figure 3d directly compares the two planning rules at each checkpoint.

## 6 Conclusion

We introduced Sibling Disagreement in Imagination (SDI), which uses repeated
actor rollouts as a shared reference for task-directed exploration and selective
planning. The same actor-referenced comparison measures variation across imagined
alternatives and determines when a plan should replace the actor, without requiring
an additional disagreement ensemble. Planning guides data collection during training,
while evaluation retains the learned actor alone. Thus, the benchmark endpoints assess
policy improvement, while the paired-state experiments separately test the quality of
the planner’s training-time interventions. Across $18$ tasks in three domains, SDI matches or exceeds the strongest
reported baseline on $15$ tasks.
Overall, the findings support actor-referenced comparison as a practical way to
connect exploration and planning in world-model learning.

## Limitations

## What the actor reference measures.

Repeated actor rollouts quantify stochastic return variation for one fixed imagined
sequence; they do not capture model bias shared by all rollouts. The acceptance
threshold $\kappa$ is an empirical operating point rather than a statistical confidence
level. Restored-state experiments show that the normalized margin ranks the frequency
of realized improvement, but even its highest decile improves on the actor in fewer
than half of paired decisions. The score should therefore not be interpreted as a
calibrated probability, despite the better aggregate outcomes of gated than ungated
continuations.

## Planning cost and simulator access.

SDI reuses the base world model, actor, and critic, but search and fresh re-scoring add
acting-time computation even when a proposal is rejected. The paired-state analysis
also requires simulator-state restoration and common random numbers; these are analysis
tools and are not used during training. The experiments measure finite continuations
from frozen checkpoints and do not isolate the long-term learning contribution of each
accepted or rejected intervention.

## A.1 Search and rescoring

The planner samples $N=256$ candidate sequences over horizon $H=8$ , with $I=4$ 
refinement iterations, $E=32$ elites, and $R=4$ independent stochastic rollouts per
candidate. Search temperature is $1.0$ ; initial and minimum action standard deviations
are $.3$ and $.05$ . Actions are clipped to the environment’s bounds.

Scores are standardized separately for each environment. The initial mean follows the
actor’s imagined mode sequence. On subsequent acting steps the previous sequence is
shifted forward; episode boundaries reset this initialization.

After search, the plan and the actor’s mode sequence receive $R_{g}=\max(R,4)=4$ fresh
rollouts each. The gate compares their mean returns using the standard deviation of
those actor rollouts. It executes only the first planned action; rejection falls back
to an action sampled from the actor. The reference used for scoring is therefore the
actor’s fixed mode sequence, whereas the training-time fallback is stochastic.
Evaluation uses the actor’s mode alone.

## Independent model noise.

Candidate rollouts, repeated actor rollouts, and fresh re-scoring all use independent
model noise. Exploration uses a separate batch with its own rollout settings. Sharing
the starting latent state does not imply sharing the model’s random draws. In contrast,
the executed-alternative studies restore simulator state and use common random numbers
where supported. These are evaluation procedures, not additional simulator access
required by SDI during learning.
