Abstract

Decision models map stated rules and observed states to discrete answers. Aggregate accuracy leaves unresolved which rule and information changes guide those answers. We connect controlled input changes to transfer, joint reliability, and directed information use through executable arithmetic rules. Semantic rule separation and crossed rule and state tests make transfer and joint success separately measurable. We compare equivalent wordings, calibrate joint correctness through marginal-preserving reassociation, and alter tables to define alternative answer targets. Adaptation gains increase with nearest-source answer agreement; fully conflicting quartets yield small pooled gains and different gain signs across source splits. Equivalent rewrites have opposing task-level effects, linking transfer gains to rule presentation. Joint-score departures depend on which rule and state associations the reference preserves. A decision service changes answers more across equivalent wordings than across identical-text repeats and usually follows the answer targets implied by altered table values or mappings. Code and data will be made available.

## 1 Introduction

“A difference which makes a difference”

— Gregory Bateson, Form, Substance and Difference (1970)

Decision models turn stated rules and observed states into labels, ratings, or selected records. Accuracy measures agreement with the prescribed answer, but equal scores can conceal different responses to the inputs. In an archived routing example, two models answer half the questions correctly. One ignores both rule and state changes; the other responds to states alone. Valid option selection can also coexist with answer-symbol binding errors (Balepur et al., 2025; Xue et al., 2024). Understanding success therefore requires testing which input changes guide each rule-based decision.

Research Question

How can we determine which rule and information changes guide a decision model's answers?

A gain on unfamiliar rules can still depend on familiar wording. Low all-four correctness can follow from individual errors, so its magnitude alone does not establish unusual joint behavior. Better performance with an external table also leaves open whether its values and mappings direct the answers. Behavioral tests and contrast sets motivate controlled input changes (Ribeiro et al., 2020; Gardner et al., 2020); rule-following benchmarks examine inference, counterfactual rules, and regulations (Parmar et al., 2024; Sun et al., 2025; Zhou et al., 2025). We connect these controls to the specific ambiguities in interpreting decision accuracy.

Executable arithmetic rules make intended answers and controlled changes checkable. We separate rules by finite-domain behavior to evaluate transfer to semantic components excluded from training. Equivalent rewrites hold those behaviors fixed while changing presentation. Crossing rules and states tests responses to each factor. Marginal-preserving reassociation calibrates all-four correctness against the observed individual predictions. More restrictive references retain rule or state associations to identify what drives departures from that calibration. Finally, changing table values or mappings defines alternative answer targets. Transitions toward those targets reveal directed information use beyond an arbitrary answer change. Figure 1 links input changes to behavioral diagnostics.

Low-rank adaptation (LoRA) improves accuracy on reserved rules, with larger gains at higher nearest-source answer agreement. Fully conflicting quartets have low joint success and opposite gain signs across source splits. Equivalent wording increases the adaptation advantage on binary decisions and reduces it on the other tasks. Joint-score departures further depend on the rule and state associations retained by the calibration reference. The decision service Jev changes answers more across equivalent wordings than across identical-text repeats. It benefits from complete value tables and follows the alternative targets implied by altered values and mappings. These diagnostics distinguish conflict-conditioned transfer, joint reliability, and directed information use in model decisions.

• 

We establish an oracle-checked evaluation that uses semantic rule separation and paired input changes to distinguish transfer, wording sensitivity, and responses to rules and states.

• 

We show that transfer gains depend on source-answer agreement and the source split under complete conflict. Joint-score departures depend on the associations retained by different marginal-preserving calibration references.

• 

We identify directed use of external values through paired answer transitions under value and mapping interventions, complementing the evidence from aggregate accuracy gains.

## 2 Related Work

## Behavioral evaluation and explicit rules.

Behavioral evaluation tests whether predictions respond correctly to controlled input changes. CheckList and contrast sets target capabilities through local perturbations (Ribeiro et al., 2020; Gardner et al., 2020). Metric rankings also depend on the evaluation context (Deviyani and Diaz, 2025). RuleTaker and ProofWriter evaluate inference from stated facts and rules (Clark et al., 2020; Tafjord et al., 2021). LogicBench spans logical systems; RuleArena separates rule selection from application in regulations (Parmar et al., 2024; Zhou et al., 2025). RuleBench and IRFT extend inferential rule-following evaluation and training (Sun et al., 2025). These designs motivate testing which inputs guide decisions. Our executable grammar combines finite-domain semantic separation with crossed rule and state changes, linking success to responses along each input axis. Appendix Table 28 compares these paired evaluation designs.

## Generalization, wording, and answer interfaces.

Generalization benchmarks vary combinations, presentations, and answer interfaces. CFQ and COGS test composition; Ordered CommonGen tests requested concept order (Keysers et al., 2020; Kim and Linzen, 2020; Sakai et al., 2025). Prompt-format and answer-symbol binding studies document interface effects (Voronov et al., 2024; Xue et al., 2024). LoRA supports adaptation tests (Hu et al., 2022). Cacheable-model studies test rule following with independently encoded inputs (Rajput et al., 2026). Choice2Seq measures correctness retained from complete-answer selection to sequential construction on matched problems (Lai et al., 2026). These studies motivate paired evaluations of generalization and presentation sensitivity. Our semantic rule separation and equivalent rewrites measure how adaptation to unfamiliar rule behavior changes across presentations of identical questions with fixed model weights and intended answers.

## Information use and internal mechanisms.

Information-use studies examine how context and representations influence decisions. Performance depends on where relevant context appears (Liu et al., 2024). Probing separates recoverable information from information used to answer (Hewitt and Liang, 2019; Belinkov, 2022). Causal abstraction and interchange-intervention training connect representations to high-level variables (Geiger et al., 2021; Geiger et al., 2022). Logit inspection and attention modification examine factual recall under contextual counterfactuals (Ortu et al., 2024). Accuracy gains from supplied values leave their influence on individual answers unresolved. We alter table values and mappings to define alternative targets. Paired transitions toward those targets test directed information use. Source-selected donor replacements separately test whether recovered rule-value information influences the final selected answer.

Takeaway

Choose input interventions that distinguish the behavioral properties behind a score. Separate evidence of transfer, responsiveness, and information use when designing each evaluation.

## 3 Controlled Rule–State Evaluation

## 3.1 States, Rules, and Decisions

A decision instance is $(s,r,t,O)$ : a state $s$ , an explicitly specified rule $r$ , a task family $t$ , and an ordered option set $O$ of size $K$ . A programmatic oracle returns the semantic answer $y=g_{t}(r,s)$ and its index in $O$ . A model predicts an option index. The semantic answers align option permutations.

Each record has three integer fields $(x,y,z)\in\{-12,\ldots,12\}^{3}$ . Rules follow

 $f_{r}(x,y,z)=o_{0}\bigl(o_{1}(x,y),o_{2}(y,z)\bigr),$ 

(1)

where each operator belongs to $\{+,-,\times,\min,\max\}$ . Eligible rules depend on all three fields and retain the same three-operator, depth-two structure. Binary decisions test whether $f_{r}>0$ . Ordinal ratings count how many prescribed thresholds the score strictly exceeds, so equality remains in the lower category. Minimum routing selects the record with the lowest rule value. Maximum selection selects the record with the highest value. Record identifiers resolve ties. The option counts are 2 for binary decisions, 3/5/7 for ratings, and 2/4/8 for routing and selection.

## 3.2 Semantic Separation and State Sampling

Syntactically different expressions can implement the same decision. We compare numeric, sign, rating, and ranking signatures over the finite record domain, including field permutations. Matching any signature creates an edge between rules. Connected components conservatively keep linked rules in one pool, even when the link is transitive rather than a direct match. The separation covers executable behavior on all records in the enumerated domain.

Replication excludes historically exposed components, then assigns disjoint source and development pools by root-operator quotas and rule characteristics. Reserved components support evaluation of fixed models. Natural sampling draws complete states before labeling. Previously used complete states are excluded across roles, while individual records may recur in different multi-record states. Appendix Algorithm 1 summarizes the construction. Appendix A.4 specifies the exact eligibility checks, allocation quotas, and constraints used to construct the paired diagnostic evaluation inputs.

## 4 Behavioral Transfer and Information Use

Three paired diagnostics address the central question by testing transfer, joint correctness, and directed use of the supplied external information.

Key Findings

Conflict-conditioned transfer: Gains increase with nearest-source answer agreement. Fully conflicting quartets have low pooled joint success and opposite gain signs across source splits. Equivalent wording changes task-level adaptation gains with the same fixed model weights.
Joint reliability: Pooled QAcc lies within the primary reference ranges. Maximum-selection departures shrink when calibration preserves ordered rule pairs. Joint-score interpretation depends on the associations retained in the chosen marginal-preserving reassociation reference.
Directed information use: Jev benefits from correct tables and switches from correct answers to altered-table targets. Paired value and mapping changes distinguish directed information use from an arbitrary response change under paired original and altered-table conditions.

## 4.2 RQ1: How Do Source Conflict and Wording Shape Transfer?

LoRA’s advantage over the controlled base model persists across development-rule splits. 
Table 1 retains the LoRA gain across two rule splits. Jev leads overall, with a ranking reversal between splits. The fixed rank-4 readout uses BF16 logit caches, while Controlled Base uses FP32 candidate projection. Appendix Figure 5 retains the individual state-seed results for each state seed and source-rule split in the development evaluation.

LoRA improves reserved-rule performance over its unadapted backbone. 
Table 1 compares fixed LoRA and source-selected MLP readouts with Controlled Base. Models and the LoRA–readout criterion were fixed before reserved-question generation (Appendix F). LoRA–Base measures adaptation gains. LoRA–readout compares selected training procedures whose source competence remains unmatched (Section 5). Subsequent conflict and wording analyses reuse this reserved benchmark.

Source-answer agreement separates different transfer demands. 
For each target rule and task/ $K$ , its nearest source maximizes uniform-domain oracle-answer agreement. We rank target pairs by their mean agreement within each source split and task/ $K$ , keeping ties together. Table 2 reports absolute accuracy, gains, and QAcc. Natural gains increase across agreement groups in both splits; pooled QAcc increases, while split-1 QAcc is not monotonic. These relative groups retain all task/ $K$ strata, although their absolute agreement ranges can overlap across individual task families.

Complete source–target conflict exposes split-dependent transfer. 
Conflict load counts differing source and target answers within an intact quartet. At load four, split-1 accuracy falls from 20.47% to 14.37%, whereas split-2 accuracy rises from 22.41% to 31.29%. Their QAcc is 0.00% and 2.83%, respectively. Pooling yields a 1.39 pp item gain and 1.42% QAcc, concealing the opposing gain signs across source splits. Intermediate conflict loads have no monotonic gain trend. The two source pools reuse target questions, so these contrasts describe source-dependent outcomes on the same fixed target-rule evaluation questions.

On natural conflicting questions, split-1 accuracy changes from 34.49% to 32.07% ( $-2.43$ pp); split-2 changes from 31.10% to 43.72% ( $+12.62$ pp). Agreeing subsets improve from 40.83% to 70.93% ( $+30.09$ pp) and 42.49% to 70.74% ( $+28.25$ pp), respectively. These conditional scores retain the original evaluation weights. Their gains differ from contributions to the full-set improvement. Individual-item filtering does not define QAcc. Conflict-load analysis instead preserves all four quartet members and reports success against the target oracle across both rules and input states.

Agreement measures similarity over the rule domain; conflict load measures disagreement on the evaluated quartet. Semantic separation alone does not require different answers on every state. These posthoc diagnostics reuse saved predictions and preserve complete quartets and original weights. Appendix L.4 reports split-level strata, coverage, and conditional intervals; Appendix L.3 reports natural conflict subsets and their gain contributions.

Comparisons at a fixed batch size reveal opposing task-level responses to equivalent wording. 
We score equivalent rewrites with fixed weights and batch size. Each rewrite parses to the original rule expression. LoRA remains above Base overall, but the functional rewrite reduces its advantage. The verbal rewrite changes little overall because binary gains offset other tasks’ declines (Figure 2). Binary gains mainly reflect a larger drop in Base. Elsewhere LoRA declines while Base is stable or improves. These task-level directions persist among items with stable original-text answers across batch sizes. Appendix L reports absolute scores and paired intervals. A fixed subset crosses BF16 and FP32 inference with dynamic and fixed padding. Wording changes continue to alter answers under FP32 with fixed padding, while same-text padding effects shrink under fixed-padding and FP32 model-execution controls (Appendix L.2).

Jev changes answers across wording more often than it changes answers across identical-text repetitions. 
Adjacent Jev requests randomize the original and two rewrites, each repeated twice. Cross-wording disagreement exceeds identical-text variability (Figure 3). The contrast remains positive in all request-slot lag strata and after excluding interrupted quartets. Elapsed-time strata have uneven coverage, including one without same-text pairs. Appendix L.5 specifies the paired requests, aggregation weights, and sensitivity checks for the paired, randomized repeated-call comparison.

Figure 2: Equivalent wording changes task-level adaptation gains in opposite directions. Paired changes in the LoRA–Base advantage use batch 8 and 95% shared-state intervals. Zero denotes an unchanged advantage on the same semantically equivalent decision questions.

Figure 3: Jev changes answers more across equivalent wordings than across identical-text repeats. (a) Disagreement rates average items within splits. Takeaway

Measure absolute accuracy, transfer gains, and joint correctness across source-agreement and conflict conditions. Check wording robustness on paired, semantically equivalent questions.

## 4.3 RQ2: What Does Calibrated Joint Correctness Show?

QAcc measures all-four success; calibration specifies which associations are being tested. 
The primary reference reassociates predictions within cell, task, option-count, quartet-slot, and gold-label strata. It preserves individual prediction marginals while breaking the observed quartet associations. Pooled LoRA and Jev QAcc lie within these reference ranges, while maximum-selection scores exceed them (Table 3). Retaining ordered rule pairs brings maximum-selection reference means closer to observed QAcc. The state-vector reference additionally retains both predictions on a state together, preserving their original within-state response associations (Appendix H.1).

Preserving rule pairs yields pooled reference means of 13.33% for LoRA and 21.69% for Jev. Adding state-vector preservation gives 12.67% and 21.61%, respectively. Observed QAcc remains 13.19% and 22.05% across these references. A departure concerns associations removed by that specific reference; it does not identify an internal reasoning mechanism. Falling within a reference range leaves the observed all-four success unchanged. Finer conditioning can restrict movable predictions, and the state-vector reference does not match latent state difficulty. These controls characterize the constructed pairs. Reliability under independently sampled second states remains untested.

## 4.4 RQ3: How Do Answers Respond to External Values?

D2 supplies every rule's value for every record. D3 marks the same entries unavailable. Both retain the state, question, options, answer, and supplementary-table instructions. Using a common all-rule table requires identifying the requested rule. Appendix D defines the conditions, and Appendix L.10 provides the full native Jev requests.

The same external values benefit the tested systems to different degrees. 
Complete values improve Jev consistently across replication cells. Local models gain less. LoRA's effects vary across cells, revealing differences in how the same supplied values affect full-quartet success (Figure 4).

Jev’s answers shift toward targets implied by altered values and mappings. 
We mismatch formula rows or record columns, or change target-formula values to imply another answer. The original oracle stays fixed. Among conflicting questions answered correctly with the correct table, Jev usually switches to the altered-table target (Table 4). Both mapping mismatches preserve the value multiset and table character length. The pattern persists under task-balanced and equal-cell weighting (Appendix L.9). Even with the correct answer supplied, performance depends on context and instruction wording.

## 5 Source Competence and Internal Interventions

Independent source auditing leaves source competence unmatched. 
The qualification gate requires natural accuracy of 90% and QAcc of 75% on training and independent source-audit inputs. Base, selected readouts, and LoRA fail this gate in all six replication cells. Common-audit natural accuracy / QAcc is 36.31% / 0.00% for Base, 45.70% / 1.39% for selected readouts, and 75.43% / 35.94% for LoRA. Validation-based early-checkpoint matching succeeds in two cells, but independent audit matching succeeds in none (Appendix I). LoRA–readout differences therefore compare the attained outcomes of the selected training procedures, with source competence still unmatched. They do not estimate a transfer advantage after controlling for attained source competence.

Source-selected internal donor replacements yield no stable rule-specific improvement over controls. Appendix G reports probe results, intervention norms, and explicit paired positive controls.

Takeaway

Check source competence on independent inputs before attributing differences to transfer. Validate internal interventions with restoration and positive controls before interpreting the recovered rule information as decision-relevant.

## 6 Conclusion

We asked which input differences guide decision models’ answers. Controlled tests distinguish conflict-conditioned transfer, all-four reliability, and directed information use. Adaptation gains increase with nearest-source answer agreement, while complete conflict yields opposite gain signs across source splits and low pooled QAcc. Equivalent wording changes task-level gains, and calibration conclusions depend on the associations retained by the reference. Paired value and mapping interventions identify directed use of supplied information. Evaluation and method design should distinguish source-consistent success from correct decisions under conflict and preserve correct answers across equivalent wording. Report joint success with explicitly specified prediction-reassociation calibration conditions. Method comparisons should report attained source competence alongside target scores. Joint reliability remains a design objective even when individual decision accuracy improves under unfamiliar rules or supplied information.

## Limitations

The findings concern the tested rule families and evaluation conditions. 
The core grammar uses fixed-depth arithmetic rules on three bounded integer fields. Semantic separation is established within this finite domain. Boolean and finite-state extensions test additional rule formats rather than broad natural-language policy coverage. Fully conflicting cohorts contain 39 and 32 quartet memberships with different task coverage. Their opposing gains describe source-dependent transfer within the observed task coverage under complete conflict.

LoRA–readout comparisons estimate outcomes of the selected training procedures, because independent source-audit competence remains unmatched. The larger-model comparison also changes system identity, so the observed effects cannot be attributed to parameter count alone.

QAcc describes joint success on the constructed rule–state quartets. Calibration departures concern the associations removed by each reassociation reference. Small or constant-prediction strata restrict the available reassociations. Multi-record second states use swapped winning-record fields, so the state-vector reference does not establish reliability under independently sampled pairs of input states.

Wording results compare the original rendering with two equivalent templates. Jev’s adjacent repeats estimate variability within the observed service window, rather than performance across service versions or observation periods. Table interventions establish directed use of supplied information in answers; they do not identify an internal decision mechanism. Model comparisons concern these controlled diagnostics, rather than comparative detection rates across existing behavioral tests.

## Ethics Statement

We use synthetic states and oracle labels, with no human participants or personal records. Remote services receive only synthetic inputs. Benchmark performance does not establish suitability for consequential decisions. Generative AI tools assisted implementation, literature organization, and writing. Experimental records, failure evidence, and the actual scope of each analysis are retained.

## Appendix A Task Construction and Evaluation Protocol

## A.1 Executable Rules and Task Semantics

The rule grammar in Equation 1 contains three operator slots drawn from five operators, giving $5^{3}=125$ syntactic candidates. Each expression is evaluated over all $25^{3}=15{,}625$ integer records in $\{-12,\ldots,12\}^{3}$ . Eligibility requires effective dependence on all three fields and excludes expressions whose audited task signatures match tested lower-complexity expressions. This leaves 104 candidates. Numeric, binary, ordinal, and full weak-order signatures, including ties and field permutations, link equivalent candidates into 77 connected components. Using components rather than pairwise exclusions also prevents a chain of equivalences from spanning data pools. The audit establishes behavioral separation over the enumerated integer domain. Symbolic equivalence on real inputs lies outside this finite integer-domain test.

For one-record tasks, let $v=f_{r}(x,y,z)$ . Binary decisions return yes exactly when $v>0$ , and no otherwise. Ordinal ratings with $K\in\{3,5,7\}$ return

 $y=\sum_{i=1}^{K-1}\mathbf{1}[v>10(i-\lfloor K/2\rfloor)].$ 

(4)

The threshold lists are $[0,10]$ , $[-10,0,10,20]$ , and $[-20,-10,0,10,20,30]$ for $K=3,5,7$ , respectively. Equality to a threshold does not increment the rating. Multiclass routing uses $K\in\{2,4,8\}$ records and selects the smallest score. Structured selection uses the same option counts and selects the largest score. Both resolve ties by the smallest numeric record ID, independently of candidate order. There are ten task/ $K$ strata, with equal macro weight assigned to each of the four task families.

## A.2 Rule Pools and Complete-State Isolation

Before replication, a historical ledger contains 35,940 complete states and 40 rule ASTs. Historical exposure excludes 19 of the 77 components. Four disjoint pools of eight components use 32 of the remaining 58, forming two source/development splits and leaving 26 components in reserve. Each eight-rule pool has root-operator counts of one addition, two subtractions, two multiplications, one minimum, and two maxima. Pool construction also matches recorded operator-composition and binary-answer characteristics. The chosen pools pass a separate ordinal overlap check at each $K$ . Rule split seeds are 20261101 and 20261102. State seeds within each split are 101, 202, and 303.

Natural sampling first draws complete states with integer coordinates uniform on the finite domain, then evaluates every rule in the relevant pool. It does not filter states by answer, class balance, margin, or tie. Rejection excludes complete states already assigned to historical data or another role. A complete-state key is the ordered sequence of all records’ $(x,y,z)$ triples. This isolates entire states. An individual record can occur in two otherwise distinct multi-record states. Source training, source validation, development, and their natural/diagnostic subsets have disjoint complete-state keys. Replication cells also have disjoint complete states, while questions for different rules within a natural role intentionally share complete states.

## A.3 Semantic Reconstruction and Similarity Audit

Exhaustive signatures over the finite domain and all six field permutations show no cross-pool equivalence, including complete weak orders for record selection. Non-equivalent rules may still agree frequently. Appendix L measures nearest-source oracle agreement under the original and best-permuted fields, separating uniform-domain similarity from accepted natural states. The source and reserved rule allocations remain fixed throughout these posthoc, paired source–target agreement analyses.

We deduplicate expression trees by sorting commutative children and canonicalizing field names under each of the six possible integer-field coordinate permutations.

For each expression, the numeric signature contains all integer values over the domain. The binary signature contains the signs $f>0$ . The ordinal signature jointly stacks the answers for $K\in\{3,5,7\}$ . The ranking signature gives the rank of each distinct value and retains ties. This complete weak order records every less-than, equal-to, and greater-than relation, rather than just the winning record. Each canonical signature is the minimum hash across the six coordinate permutations. An expression is rejected if any corresponding canonical signature agrees with a simpler expression, if any field never changes the output, or if its binary answer is constant. Graph edges join expressions when any one of the four canonical signatures agrees, and connected components take the transitive closure. Per- $K$ ordinal overlap is checked separately across pools. A graph edge therefore requires one matching signature, rather than a simultaneous match of behavior across all four task-specific signatures.

After excluding exposed components, each split uses root quotas $(1,2,2,1,2)$ for $(+,-,\times,\min,\max)$ . Within each root class, a seeded choice supplies one representative, and its partner minimizes the $L_{1}$ difference in operator-count vectors plus ten times the absolute difference in binary-positive frequency. Formula strings break distance ties, and a seeded coin assigns the pair to source or development. Each pool must permit four disjoint rule pairs for every task/ $K$ . Binary and rating pairs need at least 16 unused states in each reversal bucket. Multi-record pairs are screened by 256 deterministic seeded probes before pair matching. The procedure allows at most 10,000 attempts. Accepted components are removed before selecting the next split. The 26 remaining components retain root counts of at least $(4,4,4,2,2)$ and form the held-out reserve.

## A.5 Counterbalanced Diagnostic Construction

Binary and ordinal generation samples unused states from opposite-answer strata. For each task/ $K$ /role, the generator traverses the frozen disjoint rule pairs in order and constructs two quartets per pair. For multi-record tasks it draws $s_{0}$ , obtains the two winning record IDs $a,b$ , and rejects $a=b$ . It copies $s_{0}$ to $s_{1}$ and swaps the $(x,y,z)$ fields of records $a,b$ , retaining their IDs. Both rules are evaluated again. Acceptance requires the checkerboard labels, two different complete states, and neither state in the used-state set. Accepted states enter that set. A quartet gets at most 20,000 attempts, after which construction fails explicitly. The four items are emitted in state-major, then rule-major order. Construction uses the oracle answers only.

Each source-training question also receives one reversed candidate order, preserving semantic answers and record-ID tie-breaking. Reversed quartets are separate four-item groups, not eight-item success events. Cross-rendering comparisons align semantic answers. Diagnostic sampling conditions on quartet eligibility. We separately report diagnostic scores and natural accuracy on their respective sets of sampled natural and diagnostic inputs.

## A.10 Macro Metrics and Paired Comparisons

Let $\mathcal{T}$ be the four task families, $\mathcal{K}_{t}$ their option counts, $\mathcal{R}_{tK}$ the rules present in a natural stratum, and $I_{tKr}$ its item indices. For per-item score $a_{i}$ , define

 $\displaystyle\mathcal{M}(a)={}$ 
 $\displaystyle\frac{1}{|\mathcal{T}|}\sum_{t\in\mathcal{T}}\frac{1}{|\mathcal{K}_{t}|}\sum_{K\in\mathcal{K}_{t}}\bar{a}_{tK},$ 

(5)

 $\displaystyle\bar{a}_{tK}={}$ 
 $\displaystyle\frac{1}{|\mathcal{R}_{tK}|}\sum_{r\in\mathcal{R}_{tK}}\frac{1}{|I_{tKr}|}\sum_{i\in I_{tKr}}a_{i}.$ 

(6)

Natural accuracy uses $a_{i}=\mathbf{1}[\hat{y}_{i}=y_{i}]$ . Source selection uses $a_{i}=-\log p_{i}(y_{i})$ , the candidate-normalized negative log-likelihood. This rule-level average prevents an imbalance in rule counts from changing a task’s weight. Training cross-entropy instead weights task families and then option counts equally over the available training rows. The objective balances task and option-count strata without balancing the observed semantic answer classes.

For diagnostic quartets $\mathcal{Q}_{tK}$ , let $c_{qj}$ indicate correctness at position $j$ and $C_{q}=\sum_{j=1}^{4}c_{qj}$ . The within-stratum item score is $\mathbb{E}_{q}[C_{q}/4]$ and the all-four score is $\mathbb{E}_{q}[\mathbf{1}(C_{q}=4)]$ . Both are averaged over $K$ and task as in Equation 3. We also report the distribution $\Pr(C_{q}=c)$ for $c=0,\ldots,4$ . These macro distributions need not yield integer group counts when multiplied by the number of quartets. Paired rule- and state-switch outcomes distinguish both answers correct, an unchanged semantic prediction, and a changed semantic prediction with an incorrect answer in either item.

Replication means average the three state seeds within each rule split and then the two splits equally. D2–D3 contrasts are paired within each cell before this aggregation. Reserved-rule comparisons first aggregate within a rule block, then over the six fixed model pairs, then over the 13 blocks equally. Diagnostic reserved-rule scores cover feasible strata only. Missing quartets are disclosed rather than imputed. Shared rules, states, model fits, and quartet members are retained as dependencies. The aggregation retains these shared dependencies. Quartet success is measured on the crossed questions rather than inferred from the fourth power of the separately measured natural item accuracy.

## Appendix B Model Interfaces, Training, and Readout Selection

## B.1 Input Rendering and Candidate Scoring

Controlled Base, LoRA, and the later frozen readouts use the prose renderer exemplified in Appendix A.6. The state, explicit formula, task instructions, and semantic candidate text are available in the input. Gold labels remain withheld.

Candidate letters are checked to be distinct single nonspecial tokens after the answer prefix. In the controlled path, the BF16 text backbone produces the final-normalized hidden representation $h$ and its legal candidate logits are

 $z_{k}=E_{k}^{\top}h,\qquad p_{k}=\frac{\exp z_{k}}{\sum_{j=1}^{K}\exp z_{j}},$ 

(7)

with the candidate projection evaluated in FP32 using the original output rows $E_{k}$ . Semantic prediction is the candidate argmax. Training optimizes this restricted candidate loss rather than a free-text generation objective. The original embeddings and candidate rows stay frozen during LoRA adaptation. Inputs are encoded without an explicit length-truncation cap and left-padded to the longest prompt in each batch. Appendix L.2 separately tests fixed padding and FP32 model inference, distinct from the FP32 candidate projection used here.

External systems retain their recorded interfaces: Decider uses its decision prompt, StartLux its native interface, and Jev the native TypeSafe structured request. Such comparisons characterize deployed system configurations and do not isolate a common architecture or training recipe. Table 7 records the checkpoint and service identifiers.

## B.2 LoRA Adaptation

LoRA is attached to all linear modules of the text decoder in the common Qwen Base checkpoint, with rank 16, $\alpha=32$ , scale $\alpha/r=2$ , dropout 0.05, and no trained bias. Only adapter tensors within the language decoder are trainable, totaling 16,819,200 parameters. Each replication cell starts from the same unadapted checkpoint. Training uses AdamW at learning rate $10^{-4}$ , weight decay $10^{-4}$ , gradient-norm clipping at 1, batch size 16, and no scheduler. Non-reentrant gradient checkpointing is enabled. Two epochs over 5,760 rows yield 720 optimizer updates per cell. Source-natural macro NLL chooses between the epoch-1 and epoch-2 checkpoints, with any exact tie resolved in favor of the earlier of the two saved epoch checkpoints.

The data include original and reversed candidate orders, and task/ $K$ weighting is applied to candidate cross-entropy. The procedure does not use oracle intermediate-value labels, development examples, or audit scores for training or selection. The six replication fits share optimizer seed 17. The initial fits additionally use seeds 29 and 43 on their common dataset. These two uses of seed variation have different scientific interpretations.

## B.3 Frozen Residual Readouts

All learned frozen readouts add a correction to the base logits rather than replacing them:

 $z^{\prime}=z_{\mathrm{base}}+g_{\theta}(\tilde{h}),\qquad\tilde{h}_{j}=\frac{h_{j}-\mu_{j}}{\max(\sigma_{j},10^{-6})}.$ 

(8)

Population means and standard deviations use source-training rows only. Scores beyond the legal $K$ candidates are masked. The fixed rank-4 readout uses $g_{\theta}(\tilde{h})=(\tilde{h}V)(EU)^{\top}$ , with $U,V\in\mathbb{R}^{2048\times 4}$ , fixed candidate rows $E$ , and zero-initialized $U$ . It trains with learning rate 0.003 and L2 strength $10^{-4}$ for 800 updates, evaluating source-natural NLL every 40 steps. Replication reuses this configuration.

Readout selection compares three feature sets. The final-normalized final-position vector has 2,048 dimensions. Concatenating final-position outputs at layers 8 and 16 with the final-normalized output gives 6,144 dimensions. Final-layer means over the state, question, and option regions also give 6,144 dimensions. The question region includes the rule text. These rendered-input features omit the numeric values computed by the oracle.

Each feature set is paired with a linear correction or a GELU MLP with 128 hidden units and eight outputs. L2 strength is selected from $\{10^{-4},10^{-2}\}$ , and the output layer starts at zero. Both families minimize

 $\mathcal{L}(\theta)=\sum_{i\in\mathcal{D}_{\mathrm{train}}}w_{i}\bigl[-\log p_{\theta}(y_{i}\mid i)\bigr]+\frac{\lambda}{2}\|\theta\|_{2}^{2},$ 

(9)

where $w_{i}$ gives equal mass to tasks and then option counts. L2 covers trained weights and biases. Linear corrections use FP64 L-BFGS with strong-Wolfe line search, at most 40 chunks of 20 iterations, and history size 30. The stopping threshold is a maximum absolute gradient of $10^{-6}$ , with source validation after each chunk. MLPs use FP32 full-batch Adam at learning rate 0.003 for 800 updates, with gradient clipping at 1. We evaluate source-validation NLL after every 40 optimizer updates for source-based checkpoint selection using the same candidate-normalized decision-scoring rule.

## F.2 Finite-Benchmark Decision Rule

Let $A_{b,m}^{L}$ and $A_{b,m}^{H}$ be macro natural accuracy for LoRA and the frozen readout in model pair $m$ on block $b$ . The prospectively specified LoRA–readout contrast is

 $\Delta_{b}=\frac{1}{6}\sum_{m=1}^{6}(A_{b,m}^{L}-A_{b,m}^{H}),\qquad\bar{\Delta}=\frac{1}{13}\sum_{b=1}^{13}\Delta_{b}.$ 

(11)

Before generating reserved-rule questions or predictions, the protocol requires $\bar{\Delta}\geq 0.05$ and at least ten of thirteen blocks to satisfy $\Delta_{b}>0.05$ . Base scores, diagnostic QAcc, and task-specific results are secondary descriptions. A failure of either primary condition would be reported as failing the fixed criterion, without extending the experiment.

The fixed LoRA–readout comparison meets its predeclared finite-benchmark criterion. 
The mean difference is 14.59 percentage points, and all 13 block differences exceed five points, ranging from 9.51 to 19.53 points. Across-block means for the six separate model pairs range from 11.14 to 19.69 points. Averaging the three pairs from each source split gives 12.20 and 16.97 points. Figure 9 retains all thirteen individual rule-block effects.

Blocks do not reuse rules or complete states, but they share trained models and a finite grammar. The six model pairs also share this reserved evaluation. The pass criterion is consequently a statement about the reserved finite benchmark, not a population-level significance test or independent source-retraining confirmation. No IID row bootstrap, binomial block probability, or population $p$ -value is assigned to this result. The criterion evaluates transfer by these fixed procedures on the prospective reserved-rule transfer benchmark.

## Appendix G Probes and Counterfactual Rule Interventions

## G.1 Probe Data, Targets, and Fitting

Base and state-101 LoRA are tested in both splits. Each model/split cell has 2,880 source-training, 640 source-validation, 640 independent source-audit, and 640 development questions. Features are layers 8/16/24 at the final input and final question positions, plus input-embedding segment means. Source-training standardization uses a $10^{-6}$ scale floor. A feature-name-seeded Gaussian projection reduces each feature to 256 dimensions, scaling entries by the inverse square root of input dimension.

Value targets are $\operatorname{asinh}(f_{r}(x_{j},y_{j},z_{j})/10)$ , padded to eight columns and masked by valid records. Separate answer targets are eight-way one-hot vectors. Weighted ridge regression fits each column with an unpenalized intercept, renormalizing source-training weights over valid rows. Source-validation macro masked MSE selects L2 from $\{0.1,1\}$ . Error averages valid columns within items, then task/ $K$ /rule strata. Value probes reconstruct decisions by sign, transformed thresholds, or min/max selection. Answer probes predict the highest-scoring legal candidate among the candidate answers supplied for each evaluated task family and its prescribed legal option count.

The shuffled control permutes training labels within task/ $K$ with seed 1701 and retains the real-label regularization. Figure 10 shows every location. These supervised targets are never inputs to the language model, and recoverable information alone does not establish causal use in answering.

## G.2 Donor–Receiver Pairs and Source Selection

Each intervention pairs a receiver $(s_{r},r_{r})$ with a donor $(s_{d},r_{d})$ from the same task and option-count stratum, requiring both $s_{d}\neq s_{r}$ and $r_{d}\neq r_{r}$ . The counterfactual target is

 $y^{*}=g_{t}(r_{d},s_{r}),$ 

(12)

the donor rule applied to the receiver state. Pair construction uses input identities and the oracle, not a model’s predictions. Pairs are stratified by task/ $K$ and target-answer equality with donor and receiver answers. Each stratum retains up to four pairs in deterministic order, prioritizing distinct donor, receiver, and counterfactual answers. The fixed source-audit and development evaluations each contain 160 pairs per model/split cell. Binary tasks cannot have three distinct answers and are not treated as isolating this answer property.

Candidate intervention locations are the final question positions at layers 8 and 16. Source-training diagnostic pairs provide same-state/different-rule representation differences. Their singular value decomposition supplies a four-dimensional orthonormal basis $B$ from the leading right singular vectors. This defines a rule-associated direction set, not a proven rule-only representation. For receiver and donor hidden vectors $h_{r},h_{d}$ , the two candidate patch families are

 $\displaystyle h^{\prime}_{r}$ 
 $\displaystyle=h_{d}$ 

 $\displaystyle\text{(full)},$ 

(13)

 $\displaystyle h^{\prime}_{r}$ 
 $\displaystyle=h_{r}+BB^{\top}(h_{d}-h_{r})$ 

 $\displaystyle\text{(subspace)}.$ 

(14)

The amplitude is fixed at one. Source-validation target success selects the layer and mode by maximizing patch success minus the best of native, matched-norm random-direction, and answer-direction success. Exact ties prefer the earlier layer and then the subspace mode. Evaluation retains this source choice. Audit and development inputs evaluate this source-selected intervention without changing its selected layer, mode, or replacement amplitude.

## G.3 Intervention Controls and Numerical Validation

The controls include native prediction and restoration, the selected patch, and same-rule or same-answer donors. Additional controls use matched-norm random and answer directions, rule-subspace and random erasure, and reversal of candidate order while applying the same selected intervention.

Same-rule donors change the state while retaining the receiver rule. Same-answer donors use another state and rule whose answer matches the receiver’s answer. Answer directions subtract source-training answer prototypes within task/ $K$ strata and match the selected patch norm. Random directions are deterministically seeded per pair and layer. Rule-subspace erasure subtracts $BB^{\top}(h_{r}-\mu)$ using the source-training mean $\mu$ . Random erasure uses a perturbation of the same norm. Donors and receivers share a checkpoint and use vectors from the same source-selected layer and token position.

Receivers are captured in the native forward batch, and restoration must retain identical choices and probabilities within $10^{-5}$ . Reversed candidates use receivers captured under their own ordering. Source validation selects among layers 8 and 16 and full or subspace replacement, with amplitude fixed at one. Base/split 1 uses full replacement at layer 8; Base/split 2 uses the layer-16 subspace. Both LoRA cells use the layer-8 subspace. These fixed evaluation settings remain source-selected.

Applied BF16 norms, conversion errors, probabilities, and margins characterize the actual perturbation. Zeroing the question position and flipping the terminal sign provide positive controls for path sensitivity. A value of 4.84 thus denotes a change of 4.84% relative to the receiver norm.

## Appendix H Joint-Metric Calibration and Conditional Uncertainty

Stratified reassociation characterizes the joint reference implied by the saved prediction marginals. 
Calibration reuses predictions from the fixed models. Within each cell, reassociation preserves prediction marginals conditional on task/ $K$ , quartet slot, and true label. It uses 1,000 reassociations to obtain descriptive quantile ranges. This reference breaks associations within the original quartets. It is neither an independent-row sampling model nor a causal test of rule execution. The development replication contains 480 complete quartets, and the reserved rules yield 254 feasible quartets. Calibration covers the feasible task/ $K$ strata recorded in the fixed diagnostic evaluation sets.

The deterministic controls use only original-rendering source-training natural data. Let $R_{S}$ be its distinct rules and $S_{t,K}$ its distinct complete states for task $t$ and option count $K$ . Let $M$ return the modal answer index, breaking ties toward the smallest index. The source-label-majority control returns the mode of source labels within $(t,K)$ . The other controls are

 $\displaystyle h_{\rm rule\mbox{-}blind}(s,t,K)$ 
 $\displaystyle=M\{g_{t}(r,s):r\in R_{S}\},$ 

(15)

 $\displaystyle h_{\rm state\mbox{-}blind}(r,t,K)$ 
 $\displaystyle=M\{g_{t}(r,s):s\in S_{t,K}\}.$ 

(16)

Oracle answers use the original option-index convention, including record-ID tie-breaking. Thus the rule-blind control votes over source rules on the presented state, while the state-blind control votes over source states under the presented rule. Neither uses development labels to fit or select predictions.

On these diagnostic questions, source-label-majority, rule-blind, and state-blind controls obtain item accuracies of 34.20%, 40.32%, and 33.64%, with zero QAcc. ## J.1 Fixed Inputs and Semantic Verification

The supplement uses state seed 101 from both development splits. Complete quartets are selected by a fixed SHA256 ordering within task/ $K$ /rule-pair strata: 40 quartets and 160 questions per split, totaling 80 quartets and 320 questions. Selection does not inspect predictions. Base, the corresponding LoRA, and Jev share the questions. The functional rewrite uses named operations such as sum and difference. The verbal rewrite replaces arithmetic symbols with words inside fully parenthesized expressions. For the archived rule $min(x,y)-(y+z)$ , the functional expression is difference(minimum(x, y), sum(y, z)), and the verbal expression is (min(x, y) minus (y plus z)). Both questions ask whether this value is strictly positive and parse back to the original AST. States, thresholds, tie-breaking rules, displayed options, and original gold answers are unchanged.

The correct value table retains the original D2 input. Formula-row mismatch misassigns complete computed-score rows to formulas, while record-column mismatch applies one common column permutation to every formula. Both operations preserve the table’s value multiset and serialized character count. A nonidentity column permutation is impossible for single-record tasks, so their 128 questions are marked not applicable. Of the remaining 192 questions, 190 have table targets that conflict with the original oracle. Formula-row mismatch produces 220 conflicting questions.

The target-value counterfactual changes one table value for the requested formula so that the table target moves to the next option in a predefined cycle. Construction uses only the oracle, not model predictions. All 320 questions change their table targets. Value-range, string-length, and sign properties are matched in 292, 165, and 162 questions, respectively, and the remaining differences are retained. This table depends on the specific question, so shared-state QAcc is not reported for this condition. ## J.2 Paired Answer Transitions and Denominators

Define the conflict set $C$ using only questions for which the intervention applies and the original oracle answer $o_{i}$ differs from the manipulated table target $t_{i}$ . Let $p_{i}^{0}$ and $p_{i}^{1}$ denote predictions with the correct and incorrect tables. Set $N=|C|$ , $B=\sum_{i\in C}\mathbf{1}[p_{i}^{0}=o_{i}]$ , and

 $T=\sum_{i\in C}\mathbf{1}[p_{i}^{0}=o_{i},\ p_{i}^{1}=t_{i}].$ 

(17)

We report the paired-transition proportion over all conflicting questions, $T/N$ , and the conditional proportion among initially correct questions, $T/B$ , with integer numerators and denominators. Strata with $B=0$ are undefined. The main-text table uses pooled micro estimates. The supplementary macro estimate first pools counts from both splits within task/ $K$ , then averages equally over $K$ within tasks and over tasks. Per-cell strata and complete $3\times 3$ transition matrices are saved separately. Pooled micro, this macro estimate, and equal-cell estimates are distinct. Matrix categories are the original answer, the new table target, and other answers, separating answers that remain correct, follow the table target, or select another incorrect answer option.

## L.3 Nearest-Source Similarity and Conflict Subsets

For each target rule and task/ $K$ , the nearest source rule maximizes oracle-answer agreement over uniform finite-domain inputs. Ties within $10^{-14}$ choose the lexicographically smallest source ID. The permutation sensitivity additionally searches the six field permutations, breaking remaining ties lexicographically. This oracle-assisted reference is evaluated on accepted natural states with the target oracle retained as gold. The conflict subset contains questions where their answers differ.

For the two multi-record tasks, records are drawn independently with replacement from the finite domain. Let $(A,B)$ denote the paired rule values of a candidate, with signs reversed for minimum routing so larger is always preferred. Define $p_{<}(a,b)=P(A<a,B<b)$ and $p_{\leq}(a,b)=P(A\leq a,B\leq b)$ . Since smaller record IDs win ties, exact winner agreement for $K$ records is

 $\displaystyle P(\text{same winner})$ 
 $\displaystyle=\mathbb{E}_{(A,B)}[S_{K}(A,B)],$ 

(18)

 $\displaystyle S_{K}(a,b)$ 
 $\displaystyle=\sum_{i=0}^{K-1}p_{<}(a,b)^{i}p_{\leq}(a,b)^{K-1-i}.$ 

The empirical joint distribution enumerates all finite-domain records, so the formula integrates all ordered $K$ -record draws without enumerating their Cartesian power. Records before a candidate must be strictly worse under both rules. Later records may tie the candidate under either rule because record-ID tie-breaking favors the earlier candidate.

The subset-normalized conflict score averages within each observed task/ $K$ subset, then equally over $K$ and tasks. It does not equalize rules after filtering. For the additive decomposition, let $g=(\text{rule},t,K)$ , $w_{g}$ be its full-set macro weight, $p_{C,g}$ its conflict fraction, and $\Delta_{C,g},\Delta_{\bar{C},g}$ its conditional LoRA-minus-Base differences. Then

 $\displaystyle\Delta_{\rm full}$ 
 $\displaystyle=\Delta_{C}+\Delta_{\bar{C}},$ 

(19)

 $\displaystyle\Delta_{C}$ 
 $\displaystyle=\sum_{g}w_{g}p_{C,g}\Delta_{C,g},$ 

 $\displaystyle\Delta_{\bar{C}}$ 
 $\displaystyle=\sum_{g}w_{g}(1-p_{C,g})\Delta_{\bar{C},g}.$ 

Weights are $w_{g}=(4\,|\mathcal{K}_{t}|\,26)^{-1}$ for this balanced natural set. Empty subsets contribute zero mass. Their conditional scores are undefined rather than imputed. The two contributions exactly recover the original batch-16 macro advantage. A full-weight conditional conflict score divides its contribution by $\sum_{g}w_{g}p_{C,g}$ and differs from the subset-normalized macro computed after conflict filtering (Table 18).

## L.11 Additional Rule Split and Interface Extensions

For finite-state symbol-mapping swaps, correct-to-new-target transitions are 9/88 (10.23%) for Base, 10/82 (12.20%) for LoRA, and 23/140 (16.43%) for Qwen3.5-9B. The denominator contains initially correct conflicting questions. Table 24 reports the natural and quartet scores.
A further disjoint rule split reproduces an adaptation gain dominated by nonconflict questions. 
The added split uses 16 components disjoint from the original source/development pools, state seed 101, 5,760 training rows, and 1,920 evaluation rows. The original LoRA recipe runs 720 updates, with source-validation NLL selecting epoch 2. These components had appeared in reserved evaluation, so the result is development replication: three rule splits and seven cells overall. Natural accuracy / QAcc are 38.80% / 0.00% for Base and 58.46% / 19.79% for LoRA. The decomposition uses full-set weights. Conflict weight is 36.98%, with conditional gains of 5.99 pp versus 27.69 pp on agreeing answers.

The fixed native template does not improve the larger model’s direct decision scores. 
The native check places each rendered prompt in one user message through Qwen3.5-9B’s chat template with enable_thinking=False. It directly scores candidate letters for all 5,176 questions in each wording. Figure 14 compares this with raw prompting. Paired intervals use 2,000 resamples of the 13 existing blocks. The comparison holds model weights and question identities fixed, using direct candidate scoring without generated reasoning or additional selection of the input prompt or model checkpoint.

The tested arithmetic adaptation does not confer broad finite-state rule competence. 
The sequential extension uses four states, two event symbols, and 20 noncommuting transition tables. Each event permutes the states. We enumerate ordered pairs of distinct permutations whose composition differs in at least one state when reversed, shuffle with seed 2026100807, and retain 20 tables. Every start state and X/Y sequence of length two to four gives 112 inputs per table, with length probabilities $1/7,2/7,4/7$ under uniform sampling. Each natural set draws 16 inputs without replacement.

Adjacent tables form ten pairs. Diagnostic construction excludes both tables’ natural inputs, groups remaining inputs by their two distinct answers, and draws eight quartets per pair from opposite-answer groups. Inputs may recur across quartets within a pair. Each quartet receives a single shared permutation of the displayed options.

Independent function composition verifies every table/input oracle. The resulting 320 natural questions and 80 quartets total 640 questions.
Correct and X/Y-swapped tables are evaluated with Base, split-1/state-101 arithmetic LoRA, and 9B, producing 3,840 predictions without new-task training. The 449 conflicts pool natural and diagnostic inputs. Transition rates condition on initially correct conflicts, so denominators differ by model. All systems have zero QAcc, which alone does not establish an additional structural deficit. Intervals resample the ten table pairs.
