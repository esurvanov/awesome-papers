Abstract

In joint-embedding predictive architectures (JEPA), an encoder and a predictor are trained together to produce a representation that minimizes the error in predicting the representation of the next observation.
Because the representations of both the current and the next observation are learned, it is unclear which features they will include.
Earlier characterizations describe the features JEPA selects in terms of their individual predictability, raising the concern that unpredictable features, like a traffic light, will not be encoded into the representation.
However, the prediction error is also affected by the relationships between features, e.g., the light’s color helps predict whether the traffic will stop.
We propose the predictive closure characterization, which accounts for these relationships.
Based on a reformulation of the JEPA training objective, we show that selection depends on properties of feature sets.
This view agrees with earlier works when features evolve independently, but makes new predictions when they do not, for instance that a feature like the traffic light can still be retained.
We test this characterization in controlled experiments, which show that unpredictable features can become better represented when they help predict other features, and that changing one feature’s predictive relationships can affect how well others are represented.
We also demonstrate implications for steering feature selection: targeting one feature with an auxiliary objective, or supplying it to the predictor as side information, can strengthen the representation of another feature whose future values it helps predict, so steering can be indirect.

## 1 Introduction

We argue for a set-level characterization of how JEPA selects which features to encode.
A joint-embedding predictive architecture (JEPA) aims to learn representations useful for planning and other downstream tasks, without explicitly specifying which features those representations should include (LeCun, 2022).
JEPA-based systems have shown strong performance across a range of applications (Assran et al., 2025; Maes et al., 2026; Rao et al., 2026; Larey et al., 2026; Zhu and Choromanska, 2026; Kuhn et al., 2026), yet which features they encode is still far from obvious.
This matters because their representation acts as the world model JEPA builds for each observation (García et al., 1989; Schmidhuber, 1990; Sutton, 1991; Ha and Schmidhuber, 2018), so features absent from it cannot inform planning or other downstream tasks, however accurate JEPA’s predictions are.

Since JEPA’s encoder determines both sides of the prediction problem, JEPA learns what to predict together with how to predict it.
The encoder maps each observation (for example, three consecutive frames from a video) to a latent representation and a predictor that uses the current observation’s representation to forecast the representation of the next observation.
The training objective combines a prediction loss with regularization designed to prevent the latent representation from collapsing to the same point for every input.
With a limited latent size, the encoder must leave some features out when the observation has more than fit.
Will JEPA then represent a feature whose next value is hard or impossible to predict, such as a traffic light?

Cyclist artwork adapted from Scott McCloud’s Understanding Comics (1993).

In recent work, Pendharkar (2026) argues that unpredictable features such as the traffic light will not be represented.
This is consistent with the characterizations of feature selection in other works that portray it as dependent on the feature’s own rate of change (Sobal et al., 2022; Karmann et al., 2026) or predictability (Littwin et al., 2024; Enigma Team, 2026).
All of these works judge each feature by its own behavior.
In this paper, we argue that such features can still be represented because, while hard to predict, they can help predict other features that JEPA encodes: the traffic light’s current color helps predict whether a cyclist waiting at it will ride or stop next (Figure 1).
Reasoning about one feature at a time can then feel like chasing one’s own tail: what is useful to represent depends on what must be predicted, while what must be predicted depends on what is represented.

To account for such relationships, we propose a novel characterization named predictive closure, which judges sets of features as wholes rather than each feature on its own.
It is based on a reformulation of the JEPA training objective in which selection depends on joint properties of the selected set of features (Section 3).
The reformulation shows that among the sets the latent can represent, the objective favors the set with the greatest mutual information between the current and the next values of its features.
This means that what a feature adds to JEPA’s objective depends on the other features in the set.
Adding it raises the mutual information if its current value helps predict their next values, or if its next value can be predicted from their current values.
The traffic light can therefore belong to the set the objective favors, even though its own next state is impossible to predict.

Predictive closure explains what earlier works found about the features JEPA encodes, and agrees with them when features evolve independently.
When features help predict other features, it makes new predictions, including about steering methods (Section 4).
We construct image sequences with controlled predictive relationships, train JEPA systems on them with a latent too small to hold every feature, and use probes to measure which features the latent keeps (Section 5).
First, we find that an unpredictable traffic-light-like feature becomes more decodable as its usefulness for predicting other features increases.
Second, strengthening one predictive connection within a set of features that help predict one another can increase its members’ representation while reducing that of a competing set whose predictive relationships are unchanged.
Third, even a highly predictive set of features can remain poorly represented if it requires more capacity than the latent provides.

Predictive closure further predicts that targeting one feature during training affects the representation of its predictive partners and competitors.
We test these steering predictions in Section 6.
We find that adding an auxiliary loss to reconstruct a single image can strengthen the representation of its untargeted predictive partner while reducing that of competing feature sets.
We also find that supplying a feature directly to the predictor strengthens the representation of some features while weakening others. This suggests using side information from observations to steer feature selection, even when it is not an action (Section 6.3).
Both interventions can strengthen a predictive partner of the targeted feature, so steering can be indirect.
If we view actions as side information, predictive closure also suggests that action-conditioned JEPA favors the features an agent has an impact on.

## 2 Background

A joint-embedding predictive architecture (JEPA) learns a representation by predicting the latent representation of the next observation.
Unlike reconstruction-based approaches, which train the latent to compress the information needed to recover the input (Kingma and Welling, 2014), JEPA does not impose this requirement, so its latent can omit some features of the observation (Van Assel et al., 2025).
This raises the question of which features JEPA will encode, which is the main focus of this paper.

## 2.1 JEPA Doesn’t Explicitly Specify Features

JEPA includes an encoder $f$ that maps an observation $x_{t}$ at time $t$ to a latent representation $f(x_{t})$ , and a predictor $g$ that takes $f(x_{t})$ as input to predict $f(x_{t+1})$ (Figure 1).
Training combines a prediction loss on observation pairs with a regularization loss on the latent distribution (LeCun, 2022):

 $\mathcal{L}_{\mathrm{JEPA}}\triangleq\mathbb{E}\left\|g(f(X_{t}))-f(X_{t+1})\right\|_{2}^{2}+\lambda\mathcal{R}(f(X_{t})).$ 

(1)

Here, $X_{t}$ denotes the random observation at time $t$ , and the expectation is over consecutive observation pairs.
The parameter $\lambda>0$ controls the weight of the regularizer $\mathcal{R}$ , which acts on the distribution of $f(X_{t})$ and encourages it to match a chosen distribution to prevent collapse (such as the distributions proposed in Balestriero and LeCun, 2025; Wu et al., 2026; Kuang et al., 2026; Nicollier et al., 2026).

Within the bounds of the enforced distribution, the objective does not specify what the latent should contain, and because the encoder produces both the predictor’s input and its target, the predictor adjusts to whatever the encoder produces.

To describe what the latent represents, we use the concept of features.11
 1

 An alternative way to describe the latent is to ask which differences in the observation result in the same representation, so that the latent is defined by what it omits (Li et al., 2006).
We define features as variables of the observation, some of which correspond to named properties such as the traffic light’s color or the cyclist’s speed, and we say that the latent represents a feature when the feature’s value can be recovered from the latent.
See Appendix A.1 for the formal definition that we use in our proofs.
Features allow us to treat the latent as representing separate pieces of information and to leave aside how it encodes them together.
Such a description makes it tempting to think about the latent one piece at a time and to overlook the relationships between the pieces.
It is nonetheless a common way to describe information-processing systems, both biological (Hubel and Wiesel, 1962; Marr, 1982; Hung et al., 2005) and artificial (Bengio et al., 2013; Alain and Bengio, 2016), and it is also how earlier work has characterized the information JEPA stores, as we review next.

## 2.2 Earlier Characterizations of Feature Selection

Some earlier works characterize JEPA as focusing on slow features (Sobal et al., 2022), as encoding the most predictable features (Enigma Team, 2026), or as discarding unpredictable ones (Pendharkar, 2026).
Other works describe the information selected into the latent as a subspace of the observation space (Tang et al., 2023; Littwin et al., 2024; Khetarpal et al., 2024; Van Assel, 2026), under two assumptions: that the encoder and predictor are linear, and that features evolve independently, so the current value of each feature carries no information about the next values of the others.

These per-feature descriptions disregard the predictive relationships between features and assume that each feature carries information about its own future only, not about the future of other features.
In the characterization we propose in this work, we take this relation into account by assessing features jointly.

## 3 Predictive Closure

We reformulate JEPA’s prediction objective as selecting a feature set whose present values provide the most information about its own future (known as predictive information) while remaining feasible under the regularization applied to the latent representation.
This yields the characterization we call predictive closure (Section 3.1), which we then decompose into two terms that give a more interpretable view of the selection (Section 3.2).

## 3.1 JEPA Selects Sets, Not Individual Features

We begin by identifying which feature sets JEPA can select.
We write $S$ for a set of features, $Y_{t}(S)$ for their joint values in an observation at time $t$ , which together form one random variable, and $S(f)$ for the complete set of features recoverable from the latent of an encoder $f$ .
Our first observation is that JEPA’s regularization loss constrains $Y_{t}(S(f))$ to a specific entropy (Section 2.1), and we call a set of features $S$ feasible if its values have exactly this entropy (Appendix A.1 gives the full condition).
The question is then what determines which feasible set JEPA’s training objective selects.

We prove that the set $S(f^{\star})$ represented by an ideally trained encoder $f^{\star}$ , one that minimizes the training objective, is a feasible set with the greatest predictive information $I_{\mathrm{pred}}$ (Bialek and Tishby, 1999):

 $\boxed{S^{\star}\coloneqq S(f^{\star})\in\operatorname*{arg\,max}_{S\ \mathrm{feasible}}\underbrace{I\bigl(Y_{t}(S);Y_{t+1}(S)\bigr)}_{I_{\mathrm{pred}}(S)}.}$ 

(2)

The optimization can be thought of as seeking a set that is most “closed under prediction”, meaning that the current values of its features determine their next values. We call the feasible set that optimizes this the predictive closure.

## Proof sketch.

With the entropy of the latent’s distribution fixed, the prediction loss can be lowered only by making the next latent less uncertain given the current one, which increases the mutual information between them.
Because knowing the values of $S(f)$ is the same as knowing the latent, the mutual information between consecutive latents equals the predictive information of $S(f)$ .
Maximizing it over encoders is therefore the same as maximizing predictive information over feasible sets.
See Appendix A for the full proof.

Intuitively, adding a feature to a set of features raises the set’s predictive information if the feature’s value at time $t$ helps predict the values of the other features in the set at time $t+1$ , or if its value at time $t+1$ can be predicted from their values at time $t$ .
Here, one value helps predict another when the two have high mutual information.

The earlier characterizations in Section 2.2 and predictive closure both imply that JEPA keeps features that are predictable and help predict others, and omits features that are unpredictable and help predict nothing, but they differ fundamentally in how the choice is made.
Individual selection amounts to ranking the list of features and keeping the top $n$ that fit in the latent, whereas predictive closure requires comparing alternative sets and not alternative features, because what a feature adds to the predictive information of a set depends on which other features the set contains.
The two views coincide when features evolve independently of one another: each feature then adds the same predictive information and takes up the same capacity whatever else is represented, so features compete only for capacity and ranking them is enough (see Appendix A.5 for details).
Predictive closure makes new predictions when features are predictively related, in the sense that the current values of some features carry information about the value of another at the next time step.

Because features are assessed jointly, neither how easily a feature can be predicted nor how much information it provides determines by itself whether it belongs to the predictive closure.
A feature $\phi$ will be represented if it is a member of some feasible feature set $S_{\phi}$ with greater predictive information than any other feasible set.
These competing sets can differ in many features besides $\phi$ , and some may share only constant features.
Whether one part of an observation is represented can therefore depend on whether another part is represented, even when neither helps predict the other.

## 3.2 Aleatoric Uncertainty and Predictive Leakage

We decompose the predictive information to gain further insight into the feature selection objective:

 $S^{\star}\in\operatorname*{arg\,min}_{S\ \mathrm{feasible}}\Bigl[\underbrace{H\bigl(Y_{t+1}(S)\mid X_{t}\bigr)}_{\text{aleatoric uncertainty}}+\underbrace{I\bigl(X_{t};Y_{t+1}(S)\mid Y_{t}(S)\bigr)}_{\text{predictive leakage}}\Bigr].$ 

(3)

The aleatoric uncertainty is how uncertain the set’s next values $Y_{t+1}(S)$ remain even when the full current observation $X_{t}$ is known.
The predictive leakage is how well the current observation predicts the set’s next values beyond what can be predicted from the set’s current values, and it is zero when the set’s features together predict all of their next values.
See Appendix A.4 for the derivation.

This decomposition gives us more language to describe the choice of the best set: a feature whose current value helps predict the set’s next values lowers the set’s predictive leakage, and one whose next value is determined by the set’s current values does not add to either term.
Conversely, a noisy feature only adds to the aleatoric uncertainty unless it helps predict other features in the set, so a noisy TV that helps predict nothing (Burda et al., 2019) will not be represented.

## 4 Implications of Predictive Closure

We now show how predictive closure explains earlier empirical findings on which features JEPA-based systems encode and makes predictions about what features will be selected in scenarios where features are predictively related.
Throughout this section we reason with Equation (3): the encoder favors features that add little to its sum.

## 4.1 Explaining Earlier Findings

Sobal et al. (2022) found that a moving object was better represented when its background was independently resampled between observations than when it remained fixed within each sequence.
A fixed background adds nothing to the sum, since its next values equal its current ones, while a resampled one adds its entire entropy as aleatoric uncertainty and is left out in favor of the moving object.
Enigma Team (2026) found that even a small pattern added to the observations took over most of the latent when held fixed within each sequence, and was ignored when resampled at every observation.
Here too the resampled pattern adds its entire entropy, while every feature of the fixed pattern, however fine, adds nothing, so a set made only of such features has the smallest sum and leaves no room for the rest of the scene.

Karmann et al. (2026) found that a JEPA world model encoded the slowly changing score of a Pong game while suppressing the fast-moving ball, and, like Sobal et al. (2022), describe JEPA as biased toward slow features.
This bias follows from the time step between $t$ and $t+1$ in Equation (3): a feature that changes little within one step is almost determined by its current value and adds almost nothing to the sum, while a fast-changing one can add far more.
What counts as slow therefore depends on the time step, so a feature can be kept at one temporal resolution and omitted at another.

Pendharkar (2026) showed that an independently resampled visual cue, appearing over a predictably changing background, was barely decodable from JEPA’s latent despite determining which action earned a reward (reward was not included in the training objective).
The cue only adds to the sum: its next value is pure aleatoric uncertainty, and its current value removes no predictive leakage.

## 4.2 Predicting Feature Selection

## Cross-subsidization.

An unpredictable feature $\phi$ adds the aleatoric uncertainty of its own next value to the sum, but if $\phi$ is highly predictive of other represented features, including it also removes predictive leakage, which subsidizes this cost.
Hence, predictive closure predicts that an unpredictable feature will be represented if it is sufficiently predictive of other represented features.
In scenarios like the one depicted in Figure 1, where the cyclist’s features are determined by the traffic light and the light itself is unpredictable, the traffic light will be represented whenever the cyclist’s features are.

## Set switching.

Consider a scenario where the observations contain two feature sets with predictive relationships within each set, but not between them, and the latent has the capacity to fully represent either set but not both. Increasing the strength of the relationships within one set lowers the aleatoric uncertainty of its features’ next values, and once its sum falls below that of the second set, it will be represented instead, even if the second set remains unchanged.
Hence, predictive closure predicts that strengthening the predictive relationships within one set of features will eventually displace a disjoint set that competes with it for capacity.
For example, adding sensors for an independent, highly predictable process can displace features of the original observations from the latent.22
 2

 When we write of changes to the observations, we consider the counterfactual case where a JEPA system would be trained on the sequence after the change.

## Feasibility dependence.

Equation (3) compares only feasible sets, and a set whose entropy exceeds the latent capacity is not feasible; each feasible part of such a set has predictive leakage through the features it leaves out.
Hence, predictive closure predicts that enlarging a set of mutually predictive features beyond the latent capacity will reduce its representation, even if its features remain as predictable as before, which can lead to an entirely different set being represented.

## Steering with an auxiliary loss.

When adding an auxiliary loss that requires some features, we force those features into the predictive closure, and the remaining features are selected such that together with the fixed features they form the set with the smallest sum.
The included features will be not only those that the auxiliary loss requires, but also their predictive partners: features whose current values help predict the required features’ next values and so reduce predictive leakage, and features whose next values the required features help predict.
Hence, predictive closure predicts that an auxiliary loss on some features will also strengthen the representation of their predictive partners, at the expense of competing features.
For example, an auxiliary loss for reconstructing the wind measurements can favor representation of a flag’s state.

## Steering with side information.

When supplying the predictor with side information $U_{t}$ that it is not trained to predict (as is usually done for actions), both terms of Equation (3) are computed given $U_{t}$ as well.
This extends the prediction-error assumption to condition on both predictor inputs (see Appendix A.6 for the derivation).
When $U_{t}$ is derived from the observation, only the predictive leakage changes: it becomes $I\bigl(X_{t};Y_{t+1}(S)\mid Y_{t}(S),U_{t}\bigr)$ , so what $U_{t}$ tells about the set’s next values no longer leaks.
When it is not, as with actions, $U_{t}$ can also lower the aleatoric uncertainty.
Hence, predictive closure predicts that adding side information can strengthen the representation of features whose next values it helps predict, without requiring the side information itself to be represented in the latent.
For example, supplying wind measurements to the predictor can favor representation of a flag’s state.

## 5 Testing the Selection Predictions

We test whether trained JEPA systems follow the three selection predictions from Section 4.2, in image sequences that are simple by design.
Testing a prediction requires a sequence whose predictive relationships are known and can be changed one at a time, which natural data does not allow.
Each experiment therefore creates a synthetic sequence and changes a single property of it, with the architecture and the training budget held fixed, so that the change in what is represented can be attributed to that property.

These targets are the traffic-light state or binary indicators of target-image presence.
We approximate how well features of the image at each position are represented by averaging accuracy across the binary target-image detection tasks associated with that position.

## 5.1 Cross-subsidization: representing unpredictable features

## Scenario.

We place a two-valued traffic light alongside two images in a collage.
We write $A$ and $B$ for the images and $L$ for the light’s value, green or red.
At every transition, exactly one image is replaced by a newly sampled image while the other persists.
With probability $q$ , the current light $L_{t}$ determines which position is resampled; otherwise, the position is chosen uniformly (Figure 2, left).
Green selects $A$ for replacement and red selects $B$ .
The next light $L_{t+1}$ is an independent uniform draw, so the light is unpredictable and representing it adds one bit of aleatoric uncertainty at every value of $q$ , while a larger $q$ lets $L_{t}$ remove more predictive leakage from the images’ next values.

Figure 2: Cross-subsidization: the unpredictable light becomes more decodable when it helps predict the images.
Increasing $q$ makes the current light more useful for predicting which images persist, while its future remains unpredictable.
Dashed line: $50\%$ chance accuracy.

## Results.

As $q$ increases, the light feature $L$ becomes better represented even though its future is impossible to predict (Figure 2).
As predictive closure predicts, features are not selected solely according to how easy they are to predict.
Note that the transition in this scenario involves a nonlinear interaction between the light and the current images, which cannot be captured by frameworks that assume the predictor is a linear function such as Littwin et al. (2024).

## 5.2 Set Switching

## Scenario.

The two-pair setup places images $A/B$ and $C/D$ in a $2\times 2$ collage.
Within each pair, an image can be copied to the other position in the next frame; otherwise, a new image is sampled independently.
We vary only the probability $p_{D}$ that $C_{t}$ is copied to $D_{t+1}$ while keeping all other copying probabilities fixed (Figure 3, left; Appendix B.3).

Figure 3: Set switching: changing predictive relationships reverses which pair is more strongly represented.
Increasing $p_{D}$ strengthens decoding of $C/D$ and weakens $A/B$ , whose predictive relationships remain fixed; neither pair helps predict the other.
Dashed line: $50\%$ chance.

## Results.

Increasing $p_{D}$ shifts representation from features of $A/B$ toward features of $C/D$ , although the predictive relationships within $A/B$ remain unchanged and neither pair helps predict the other (Figure 3).
We also find similar decoding accuracy within each pair, consistent with the set-level characterization.

## 5.3 Feasibility Dependence

## Scenario.

To test feasibility dependence, we keep $A/B$ and the latent size fixed and increase the competing cycle to $N\in\{2,4,8,16\}$ images (Figure 4, left).
Average within-cycle copying probabilities remain unchanged, so retaining the larger cycle requires representing features of more images; tile scale and layout also change with $N$ (Appendix B.3).

Figure 4: Feasibility dependence: adding images to a cycle can reverse which images’ features are more strongly represented.
Mean decoding accuracy across the competing cycle’s positions decreases as $N$ grows, despite unchanged average copying probabilities; at $N=16$ , the fixed $A/B$ pair is better represented.
Dashed line: $50\%$ chance.

## Results.

Mean decoding accuracy for features of the competing images decreases at every increase in $N$ in all three optimization seeds (Figure 4).
At $N=16$ , features of $A/B$ are better represented in all three seeds; this endpoint reversal also holds for the worst and best positions in each cycle (Appendix E).
In one out of the three sensitivity-analysis configurations, the increase in representation of $A/B$ ’s features is within the error bars (see Appendix D).

## 6 Testing the Steering Predictions

We now test the two steering predictions from Section 4.2.
Since selection operates jointly, we examine how steering that targets features of a single image affects both their predictive partners and competing features.
Both experiments use the two-pair setup from Section 5.2, keeping the sequence’s predictive relationships, image pool, three-dimensional main latent representation, and training budget unchanged.
We measure image-detection accuracy from the frozen main encoder alone, training probes on collages of images held out from encoder training and evaluating them on separate collages.
Chance decoding accuracy is $50\%$ for each feature individually.

## 6.1 An Auxiliary Reconstruction Objective

Auxiliary objectives have been proposed to steer JEPA representations toward task-relevant information (LeCun, 2022; Destrade et al., 2025; Zhu et al., 2026; Vujinovic and Kovacevic, 2026).
An auxiliary reconstruction objective encourages the encoder to retain features of the image being reconstructed.
Section 4.2 predicts that this incentive will also favor their predictive partners, at the expense of competing features.

## Steering.

To test this prediction, we add an auxiliary objective that reconstructs a coarse version of the current $C$ image from the main latent representation; only $C$ is a reconstruction target, and the decoder is discarded before probing.
We vary the reconstruction weight $\beta$ across all five original values of $p_{D}$ , using one optimization seed.
The nonzero weights come from a preliminary search with both $C$ and $D$ as reconstruction targets (Appendix B.4).

## Results.

Rewarding reconstruction of $C$ alone can make $D$ ’s features more strongly represented and $A/B$ ’s less so (Figure 5).
At the largest weight, $D$ , which is never reconstructed, is decoded almost as accurately as $C$ at every $p_{D}$ .
This supports the prediction that steering can affect representation beyond the directly targeted features.

Figure 5: Reconstructing one image can strengthen representation of its predictive partner.
The changes are not uniformly monotonic, and the baseline already favors $C/D$ at high $p_{D}$ .
Each cell uses one optimization seed; all panels use the same $50$ – $90\%$ color scale.

## 6.2 Predictor Side Information

Supplying information directly to the predictor changes how well it can predict different features.
Section 4.2 predicts that this can strengthen the representation of features whose next values the additional information helps predict.

## Steering.

To test this prediction, we supply the current $C$ image through an additional predictor input, without an auxiliary loss or masking it from the main input.
A separate encoder with the same architecture as the main encoder maps $C$ to a three-dimensional vector, which we concatenate with the main latent representation before prediction; this adds encoder capacity while leaving the main representation’s dimension unchanged.
The side encoder is trained jointly with the main encoder and predictor through the prediction loss; SIGReg is applied only to the main latent representation.
We evaluate all five values of $p_{D}$ , paired with their no-side-input controls.
We validate these systems’ predictive performance in Appendix C.

## Results.

Supplying $C$ changes how well features of the other images are represented, but produces a different redistribution from reconstruction (Figure 6).
For most values of $p_{D}$ , we see an increase in the representation of $D$ ’s features and a decrease in that of $B$ ’s, while representation of $A$ ’s features increases throughout the sweep.
These changes support the steering prediction for $D$ ; predictive closure does not account for $A$ and $B$ separating, since it values them only as a pair.
Low decoding accuracy from the main latent alone does not establish that a feature is unavailable to the predictor: information about $C$ or other features may be recoverable jointly from the main and side representations.

Figure 6: Supplying $C$ to the predictor can strengthen representation of its predictive partner $D$ .
Data and probe tasks are matched; probes use only the main latent.
 $D$ becomes more represented for $p_{D}\geq 0.75$ and less at $p_{D}=0.60$ , where $C$ is least often copied to $D$ ; $C$ becomes less represented at the highest $p_{D}$ .
Dotted line: $50\%$ chance.

## 6.3 Implications for representation learning

## Action conditioning.

In action-conditioned JEPA, the predictor receives the agent’s action alongside the current latent.
If we view the side information as an action, features that the agent has an impact on are more likely to be represented.
The action helps predict their future values, so the sets that include them gain the predictive information induced by their relationships with the action (Appendix A.6).
Features that the agent does not affect gain no such information and are less likely to be represented, unless they are predictive partners of features the agent affects.
In our side-information experiment, $C$ plays the role of the action and $D$ of a feature it affects: for $p_{D}=0.75,0.85,0.95$ , supplying $C$ strengthens representation of $D$ .
The consequences of genuine action conditioning remain to be tested.

## Steering through extracted information.

A practitioner can instead choose side information specifically to steer predictive closure.
If a desired set of predictive features is poorly represented and one of its features can be extracted from the observation, supplying that feature to the predictor may strengthen representation of the features whose next values it helps predict.
Our side-information experiment illustrates this possibility: supplying $C$ can strengthen representation of $D$ without directly supervising $D$ .
The mixed changes across the remaining features show why steering should be evaluated against all features needed downstream.

## Steering can be indirect.

Both forms of steering target only $C$ , yet both can strengthen representation of $D$ .
This shows that steering can be indirect: it need not target the desired feature itself.
Indirect steering is particularly useful when a related feature can be targeted but no loss can be written for the desired feature.
An auxiliary loss can target a feature that helps predict its next values, or one whose next values it helps predict; side information can supply only a feature of the first kind.
For example, an object’s velocity determines where the object will be next, so an auxiliary loss on its velocity, or supplying the velocity to the predictor, can strengthen the representation of its position.

## 7 Conclusion

We characterize JEPA representation learning through the joint predictive value of feature sets.
We reformulate the training objective as selecting a predictive closure: a feasible feature set that maximizes the mutual information between its features’ current values and their next values.
This view explains earlier findings on other JEPA systems, and our experiments match its predictions: an unpredictable feature becomes more decodable when it helps predict others, and changing a competing set can weaken a feature’s representation even when its own predictive relationships are unchanged.
Experiments with auxiliary objectives and predictor side information further show that targeting one feature can strengthen the representation of its predictive partners, so steering can be indirect.
If we view actions as side information, predictive closure also suggests that action-conditioned JEPA favors the features an agent has an impact on.
These experiments illustrate how this view can inform the design of JEPA systems to better represent task-relevant features.
Our experiments test the direction of each predicted effect; measuring its size in large JEPA systems trained on natural data remains for future work.
This set-level view may also be relevant to models of biological representation learning that link representation to prediction (Palmer et al., 2015; Chalk et al., 2018; Singer et al., 2023).
We hope predictive closure provides a clearer way to reason about which features JEPA encodes and informs the design and use of these systems in downstream tasks.

## Appendix A Formalization of Predictive Closure

We provide a supporting derivation for the predictive-closure characterization in Equation (2) of Section 3.
We first give the definitions and assumptions, then connect prediction loss to mutual information and express the resulting objective in terms of feature sets.

## A.1 Definitions and Assumptions

We use features to describe observations through identifiable properties, such as the traffic light’s color or whether the cyclist is riding or stopping.
This lets us characterize what JEPA encodes in terms of those properties and their predictive relationships.
The latent could also be described by which observations it maps to the same representation, so that the latent is defined by what it omits: whatever differs among observations that share a representation (Givan et al., 2003; Li et al., 2006).

## Features.

A feature $\phi_{i}$ describes a property of an observation, such as the traffic light’s color or the cyclist’s speed.
Formally, $\phi_{i}$ is a mapping from observations to scalar values, and we write $y_{t}^{i}=\phi_{i}(x_{t})$ for its value at time $t$ .
This excludes properties that cannot be inferred from the observation, such as which watch the cyclist wears when it is completely hidden and no other clues reveal it.
Different mappings define different features.
For example, a mapping that matches whether the cyclist is riding or stopping on some observations but not others defines a different feature.
A feature set $S=\{\phi_{1},\ldots,\phi_{m}\}$ is a collection of these mappings.
We write $Y_{t}(S)=(\phi_{i}(X_{t}))_{\phi_{i}\in S}$ for their values on an observation $X_{t}$ at time $t$ .
Likewise, a reader $d$ is a mapping from latents to scalar values, like those the predictor or a downstream model uses to read values off the latent.

## Represented feature sets.

We say that a feature $\phi_{i}$ is represented in the latent $f(x_{t})$ when a reader $d_{i}$ whose output changes only slightly under small changes to the latent (formalized in Appendix A.3) recovers its value across observations: $d_{i}(f(x_{t}))=y_{t}^{i}$ for all $t$ .
We write $S(f)$ for the complete set of features recoverable in this way from the latent produced by encoder $f$ .

## Fixed latent entropy.

Representing a feature requires capacity (Klindt et al., 2026) and we assume that all encoders match the same Gaussian target prescribed by regularization at each time, with $P$ denoting a finite-precision latent distribution.
44
 4

 All encoders use the same numerical precision, and readers access the stored values. This idealizes the distribution matching encouraged by regularizers such as SIGReg, for which Balestriero and LeCun (2025, Section 4.3) provide empirical support.
The shared distribution fixes the Shannon entropy of the latent distribution $H(P)$ , which we refer to as the latent’s entropy constraint.
We assume that the entropy constraint $H(P)$ is less than the observations’ entropy so not all features can be represented. We call a feature set $S$ feasible when some encoder represents all of its features and $H(Y_{t}(S))=H(P)$ .
The complete set $S(f)$ of any encoder $f$ is feasible, since its values and the latent determine one another, so that $H(Y_{t}(S(f)))=H(f(X_{t}))=H(P)$ (Appendix A.3).
If we could directly choose which features are represented, adding a feature that provides new information would require removing others to keep the resulting set feasible.

Throughout, the prescribed distribution $P$ and latent dimension $k$ are fixed across encoders.

## A.2 Prediction Loss and Information

Because the regularization term in Equation (1) depends only on the distribution of $f(X_{t})$ , which is $P$ for every encoder, an encoder minimizes the training objective exactly when it minimizes the prediction loss.
Under a Gaussian prediction-error assumption, we show that minimizing expected squared prediction error is equivalent to maximizing the mutual information between consecutive representations.
We write $f^{\star}$ for any such encoder:

 $f^{\star}\in\operatorname*{arg\,min}_{f}\;\min_{g}\,\mathbb{E}\left\|g(f(X_{t}))-f(X_{t+1})\right\|_{2}^{2}=\operatorname*{arg\,max}_{f}\;I\bigl(f(X_{t});f(X_{t+1})\bigr).$ 

(4)

The expectation is over consecutive observation pairs.

## Prediction-error assumption.

Write $Z_{t}=f(X_{t})$ .
We assume that all encoders produce $k$ -dimensional latents with the same marginal distribution $P$ , whose Shannon entropy $H(P)$ is finite.
For each encoder $f$ , assume that among the functions the predictor network can represent there is a predictor $g_{f}$ such that, at the latent’s numerical resolution,

 $Z_{t+1}\mid Z_{t}=z\sim\mathcal{N}\!\left(g_{f}(z),\sigma_{f}I_{k}\right),$ 

(5)

where $\sigma_{f}>0$ is a scalar variance that may differ between encoders.

## Proof.

For each current latent, squared prediction error is minimized by the mean of this Gaussian, which $g_{f}$ predicts.
Each error coordinate has zero mean and variance $\sigma_{f}$ , so its expected squared error is $\sigma_{f}$ .
Summing over the $k$ coordinates gives

 $\min_{g}\mathbb{E}\left\|Z_{t+1}-g(Z_{t})\right\|_{2}^{2}=k\sigma_{f}.$ 

(6)

The conditional Gaussian distribution has entropy

 $h(Z_{t+1}\mid Z_{t})=\frac{k}{2}\log(2\pi e\sigma_{f}).$ 

(7)

At the latent’s fixed numerical precision, we assume the discrete conditional entropy equals this Gaussian value plus an additive correction $c$ shared across encoders.
( $c$ comes from rounding the continuous latent to that precision, so it depends only on the precision.)
Since the next latent has the fixed marginal distribution $P$ ,

 $\displaystyle I(Z_{t};Z_{t+1})$ 
 $\displaystyle=H(P)-H(Z_{t+1}\mid Z_{t})$ 

(8)

 $\displaystyle=H(P)-\frac{k}{2}\log(2\pi e\sigma_{f})-c.$ 

Because $H(P)$ , $k$ , and $c$ are fixed, predictive information is strictly decreasing in $\sigma_{f}$ , and so in the optimized prediction error $k\sigma_{f}$ .
Therefore, minimizing expected squared prediction error and maximizing predictive information select exactly the same encoders.
Without the Gaussian assumption, and with the same precision correction $c$ , Equation (8) holds with $\geq$ in place of its second equality for every encoder that matches $P$ , with $\sigma_{f}$ taken as its optimized prediction error divided by $k$ , because among distributions with a given summed variance the isotropic Gaussian has the largest entropy (averaging over $Z_{t}$ uses the concavity of the logarithm).
Minimizing the prediction loss then maximizes a lower bound on the mutual information between consecutive latents.

## A.3 From Representations to Feature Sets

We now write the objective of Equation (4) in terms of the complete set $S(f)$ .

## Reader condition.

For $Z=f(X_{t})\sim P$ , we control reader sensitivity using common tolerances $\varepsilon,\delta>0$ and $0<\alpha<1$ , keeping these tolerances unchanged across encoders:

 $\Pr\!\left[\sup_{\|z^{\prime}-Z\|_{2}\leq\varepsilon}|d(z^{\prime})-d(Z)|>\delta\right]\leq\alpha.$ 

Thus, latent perturbations of size at most $\varepsilon$ change the reader’s output by at most $\delta$ , except on a set of probability at most $\alpha$ .
We require exact recovery from the unperturbed latent.

## Information preservation.

The latent determines every feature value in $Y_{t}(S(f))$ .
Conversely, the readers $d_{j}(z)=(\delta/\varepsilon)z_{j}$ , for $j=1,\ldots,k$ , satisfy the sensitivity condition everywhere, so the corresponding features $x\mapsto d_{j}(f(x))$ belong to $S(f)$ .
Their values recover every latent coordinate.
The latent and the values $Y_{t}(S(f))$ therefore determine one another, so they carry the same information, and their mutual information across consecutive observations is equal:

 $I\bigl(f(X_{t});f(X_{t+1})\bigr)=I\bigl(Y_{t}(S(f));Y_{t+1}(S(f))\bigr).$ 

(9)

The same equality holds for every feasible set $S$ , with $f$ an encoder that represents it: the latent determines the values $Y_{t}(S)$ , and a function of the latent that keeps its entropy $H(P)$ is one-to-one, so these values also determine the latent.
This equality and Appendix A.2 together show that $S(f^{\star})$ maximizes predictive information over feasible feature sets, proving Equation (2).

## A.4 Aleatoric Uncertainty and Predictive Leakage

For a feature set $S$ , we write $Y_{t}=Y_{t}(S)$ and $Y_{t+1}=Y_{t+1}(S)$ .
By definition,

 $I(Y_{t};Y_{t+1})=H(Y_{t+1})-H(Y_{t+1}\mid Y_{t}),$ 

and for a feasible set the first term is $H(P)$ .
Conditional mutual information is defined in the same way, given $Y_{t}$ :

 $I(X_{t};Y_{t+1}\mid Y_{t})=H(Y_{t+1}\mid Y_{t})-H(Y_{t+1}\mid X_{t},Y_{t}).$ 

Because $Y_{t}$ is computed from $X_{t}$ , knowing $X_{t}$ already means knowing $Y_{t}$ , so $H(Y_{t+1}\mid X_{t},Y_{t})=H(Y_{t+1}\mid X_{t})$ and

 $H(Y_{t+1}\mid Y_{t})=H(Y_{t+1}\mid X_{t})+I(X_{t};Y_{t+1}\mid Y_{t}).$ 

Substituting this into the first equation gives

 $I(Y_{t};Y_{t+1})=H(P)-H(Y_{t+1}\mid X_{t})-I(X_{t};Y_{t+1}\mid Y_{t}),$ 

(10)

so among feasible sets, maximizing predictive information is the same as minimizing the sum of the last two terms, as in Equation (3).

## A.5 Relation to Per-Feature Selection

For a feature set $S$ and a feature $\phi\notin S$ , we write $Y_{t}=Y_{t}(S)$ and $\phi_{t}=\phi(X_{t})$ .
By the chain rule of mutual information, adding $\phi$ to $S$ changes the set’s predictive information by

 $\Delta(\phi\mid S)\coloneqq I_{\mathrm{pred}}(S\cup\{\phi\})-I_{\mathrm{pred}}(S)=I\bigl(\phi_{t};Y_{t+1}\mid Y_{t}\bigr)+I\bigl((Y_{t},\phi_{t});\phi_{t+1}\mid Y_{t+1}\bigr),$ 

(11)

and changes its entropy by $H(\phi_{t}\mid Y_{t})$ , the entropy cost of $\phi$ .
The first term is the information that $\phi$ ’s current value adds about the set’s future.
The second is the information that the set’s present, together with $\phi$ ’s, provides about $\phi$ ’s future beyond the set’s own future.
Both terms and the entropy cost generally depend on $S$ .
In optimization terminology, predictive information is generally a non-additive, or non-modular, set objective: its value depends on the combination of selected features rather than a sum of fixed individual contributions.

## Independent features.

Suppose features $\phi_{1},\ldots,\phi_{n}$ evolve independently, so that the pairs $(\phi_{i}(X_{t}),\phi_{i}(X_{t+1}))$ are mutually independent across $i$ .
For a set $S$ of these features and $\phi_{j}\notin S$ , the first term of Equation (11) vanishes, the second equals $I(\phi_{j}(X_{t});\phi_{j}(X_{t+1}))$ , and the entropy cost equals $H(\phi_{j}(X_{t}))$ , none of which depends on $S$ .
Hence

 $I_{\mathrm{pred}}(S)=\sum_{\phi_{i}\in S}I\bigl(\phi_{i}(X_{t});\phi_{i}(X_{t+1})\bigr),\qquad H\bigl(Y_{t}(S)\bigr)=\sum_{\phi_{i}\in S}H\bigl(\phi_{i}(X_{t})\bigr).$ 

If these features all have the same entropy and $H(P)$ is $k$ times it, then every feasible set formed from whole features $\phi_{i}$ contains $k$ of them, and the one with the greatest predictive information consists of the $k$ features with the greatest individual predictive information $I(\phi_{i}(X_{t});\phi_{i}(X_{t+1}))$ .
Selection among such sets then reduces to ranking individual features.
With unequal entropies, it becomes a knapsack problem in which each feature’s value and cost are still independent of the other features selected.

## Dependent features.

For the traffic light $L$ of Section 5.1 and a set $S$ of image features, $L_{t+1}$ is independent of $(Y_{t},L_{t},Y_{t+1})$ , so $\Delta(L\mid S)=I(L_{t};Y_{t+1}\mid Y_{t})$ .
This contribution is zero unless $S$ contains the images whose persistence the light controls, while its entropy cost $H(L_{t}\mid Y_{t})$ is one bit at every $q$ .
In the cycle of Section 5.3, the information an image carries through its copy link counts only when the image it is copied to is also in the set.
A set holding part of a long cycle therefore keeps only the links whose two ends it contains.

## A.6 Side Information

Section 4.2 considers a predictor that also receives side information $U_{t}$ , so that it predicts $f(X_{t+1})$ by $g(f(X_{t}),U_{t})$ .
We derive how this changes the two terms of Equation (3).
For a feature set $S$ , we again write $Y_{t}=Y_{t}(S)$ and $Y_{t+1}=Y_{t+1}(S)$ .

## Objective.

We extend the prediction-error assumption of Appendix A.2 to condition on both predictor inputs: writing $Z_{t}=f(X_{t})$ , for each encoder $f$ there is a predictor $g_{f}$ such that

 $Z_{t+1}\mid Z_{t}=z,\,U_{t}=u\sim\mathcal{N}\!\left(g_{f}(z,u),\sigma_{f}I_{k}\right).$ 

The proof in Appendix A.2 then holds with $U_{t}$ added to every condition, so the optimized prediction error is strictly increasing in $H(Z_{t+1}\mid Z_{t},U_{t})$ .
Because the latent and the values of the complete represented set determine one another (Appendix A.3), this entropy equals $H(Y_{t+1}\mid Y_{t},U_{t})$ for $S=S(f)$ .
An ideally trained encoder therefore represents a feasible set that minimizes $H(Y_{t+1}\mid Y_{t},U_{t})$ , which is the same as maximizing $I\bigl((Y_{t},U_{t});Y_{t+1}\bigr)=H(P)-H(Y_{t+1}\mid Y_{t},U_{t})$ .

## The two terms.

The steps of Appendix A.4 hold with $U_{t}$ added to every condition.
By the definition of conditional mutual information,

 $I(X_{t};Y_{t+1}\mid Y_{t},U_{t})=H(Y_{t+1}\mid Y_{t},U_{t})-H(Y_{t+1}\mid X_{t},Y_{t},U_{t}),$ 

and because $Y_{t}$ is computed from $X_{t}$ , the last term equals $H(Y_{t+1}\mid X_{t},U_{t})$ , so

 $H(Y_{t+1}\mid Y_{t},U_{t})=H(Y_{t+1}\mid X_{t},U_{t})+I(X_{t};Y_{t+1}\mid Y_{t},U_{t}).$ 

(12)

The minimized quantity is thus the sum of the two terms of Equation (3), each computed given $U_{t}$ as well.

## Change in each term.

By the definition of conditional mutual information, supplying $U_{t}$ lowers the sum by

 $H(Y_{t+1}\mid Y_{t})-H(Y_{t+1}\mid Y_{t},U_{t})=I(U_{t};Y_{t+1}\mid Y_{t}),$ 

which is what $U_{t}$ tells about the set’s next values beyond the set’s current values, so sets for which this quantity is larger are favored.
Supplying $U_{t}$ lowers the aleatoric uncertainty by

 $H(Y_{t+1}\mid X_{t})-H(Y_{t+1}\mid X_{t},U_{t})=I(U_{t};Y_{t+1}\mid X_{t}),$ 

which is what $U_{t}$ tells about the set’s next values beyond the whole current observation.
When $U_{t}$ is derived from the observation, knowing $X_{t}$ already means knowing $U_{t}$ , so this second quantity is zero.
The aleatoric uncertainty is then unchanged, and the whole reduction comes from the predictive leakage:

 $I(X_{t};Y_{t+1}\mid Y_{t},U_{t})=I(X_{t};Y_{t+1}\mid Y_{t})-I(U_{t};Y_{t+1}\mid Y_{t}).$ 

When $U_{t}$ is not determined by the observation, as with an action, the second quantity can be positive.
For example, an agent’s next position can be uncertain given the whole current observation and certain once its action is known.

## Appendix B Experimental Setup and Evaluation Details

## B.1 Shared training and probing protocol

In each experiment in Section 5, we vary a single design parameter while keeping the remaining data-generation rules fixed.
At each value of the varied parameter, we train the same end-to-end JEPA from scratch on sequences of collages composed of CIFAR-10 images, using a three-dimensional latent and the objective $0.9\mathcal{L}_{\mathrm{pred}}+0.1\mathcal{L}_{\mathrm{SIGReg}}$ (Balestriero and LeCun, 2025).
Training draws from a class-balanced set of 5,000 images from the official training split; after training, we freeze the encoder and train probes to decode designated features from newly sampled collages drawn from a disjoint class-balanced set of 5,000 test images.

## Architecture and gradients.

The encoder has four $3\times 3$ convolution/ReLU/ $2\times 2$ max-pooling blocks with 32, 64, 128, and 256 channels, followed by a $4096\to 1024\to 3$ projection with a GELU hidden activation.
The group-size encoder additionally uses adaptive max-pooling to produce a $4\times 4$ spatial output.
Predictors use $3\to 16\to 16\to 3$ GELU MLPs, with six inputs for side information; the reconstruction decoder is an affine $3\to 48$ map.
We share the main encoder across frames and backpropagate through both prediction-loss branches, without stop-gradient.
All JEPA systems train with AdamW at learning rate $10^{-3}$ with cosine decay to $10^{-5}$ , and SIGReg uses 1,024 random projections.

## B.2 Two-image traffic-light setup and readouts

To vary the light’s usefulness for predicting the next transition while keeping each image’s marginal persistence fixed, we let the light control which image is replaced.
The two $32\times 32$ -pixel images occupy the upper row of a $64\times 64$ -pixel canvas, and a $4\times 4$ -pixel light patch appears in the lower-right quadrant; the remaining pixels are black.
Each transition replaces exactly one image with a different identity; the current light selects the position with probability $q$ , and a uniform draw selects it otherwise.
The light is sampled independently and uniformly at every frame.
Consequently, each image persists with marginal probability $0.5$ at every $q$ , while the light identifies the replaced position with probability $(1+q)/2$ .
We train three runs at each $q\in\{0,0.25,0.5,0.75,1\}$ , each for 25 epochs of 100,000 eight-frame sequences with batch size 512.

A two-hidden-layer probe of width 16 decodes the current light from the frozen current-frame latent, using separately sampled training, validation, and test datasets containing 20,000, 5,000, and 5,000 examples from the held-out image pool, respectively.
The probe trains for 1,200 steps with batch size 512; chance accuracy is $50\%$ .

## B.3 Setups and readouts for the two-pair and cycle experiments

## Changing predictability.

The two-pair setup groups image identities into $\{A,B\}$ and $\{C,D\}$ at the four locations of a $2\times 2$ collage.
Within each pair, an image identity can be copied to the other position in the next frame: $B_{t}$ determines $A_{t+1}$ with probability $1$ , $A_{t}$ determines $B_{t+1}$ with probability $0.6$ , and $D_{t}$ determines $C_{t+1}$ with probability $0.9$ .
The probability $p_{D}$ that $C_{t}$ determines $D_{t+1}$ is the only parameter we vary; when a copy does not occur, the next image is sampled independently.
We train three runs at each $p_{D}\in\{0.60,0.75,0.85,0.95,1\}$ , each for 25 epochs of 100,000 eight-frame sequences with batch size 512.

## Changing group size.

The $A/B$ cycle is fixed at two identities with copy probability $0.85$ , and the competing $C/D$ cycle has $N\in\{2,4,8,16\}$ identities, ordered $C,D,E,F,\ldots$ through the first $N$ positions, with copy probabilities alternating between $0.90$ and $0.96$ .
Thus the average per-feature copy probabilities remain $0.85$ for $A/B$ and $0.93$ for $C/D$ at every size.
We train three runs per configuration, each for 100 epochs of 100,000 eight-frame sequences, with batch size 512 and a three-dimensional latent.
Within each design, $\{A,B\}$ remains unchanged, allowing us to assess whether changes in the competing group alter its representation.
We used the first run during configuration development and kept the configuration unchanged for the two replications; all three runs share the image pools and data-generation randomness.

## Rendering control.

Keeping individual image size fixed would make the larger $C/D$ group occupy more of the input, confounding feature count with the group’s total spatial extent.
We therefore keep the $128\times 256$ -pixel canvas and the two native $32\times 32$ -pixel $A/B$ images fixed, while distributing approximately the same total displayed area among the $C/D$ images.
To avoid removing image detail through downsampling, we use the native CIFAR-10 resolution as the minimum tile size and enlarge images when fewer positions share this area.
For $N=2,4,8,16$ , individual $C/D$ images have side lengths of 90, 64, 45, and 32 pixels, respectively, giving occupied areas of 16,200, 16,384, 16,200, and 16,384 pixels, which differ by less than $1.2\%$ .
The $C/D$ images occupy centered row-major grids of $1\times 2$ , $2\times 2$ , $2\times 4$ , and $4\times 4$ within the same right-hand region; unused pixels remain black.
Larger tiles use bilinear enlargement of the native CIFAR-10 images, without cropping or reducing any image below its original resolution.
Enlargement is greatest at $N=2$ and goes back to the original size at $N=16$ .
Tile scale and layout still change with $N$ , so this control does not isolate representation cost from the difficulty of extracting the images’ information.

## Image-detection probes.

To assess image-identity information in the latent, we train target-image presence detectors separately for each fixed position.
The group-size experiment uses the same primary image-detection probe architecture, per-detector training budget, and held-out image pool as the four-image predictability and steering experiments.
We train a separate binary classifier for each of 50 target images at every fixed position, with five targets per CIFAR-10 class.
Each classifier receives only the frozen latent representation: positive examples contain its target at the designated position, while negative examples exclude that target everywhere and use a different image of the same class at the designated position.
Other positions are sampled independently, excluding the target.
Because negative examples exclude the target everywhere, a representation of the unordered images within a pair could pass both position-associated probes without distinguishing their positions.
These readouts measure target-image detection under the stated sampling protocol and do not establish position binding.

Each detector has two hidden layers of width 16 and trains for 1,000 steps with batch size 128 on 512 training examples, with 512 validation and 1,024 test examples, balanced between positive and negative cases.
We use AdamW with learning rate $10^{-3}$ decaying to $10^{-5}$ , 50 warmup steps, weight decay $10^{-4}$ , gradient clipping at 10, and the same probe optimization seed across comparisons.
Latent coordinates are standardized using 100,000 separately sampled collages from the held-out image pool.
All probe images are unseen during encoder training; target identities recur across probe training, validation, and testing, while the collages are sampled separately from the same held-out pool.
We report ordinary binary classification accuracy at the zero-logit threshold, with chance accuracy $50\%$ .
Increasing the number of positions increases the number of independent detectors, rather than reducing the training or evaluation budget per position.
We first average accuracy over target images within each position, then average positions within each group, and finally report the mean and standard error across optimization seeds.

## B.4 Steering interventions

Both interventions use the two-pair setup, keeping the sequence’s predictive relationships, image pool, three-dimensional main latent representation, and training budget unchanged.
Held-out image-detection probes receive only the frozen main encoder’s representation.

## Auxiliary reconstruction.

To directly reward retaining information about $C$ , we add an auxiliary reconstruction objective.
The decoder reconstructs a standardized $4\times 4$ average-pooled version of the current $C$ image from the current latent representation, giving the objective $0.9\mathcal{L}_{\mathrm{pred}}+0.1\mathcal{L}_{\mathrm{SIGReg}}+\beta\mathcal{L}_{\mathrm{recon}}^{C}$ .
Only $C$ is a reconstruction target; the decoder is discarded before probing.
The four nonzero weights were identified in a preliminary search at $p_{D}=0.75$ with both $C$ and $D$ as reconstruction targets.
We then evaluate reconstruction of $C$ alone at $\beta\in\{0,\allowbreak 0.0425,\allowbreak 0.105,\allowbreak 0.135,\allowbreak 0.36\}$ and all five original values of $p_{D}$ , using one optimization seed.

## Predictor side information.

To examine how direct predictor access to $C$ changes the main representation, we supply the current $C$ image through a separate encoder.
The side encoder has the same architecture as the main encoder and maps the current $32\times 32$ -pixel $C$ image, bilinearly enlarged to $64\times 64$ pixels, to a three-dimensional vector.
We concatenate this vector with the current main latent to form the predictor’s six-dimensional input; its target remains the next-frame main latent.
The main encoder continues to receive the full collage, including $C$ , and retains its three-dimensional output.
Training uses $0.9\mathcal{L}_{\mathrm{pred}}+0.1\mathcal{L}_{\mathrm{SIGReg}}$ , with the side encoder trained through the prediction loss and SIGReg applied only to the main latent.
This intervention adds encoder capacity while keeping the main latent dimension fixed.
We evaluate all five values of $p_{D}$ with three training runs per condition, paired with their corresponding no-side-input controls.

## Appendix C Next-Observation Prediction

To validate that the JEPA systems learned to predict, we test whether their predictions distinguish the actual next observation from an alternative.
We evaluate the traffic-light systems trained with light-control probability $q=1$ , in which the current light always determines which image is replaced (Section 5.1).
We also evaluate the two-pair systems at all five values of $p_{D}$ , the probability that $C_{t}$ is copied to $D_{t+1}$ (Section 5.2).
For these, we test both the ordinary systems and those whose predictor also receives the current $C$ image as side information (Section 6.2).
Training settings follow Appendix B.

We evaluate each trained system on $5{,}000$ transitions generated from images held out from encoder training, using the same transitions across runs.
For each transition, the system predicts the latent of the next observation from the current observation $x_{t}$ .
We count the prediction as correct if it is closer, in squared Euclidean distance, to the latent $f(x_{t+1})$ of the actual next observation than to the latent $f(\tilde{x})$ of an alternative observation $\tilde{x}$ .
We draw $\tilde{x}$ from the same distribution as the observations and redraw it whenever the transition rules allow it to follow $x_{t}$ .
It is therefore as likely as $x_{t+1}$ overall and differs from it only in that it cannot follow $x_{t}$ .
As a control, we shuffle predictions across transitions while keeping the actual and alternative observations fixed, so that each prediction comes from an unrelated current observation.

In every tested setting, the systems identify the actual next observation well above chance, whereas shuffled predictions remain near chance (Table 1).

(13)
