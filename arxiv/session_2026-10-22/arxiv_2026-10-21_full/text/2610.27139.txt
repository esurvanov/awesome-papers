Abstract

We encounter a system through its responses, yet its state concerns how the system is. Predicting further responses promises knowledge beyond what is immediately observed. What that knowledge tells us about the system’s state depends on what we mean by a state in the first place. We give this notion a model-relative meaning: a state is the complete response profile over a specified query universe, and configurations agreeing on every query are regarded as the same state. From this perspective, a learned state is understood through the distinctions between these profiles that it retains. Prediction concerns selected observations; recovery concerns the profile as a whole. We examine their relationship through query ambiguity, state-space geometry, and the choice of prediction targets. Synthetic systems with known response laws and neural recordings provide complementary settings for this investigation. The aim is to clarify how prediction can become a way of knowing a system, and what it would mean for a learned state to preserve the state being studied.

## 1 Introduction

Figure 1: From observation to prediction. The encoder maps input observations to a learned state; the predictor estimates observations at the target queries.

Learning a system’s state requires deciding which differences between its possible conditions matter. Knowing that state would let us reason beyond the aspects we happen to observe. For an animal, a neural recording offers one such view: a pattern of activity from which we seek to understand the condition that gives rise to it (Cunningham and Yu, 2014; Churchland et al., 2012). Giving this underlying condition a precise meaning is part of the problem of knowing it.

Predicting further observations offers a way to study this problem. Neural population models learn to predict held-out activity (Pei et al., 2021), and models trained across recordings use related objectives to support downstream decoding (Ye et al., 2023). A learned state is useful here because it carries information about observations beyond its input.

“When does learning to predict a system amount to learning its state?”

We make this question precise relative to a query universe. A query specifies what is measured, and an observation is the resulting value. Within that universe, the ontic state is the complete response profile: configurations agreeing on every query count as the same state. In a neural recording, a query specifies a unit and a trailing-window duration. An encoder maps input observations to a learned state, from which a predictor estimates observations at target queries (figure 1). Theoretical work relates auxiliary prediction and context learning to downstream performance (Lee et al., 2021; Zhai et al., 2025). We ask how much of the ontic state can be recovered from the learned state that supports these predictions.

Consider targets that all depend on one coordinate of a state. Exact prediction constrains that coordinate while leaving the others free. Query ambiguity measures the unresolved state differences. It connects the distinctions tested by prediction to the profile we seek to recover.

This connection motivates three contributions:

1. 

Ontic-state formulation. We formulate ontic states as complete response profiles over a query universe.

2. 

Recovery guarantees. We establish prediction–recovery guarantees in both general settings and the low-dimensional settings commonly studied in neuroscience.

3. 

Fixed-family sharpness. We prove matching budget bounds on a fixed state family, distinguishing targets shared across encoders from targets tailored to each encoder.

## 2 Ontic State

## 2.1 State, Query, and Observation

Figure 2: State, query, and observation. The state $f\in\mathcal{F}$ and query set $Q=\{q_{1},q_{2}\}\subseteq\mathcal{U}$ determine the observation vector $f(Q)$ . Its entries are $f(q_{1})$ and $f(q_{2})$ ; unlabeled points denote queries outside $Q$ .

What does it mean for a system to be in a particular state, independently of how we describe it? We need a criterion of identity. Leibniz’s account of individual substance locates identity in a complete concept determining the predicates of its subject (Leibniz, 1686). For a scientific account of state, which properties should determine this identity?

We give these properties empirical meaning through the observations the system could produce (Peirce, 1878; James, 1907). Each query specifies one such observation. Two configurations may agree in position and differ in velocity: whether we distinguish them depends on the queries admitted. We therefore fix a query universe before defining its states.

If no question in this universe can distinguish two putative states, we regard them as one ontic state: a difference in description alone does not constitute a difference in state. Their common response profile fixes this identity independently of the coordinates used to represent it (Poincaré, 1905). An experiment reveals part of the profile, while the state specifies responses throughout the universe. We thus model a state as a function from queries to observations.

Definition 2.1 (Ontic State).

An ontic state is an admissible bounded function

 $f:\mathcal{U}\to\mathbb{R},$ 

(1)

where $\mathcal{U}$ is a fixed nonempty set. The collection $\mathcal{F}$ of all admissible ontic states is called the ontic state space.

Definition 2.2 (Query Universe).

The common domain $\mathcal{U}$ of the ontic states is called the query universe, and its elements are called queries. For $f\in\mathcal{F}$ and $q\in\mathcal{U}$ , the value $f(q)$ is the observation returned by query $q$ in state $f$ .

An experiment records responses to a finite set of queries. We collect these readings into an observation vector.

Definition 2.3 (Observation).

A query set is a nonempty finite subset $Q\subseteq\mathcal{U}$ . The observation vector of a state $f\in\mathcal{F}$ on $Q$ is

 $f(Q)\coloneqq\bigl(f(q)\bigr)_{q\in Q}\in\mathbb{R}^{Q}.$ 

(2)

Here $\mathbb{R}^{Q}$ denotes real-valued vectors indexed by $Q$ .

To compare two profiles, we ask how far their responses can differ over the queries being considered. Taking the largest difference gives a common distance for full states and finite observation vectors.

Definition 2.4 (Ontic Distance).

For a nonempty index set $I$ and bounded real-valued functions $u,v$ whose domains contain $I$ , define their distance on $I$ by

 $d_{I}(u,v)\coloneqq\sup_{i\in I}|u(i)-v(i)|.$ 

(3)

This is the supremum metric between their restrictions to $I$ . Vectors are functions on their index set; for finite $I$ , the supremum is a maximum.

The ontic distance is $d_{\mathcal{U}}(f,g)$ ; the observation distance on $Q$ is $d_{Q}(f(Q),g(Q))$ . The latter is a metric on observation vectors and a pseudometric on states, since distinct states can yield identical observations on $Q$ .

Figure 2 shows how a state and query set determine an observation vector. The noisy extension treats the profile as a conditional mean response and measured activity as a noisy observation (appendix E).

## 2.2 Query Ambiguity

A complete response profile defines a state, but how much of it do our observations determine? Hume’s question about inference beyond present observation brings this gap into focus (Hume, 1902, sec. IV). Within a specified model class, optimal recovery makes the uncertainty quantitative (Micchelli and Rivlin, 1977; Binev et al., 2024). We ask how different two full states can be when their recorded observations agree within a given tolerance.

Definition 2.5 (Query Ambiguity).

Fix a query set $Q\subseteq\mathcal{U}$ . For a tolerance $r\geq 0$ , define the query ambiguity on $Q$ by

 $\omega_{Q}(r)\coloneqq\sup_{\begin{subarray}{c}f,g\in\mathcal{F}\\
d_{Q}(f(Q),g(Q))\leq r\end{subarray}}d_{\mathcal{U}}(f,g).$ 

(4)

At $r=0$ , ambiguity measures the state differences compatible with identical observations on $Q$ . Positive tolerances allow for prediction error. An observation decoder recovers a state from the observation vector.

Definition 2.6 (Observation Decoder).

Fix a query set $Q\subseteq\mathcal{U}$ . Define the observation decoder class by

 $\mathcal{A}_{Q}\coloneqq\{a_{Q}:\mathbb{R}^{Q}\to\mathcal{F}\}.$ 

(5)

For an observation decoder $a_{Q}\in\mathcal{A}_{Q}$ , its recovery error is

 $\mathcal{E}_{Q}(a_{Q})\coloneqq\sup_{f\in\mathcal{F}}d_{\mathcal{U}}\bigl(a_{Q}(f(Q)),f\bigr).$ 

(6)

The optimal recovery error from observations on $Q$ is

 $\mathcal{E}_{Q}^{\star}\coloneqq\inf_{a_{Q}\in\mathcal{A}_{Q}}\mathcal{E}_{Q}(a_{Q}).$ 

(7)

Additional queries can resolve distinctions left open by the current observations. We describe this accumulation of information by a nested query sequence.

Definition 2.7 (Query Sequence).

A query sequence is a family $(Q_{p})_{p\geq 1}$ of query sets with $Q_{p}\subseteq Q_{p+1}\subseteq\mathcal{U}$ for all $p\geq 1$ . The stage- $p$ observation vector is $f(Q_{p})$ .

Definition 2.8 (State Separation).

A query sequence $(Q_{p})_{p\geq 1}$ is said to separate states in $\mathcal{F}$ if

 $\forall f\neq g\in\mathcal{F},\quad\exists p\geq 1:\quad f(Q_{p})\neq g(Q_{p}).$ 

(8)

Separating queries progressively resolve observation ambiguity (figure 8). Compactness makes this resolution stable under vanishing tolerances.

Lemma 2.9 (Vanishing Ambiguity).

Let $(\mathcal{F},d_{\mathcal{U}})$ be nonempty and compact, and let $(P_{m})_{m\geq 1}$ be a query sequence separating states. For nonnegative tolerances $r_{m}\to 0$ ,

 $\omega_{P_{m}}(r_{m})\to 0.$ 

(9)

## 2.3 Prediction and Recovery

What must a learned representation preserve for us to recover the state it describes? Hertz’s account of representation centers on the correspondence between consequences (Hertz, 1899, Introduction). Here we test that correspondence by predicting further responses from encoded observations. The preceding lemma explains why the targets matter: agreement on sufficiently rich readings constrains the difference between full states. Prediction can thereby test whether a representation retains the distinctions defining the state.

Definition 2.10 (Prediction and Recovery).

The learning pipeline uses two disjoint query sets: $Q$ indexes the input observations $f(Q)$ , and $P$ indexes the target observations $f(P)$ . An encoder $e:\mathbb{R}^{Q}\to\mathcal{Z}$ maps $f(Q)$ to the learned state $e(f(Q))$ in a nonempty space $\mathcal{Z}$ . From this learned state, a predictor $b:\mathcal{Z}\to\mathbb{R}^{P}$ estimates $f(P)$ , while a state decoder $a:\mathcal{Z}\to\mathcal{F}$ reconstructs the ontic state $f$ . Their errors are

 $\displaystyle\mathcal{L}_{Q,P}(b;e)$ 
 $\displaystyle\coloneqq\sup_{f\in\mathcal{F}}d_{P}\bigl((b\circ e)(f(Q)),f(P)\bigr),$ 

(10)

 $\displaystyle\mathcal{R}_{Q}(a;e)$ 
 $\displaystyle\coloneqq\sup_{f\in\mathcal{F}}d_{\mathcal{U}}\bigl((a\circ e)(f(Q)),f\bigr).$ 

Let $\mathcal{B}_{P}$ and $\mathcal{A}$ be the classes of all maps of these respective types. For a fixed encoder, define

 $\mathcal{L}_{Q,P}^{\star}(e)\coloneqq\inf_{b\in\mathcal{B}_{P}}\mathcal{L}_{Q,P}(b;e),\qquad\mathcal{R}_{Q}^{\star}(e)\coloneqq\inf_{a\in\mathcal{A}}\mathcal{R}_{Q}(a;e).$ 

(11)

Both optimizations hold the encoder fixed; $\mathcal{R}_{Q}^{\star}(e)$ measures the recovery accuracy available from its learned state.

Corollary 2.11 (Input Ambiguity).

For a nonempty state family, query set $Q$ , and encoder $e$ ,

 $\mathcal{R}_{Q}^{\star}(e)\geq\mathcal{E}_{Q}^{\star}\geq\frac{1}{2}\omega_{Q}(0).$ 

(12)

Input queries supply distinctions to the encoder; targets test their preservation in its learned state.

## 2.4 Low-Dimensional Geometry

Figure 3: From population activity to state geometry. The neural inset motivates a low-dimensional model for the ontic state space $\mathcal{F}$ .

A neural recording contains many coordinates, yet activity within a task can vary through a few latent variables (Gallego et al., 2017; Jazayeri and Ostojic, 2021). This organization can constrain which patterns are learned (Sadtler et al., 2014) and take forms such as the toroidal geometry of grid-cell activity (Gardner et al., 2022). The resulting state family may curve through a much larger linear space (De and Chaudhuri, 2023).

Recovering a state within such a family requires responses that distinguish its members. Classical population decoding illustrates how neural responses carry this information: movement direction can be read from motor-cortical ensembles (Georgopoulos et al., 1986), and position reconstructed from hippocampal place-cell activity (Zhang et al., 1998). Models of population codes explain how neuronal tuning and background activity affect readout accuracy (Seung and Sompolinsky, 1993).

These observations lead to two quantitative requirements (figure 3). The state family should admit a controlled number of representatives at each resolution, and queries outside the inputs should distinguish its members. Covering numbers express the first requirement; observability expresses the second.

Assumption 2.12 (Low-Dimensional Observability).

For a query set $Q$ with $\mathcal{U}\setminus Q\neq\varnothing$ , there are constants $C\geq 1$ , $d>0$ , and $\alpha\in(0,1]$ such that

 $\mathcal{N}_{\mathcal{F}}(\varepsilon)\leq C\varepsilon^{-d},\qquad 0<\varepsilon\leq 1,$ 

(13)

where $\mathcal{N}_{\mathcal{F}}(\varepsilon)$ is the covering number: the fewest closed $d_{\mathcal{U}}$ -balls of radius $\varepsilon$ , centered in $\mathcal{F}$ , that cover $\mathcal{F}$ . The queries outside $Q$ distinguish states quantitatively:

 $\sup_{p\in\mathcal{U}\setminus Q}|f(p)-g(p)|\geq\alpha d_{\mathcal{U}}(f,g),\qquad f,g\in\mathcal{F}.$ 

(14)

## 3 Main Results

Prediction tests the distinctions retained by a learned state. If an encoder maps two states to the same learned state, every predictor must return the same target observations for both. Their target difference therefore imposes an unavoidable prediction error.

Lemma 3.1 (Prediction within Fibers).

Assume $(\mathcal{F},d_{\mathcal{U}})$ is nonempty and bounded. Fix a query set $Q\subseteq\mathcal{U}$ , a nonempty finite target query set $P\subseteq\mathcal{U}\setminus Q$ , and an encoder $e:\mathbb{R}^{Q}\to\mathcal{Z}$ . The optimal prediction error is attained and equals

 $\mathcal{L}_{Q,P}^{\star}(e)=\frac{1}{2}\sup_{\begin{subarray}{c}f,g\in\mathcal{F}\\
e(f(Q))=e(g(Q))\end{subarray}}d_{P}(f(P),g(P)).$ 

(15)

In the one-coordinate example, two states can have identical target readings while differing elsewhere. A predictor can be exact on those targets even if its encoder merges the states. Recovery depends on how much full-state difference those same readings permit.

## 3.1 General Case

Target ambiguity controls how prediction accuracy translates into state recovery.

Theorem 3.2 (General Prediction-Recovery Bound).

Let $(\mathcal{F},d_{\mathcal{U}})$ be nonempty and bounded. For disjoint query sets $Q,P$ and any encoder $e:\mathbb{R}^{Q}\to\mathcal{Z}$ ,

 $\mathmakebox[0.28][r]{\mathcal{L}_{Q,P}^{\star}(e)}\leq\boxed{\mathcal{R}_{Q}^{\star}(e)}\leq\mathmakebox[0.28][l]{\omega_{P}\bigl(2\mathcal{L}_{Q,P}^{\star}(e)\bigr).}$ 

(16)

The upper bound also holds with $\mathcal{L}_{Q,P}(b;e)$ for any predictor $b$ with finite error.

When the state space is compact, a growing set of separating targets resolves the remaining ambiguity. Prediction and recovery then converge together.

Theorem 3.3 (General Prediction-Recovery Equivalence).

Let $(\mathcal{F},d_{\mathcal{U}})$ be nonempty and compact, and let $(P_{m})_{m\geq 1}$ be a nested query sequence separating states. For each $m$ , choose a query set $Q_{m}\subseteq\mathcal{U}\setminus P_{m}$ and an encoder $e_{m}:\mathbb{R}^{Q_{m}}\to\mathcal{Z}_{m}$ . Then

 $\mathcal{L}_{Q_{m},P_{m}}^{\star}(e_{m})\to 0\quad\Longleftrightarrow\quad\mathcal{R}_{Q_{m}}^{\star}(e_{m})\to 0.$ 

(17)

For fixed input queries and a fixed encoder, vanishing prediction error along such a separating sequence leaves no distinct ontic states with the same learned state: an exact state decoder exists (corollary C.1). If the map to a Euclidean learned state is also continuous, compactness makes it a homeomorphism onto its image (corollary C.2). Under these conditions, preserving the distinctions that define states also preserves the topology of the state space.

## 3.2 Low-Dimensional Case

Assumption 2.12 combines a bound on the number of representative states with the ability to distinguish them through queries outside $Q$ . Together, these conditions give a finite target budget.

Theorem 3.4 (Low-Dimensional Prediction-Recovery Bound).

Let $\mathcal{F}$ be nonempty and let $(\mathcal{F},Q)$ satisfy assumption 2.12 with constants $C,d,\alpha$ . For every integer $m\geq C^{2}/2$ , there is a target set $P\subseteq\mathcal{U}\setminus Q$ , $1\leq|P|\leq m$ , such that every encoder $e$ satisfies

 $\mathcal{L}_{Q,P}^{\star}(e)\leq\boxed{\mathcal{R}_{Q}^{\star}(e)}\leq\frac{2}{\alpha}\mathcal{L}_{Q,P}^{\star}(e)+\frac{2+\alpha}{\alpha}\left(\frac{C^{2}}{2m}\right)^{\frac{1}{2d}}.$ 

(18)

The upper bound also holds with $\mathcal{L}_{Q,P}(b;e)$ for any predictor $b$ with finite error.

The recovery allowance vanishes as the target budget grows, yielding convergence and rate equivalences.

Theorem 3.5 (Low-Dimensional Prediction-Recovery Equivalence).

Let $\mathcal{F}$ be nonempty. Assume $(\mathcal{F},Q_{m})$ satisfies assumption 2.12 with common $C,d,\alpha$ for every integer $m\geq C^{2}/2$ , and choose $P_{m}$ by theorem 3.4. Then every encoder sequence $(e_{m})$ satisfies

 $\mathcal{L}_{Q_{m},P_{m}}^{\star}(e_{m})\to 0\quad\Longleftrightarrow\quad\mathcal{R}_{Q_{m}}^{\star}(e_{m})\to 0.$ 

(19)

Moreover,

 $\mathcal{L}_{Q_{m},P_{m}}^{\star}(e_{m})=O(m^{-1/(2d)})\quad\Longleftrightarrow\quad\mathcal{R}_{Q_{m}}^{\star}(e_{m})=O(m^{-1/(2d)}).$ 

(20)

## 3.3 Sharpness on a Fixed State Family

We next examine whether the budget rate can be improved when one target set serves every encoder. For $\alpha=1$ , we measure the additive recovery cost beyond $2\mathcal{L}^{\star}_{Q,P}(e)$ on a fixed state family. Here $d$ is the covering exponent; the family has topological dimension one.

Definition 3.6 (Uniform Transfer Residual).

Let $\mathcal{E}_{\mathrm{Lip}}$ be the globally Lipschitz maps $e:\mathbb{R}^{Q}\to\mathbb{R}^{2}$ . For an integer $m\geq 1$ , the uniform transfer residual is

 $\mathcal{T}_{m}(\mathcal{F},Q)\coloneqq\inf_{\begin{subarray}{c}P\subseteq\mathcal{U}\setminus Q\\
1\leq|P|\leq m\end{subarray}}\sup_{e\in\mathcal{E}_{\mathrm{Lip}}}\bigl[\mathcal{R}_{Q}^{\star}(e)-2\mathcal{L}_{Q,P}^{\star}(e)\bigr].$ 

(21)

The target set is selected before the encoder. The family below has identifying inputs and even a single query outside $Q$ whose exact response identifies the state (equation 92). An encoder can nevertheless merge distinct states. The residual measures the additive cost of controlling their recovery by twice the prediction error, uniformly across encoders.

Theorem 3.7 (Sharp Uniform Transfer).

For every $d>1$ , there exist a fixed countable query universe $\mathcal{U}$ , a singleton input set $Q$ , and a compact state family $\mathcal{F}$ homeomorphic to $[0,1]$ , of diameter $1$ . The pair $(\mathcal{F},Q)$ satisfies assumption 2.12 with $C=C_{d}$ and $\alpha=1$ , and its input observation map is injective. For every integer $m\geq C_{d}^{2}/2$ ,

 $\mathmakebox[0.28][r]{\frac{1}{6}m^{-1/(2d)}}\leq\boxed{\mathcal{T}_{m}(\mathcal{F},Q)}\leq\mathmakebox[0.28][l]{3\left(\frac{C_{d}^{2}}{2m}\right)^{1/(2d)}.}$ 

(22)

The supremum in equation 21 has the same value when restricted to $1$ -Lipschitz encoders.

The order of selection matters as well. On this same family, a target selected for one fixed $1$ -Lipschitz encoder can achieve $\mathcal{R}_{Q}^{\star}(e)\leq 2\mathcal{L}_{Q,\{p\}}^{\star}(e)$ with a single query (corollary C.10). This selection uses the complete state family. Requiring one target set to serve every encoder gives the sharp budget in theorem 3.7. Classical optimal recovery studies the radius left by fixed information (Traub et al., 1983; Krieg and Ullrich, 2026); our budget measures how many prediction targets suffice to control that radius uniformly across learned representations.

## 3.4 From Recorded Error to Recovery

The bounds above use prediction error over the entire state family. Training supplies finitely many observation pairs. To pass from recorded error to a recovery guarantee, we need to know both how these records cover possible observations and how predictions vary between them.

Definition 3.8 (Recorded Error and Coverage).

Fix disjoint query sets $Q,P$ , a pair $(e,b)$ , and states $f_{1},\ldots,f_{n}\in\mathcal{F}$ with $n\geq 1$ indexing the recorded pairs $(f_{i}(Q),f_{i}(P))$ . The empirical prediction error and observation coverage radius are

 $\widehat{\mathcal{L}}_{Q,P,n}(b;e)\coloneqq\max_{1\leq i\leq n}d_{P}\bigl((b\circ e)(f_{i}(Q)),f_{i}(P)\bigr),$ 

(23)

 $h_{n}\coloneqq\sup_{f\in\mathcal{F}}\min_{1\leq i\leq n}d_{Q\cup P}\bigl(f(Q\cup P),f_{i}(Q\cup P)\bigr).$ 

(24)

The radius measures coverage jointly in inputs and targets: every possible observation pair lies within $h_{n}$ of a record. Prediction stability controls how the learned map responds over this distance.

Assumption 3.9 (Prediction Stability).

For the pair $(e,b)$ , there is a nondecreasing function $\rho:[0,\infty)\to[0,\infty)$ with $\rho(0)=0$ and $\rho(t)\to 0$ as $t\downarrow 0$ such that, for all $f,g\in\mathcal{F}$ ,

 $d_{P}\bigl((b\circ e)(f(Q)),(b\circ e)(g(Q))\bigr)\leq\rho\bigl(d_{Q}(f(Q),g(Q))\bigr).$ 

(25)

For a nearby record, the prediction changes by at most $\rho(h_{n})$ and the target reading by at most $h_{n}$ . Adding these changes to the recorded error controls prediction at the unrecorded state. A Lipschitz prediction map has $\rho(t)=Kt$ .

Proposition 3.10 (Recovery from Records).

Let $(\mathcal{F},d_{\mathcal{U}})$ be nonempty and compact. For a pair $(e,b)$ satisfying assumption 3.9, the prediction error obeys

 $\displaystyle E_{n}\coloneqq\widehat{\mathcal{L}}_{Q,P,n}(b;e)+\rho(h_{n})+h_{n},$ 

(26)

 $\displaystyle\mathmakebox[0.20][r]{\widehat{\mathcal{L}}_{Q,P,n}(b;e)}\leq\boxed{\mathcal{L}_{Q,P}(b;e)}\leq\mathmakebox[0.20][l]{E_{n},}$ 

(27)

and the recovery error satisfies

 $\mathcal{R}_{Q}^{\star}(e)\leq\omega_{P}(2E_{n}).$ 

(28)

Under assumption 2.12, for targets selected by theorem 3.4,

 $\mathcal{R}_{Q}^{\star}(e)\leq\frac{2}{\alpha}E_{n}+\frac{2+\alpha}{\alpha}\left(\frac{C^{2}}{2m}\right)^{1/(2d)}.$ 

(29)

The terms answer different questions. The empirical error measures fit on recorded pairs. Their coverage and the prediction modulus control what this fit implies between records. The target budget controls distinctions left unresolved even by a uniformly accurate predictor. More training records and more target queries address these two sources of uncertainty separately. The fine-tuning results in theorems D.4 and D.5 include model-class error and optimization tolerance; appendix E also treats measurement perturbations.

## 4 Experiment

The experiments examine prediction and recovery with two kinds of access to the state. On Sphere, Torus, and General families, the known response law makes the complete profile available for evaluation. Random target sampling tests separation and budget dependence; theorem 3.7 supplies the sharpness result analytically. Neural recordings then let us examine covering geometry, held-out prediction, and recovery of a fixed model’s hidden state as an ontic-state surrogate.

## 4.1 Synthetic Experiment

Figure 4: Synthetic state families. Representative low-dimensional views of the sphere, product of circles and independent box.

We use three synthetic state families (figure 4): Sphere is uniform on a unit sphere; Torus consists of independent circle factors; General has independent uniform coordinates in a high-dimensional box. A common observation law embeds them into the same query universe. We jointly train an encoder and predictor on input–target observations, then recover the state through a deterministic ground-truth (GT) map, following theorem 3.2. Here the coordinate structure determines the random-sampling budget; the experiment tests how target separation transfers prediction accuracy to recovery.

For a latent vector $x\in[-1,1]^{r}$ in one of the three families, define

 $f_{x}(j,k)=\tanh\bigl(a_{jk}s_{j}x_{i(j)}+c_{jk}\bigr),$ 

(30)

where $i(j)$ selects a coordinate, $s_{j}\in\{-1,1\}$ , and $a_{jk}>0,c_{jk}\in\mathbb{R}$ are fixed channel coefficients.
Each family uses the same coefficient law. Repeating low-dimensional coordinates across the query universe changes the geometry of the state family while retaining this observation mechanism.

Given predicted target observations $y\in\mathbb{R}^{P}$ , the ideal deterministic GT map returns

 $\widehat{f}(y)\in\operatorname*{arg\,min}_{g\in\mathcal{F}}d_{P}\bigl(g(P),y\bigr).$ 

(31)

The known observation law converts target-error tolerances into coordinate intervals. A deterministic feasibility calculation approximates this map (appendix F) and supplies the complete recovered profile, including responses outside the target set.

Observability check. To apply theorem 3.2, we need to control target ambiguity. Complete coordinate coverage gives an explicit constant before training.

Proposition 4.1 (Coordinate Observability).

For the family in equation 30, suppose $P$ observes every latent coordinate. Let $\ell_{i}$ be the largest $a_{jk}\operatorname{sech}^{2}(a_{jk}+|c_{jk}|)$ among target channels observing coordinate $i$ , and let $A_{i}$ be the largest $a_{jk}$ among all channels observing it. Then, for all $f,g\in\mathcal{F}$ ,

 $\alpha_{P}=\min_{i}\frac{\ell_{i}}{A_{i}}>0,\qquad d_{P}(f,g)\geq\alpha_{P}d_{\mathcal{U}}(f,g).$ 

(32)

This inequality gives $\omega_{P}(t)\leq t/\alpha_{P}$ , so theorem 3.2 yields $\mathcal{R}_{Q}^{\star}(e)\leq 2\mathcal{L}_{Q,P}(b;e)/\alpha_{P}$ . The observation law and target set determine this global constant; predictive training determines the target error. Together they control differences in the complete profile. Target prediction. We next ask whether a learned representation predicts a disjoint target set. An encoder–predictor learns from the same sessions’ training blocks and is evaluated on later held-out observations. ## 5 Related Work

Prediction and state learning. Predictive state models describe dynamics through action-conditioned future observations (Littman et al., 2001). Auxiliary prediction and context learning link predictive objectives to downstream performance (Lee et al., 2021; Zhai et al., 2025). Zhang et al. (2025) recover generating latent variables up to coordinate negations and permutations as tasks increase, under a low-degree task distribution and preference for low-degree realizations. Our target is the complete query-response profile; the fixed-family bound quantifies the cost of one target set serving all encoders.

Identifiability. Identifiability depends on the learning setup (Locatello et al., 2019). Auxiliary variables (Khemakhem et al., 2020), contrastive objectives with generative assumptions (Zimmermann et al., 2021), and multiple modalities (Daunhawer et al., 2023) can identify factors up to transformations. Our recovery target is specified by query responses before choosing latent coordinates.

Optimal recovery and sampling. Optimal recovery studies uncertainty under partial observations (Micchelli and Rivlin, 1977). Here, states sharing an encoder output form a set whose diameter limits recovery; prediction constrains that set through its targets. Structured model classes also yield recovery and sampling guarantees (Binev et al., 2024; Krieg and Ullrich, 2026).

Geometry and stable approximation. Embeddings (Sauer et al., 1991) and random manifold projections (Baraniuk and Wakin, 2009) relate geometry to measurement requirements. Stable manifold widths link approximation to metric entropy (Cohen et al., 2022). Here, low-dimensional covering controls the distinctions to resolve; observability supplies the queries.

Neural geometry and computation. Population geometry relates to computation (Chung and Abbott, 2021; Jazayeri and Ostojic, 2021), cross-task generalization (Wakhloo et al., 2026), and cross-animal decoding (Safaie et al., 2023). Intrinsic-dimension estimation characterizes the degrees of freedom in neural activity (Fadanni et al., 2026). These studies motivate our geometric assumptions, which connect covering complexity to query budgets.

Neural state learning. LFADS infers population dynamics (Pandarinath et al., 2018); the Neural Latents Benchmark evaluates held-out activity and behavioral readouts (Pei et al., 2021). Multi-context, multi-task, and foundation models learn across recordings (Ye et al., 2023; Azabou et al., 2025; Wang et al., 2025). CEBRA uses behavioral or temporal context (Schneider et al., 2023), DPAD prioritizes behaviorally relevant dynamics (Sani et al., 2024), and MARBLE represents local manifold dynamics (Gosztolai et al., 2025). These objectives reward different distinctions; we ask when preserving them suffices to recover the complete response profile.

## 6 Conclusion

We studied when learning to predict a system enables recovery of its ontic state. Defining that state as a complete response profile lets us relate prediction to the distinctions a learned representation preserves. Query ambiguity makes this connection quantitative, yielding recovery guarantees in general and low-dimensional settings. In the latter, we establish query-budget bounds whose order is sharp on a fixed state family when one target set serves every encoder. These results give a precise sense in which predicting observations can become a way of knowing the state that produces them. We hope that our work offers theoretical support for using deep learning models as computational surrogates for complex systems, including those studied in neuroscience.

## Appendix A State, Query, and Observation

We begin with observation ambiguity, then derive the prediction–recovery bounds and their sharpness. The training and noisy-observation results extend this chain to finite records and perturbed measurements. Experimental details follow the main-text order: synthetic recovery, joint-query calibration, and neural observation geometry and surrogate-state recovery.

## A.1 Distance and Restriction

Distances contract when we restrict the query set. For query sets $Q\subseteq Q^{\prime}\subseteq\mathcal{U}$ and states $f,g\in\mathcal{F}$ ,

 $d_{Q}(f(Q),g(Q))\leq d_{Q^{\prime}}(f(Q^{\prime}),g(Q^{\prime}))\leq d_{\mathcal{U}}(f,g).$ 

(33)

Each inequality follows by taking the supremum over a subset of the same observation coordinates. In particular, every observation map $f\mapsto f(Q)$ is $1$ -Lipschitz and hence continuous.

Lemma A.1 (Ontic Metric).

The function $d_{\mathcal{U}}:\mathcal{F}\times\mathcal{F}\to[0,\infty)$ is a metric on $\mathcal{F}$ . Hence $(\mathcal{F},d_{\mathcal{U}})$ is a metric space.

Proof.

Boundedness of $f,g\in\mathcal{F}$ gives

 $d_{\mathcal{U}}(f,g)\leq\sup_{q\in\mathcal{U}}|f(q)|+\sup_{q\in\mathcal{U}}|g(q)|<\infty.$ 

(34)

Nonnegativity and symmetry follow from absolute value. Moreover, $d_{\mathcal{U}}(f,g)=0$ holds exactly when $f(q)=g(q)$ at every query, which means $f=g$ as functions. Finally, for every $q\in\mathcal{U}$ ,

 $|f(q)-g(q)|\leq|f(q)-h(q)|+|h(q)-g(q)|\leq d_{\mathcal{U}}(f,h)+d_{\mathcal{U}}(h,g).$ 

(35)

Taking the supremum over $q$ proves the triangle inequality.
∎

## A.2 A Common Readout

States sharing the same input must receive the same output. Their target spread limits the accuracy of a common readout.

Lemma A.2 (Fiberwise Error Bound).

Let $\mathcal{F}$ be nonempty and $(\mathcal{V},d)$ a metric space. The map $T:\mathcal{F}\to\mathcal{Y}$ specifies the input available to a readout, and $G:\mathcal{F}\to\mathcal{V}$ specifies its target. Define the largest target diameter among states with the same input by

 $\Delta\coloneqq\sup_{\begin{subarray}{c}f,g\in\mathcal{F}\\
T(f)=T(g)\end{subarray}}d(G(f),G(g)).$ 

(36)

Then

 $\frac{\Delta}{2}\leq\boxed{\inf_{c:\mathcal{Y}\to\mathcal{V}}\sup_{f\in\mathcal{F}}d(c(T(f)),G(f))}\leq\Delta.$ 

(37)

If $(\mathcal{V},d)=(\mathbb{R}^{P},d_{P})$ with $P$ nonempty and finite and $G(\mathcal{F})$ bounded, the coordinatewise midpoint attains the lower bound $\Delta/2$ .

Proof.

Choose a common output. For each attainable input $y\in T(\mathcal{F})$ , let $S_{y}\coloneqq\{f\in\mathcal{F}:T(f)=y\}$ be its fiber. Choose $h_{y}\in S_{y}$ and define $c(y)=G(h_{y})$ . Assign a fixed element of $\mathcal{V}$ at unattainable inputs. For any $f\in S_{y}$ ,

 $d(c(T(f)),G(f))=d(G(h_{y}),G(f))\leq\Delta.$ 

(38)

Taking the supremum over $f\in\mathcal{F}$ gives the general upper bound.

The state-valued case $G(f)=f$ is shown below for three fibers.

Compare any common output. If $T(f)=T(g)$ , every readout $c$ gives the same output to both states. The triangle inequality gives

 $d(G(f),G(g))\leq d(G(f),c(T(f)))+d(c(T(g)),G(g))\leq 2\sup_{h\in\mathcal{F}}d(c(T(h)),G(h)).$ 

(39)

Taking the supremum over pairs and then the infimum over readouts gives the lower bound $\Delta/2$ .

Use coordinate midpoints. When $(\mathcal{V},d)=(\mathbb{R}^{P},d_{P})$ and $G(\mathcal{F})$ is bounded, define the coordinatewise midpoint

 $[c^{\star}(y)](p)\coloneqq\frac{1}{2}\Bigl(\inf_{g\in S_{y}}[G(g)](p)+\sup_{g\in S_{y}}[G(g)](p)\Bigr),\qquad p\in P.$ 

(40)

The endpoints are finite by boundedness. Set $c^{\star}(y)=0\in\mathbb{R}^{P}$ at unattainable inputs. For any $f\in S_{y}$ and $p\in P$ ,

 $\bigl|[c^{\star}(y)](p)-[G(f)](p)\bigr|\leq\frac{1}{2}\sup_{g,h\in S_{y}}\bigl|[G(g)](p)-[G(h)](p)\bigr|\leq\frac{\Delta}{2}.$ 

(41)

Taking the maximum over $p\in P$ and the supremum over $f\in\mathcal{F}$ shows that $c^{\star}$ attains the lower bound.
∎

Lemma A.3 (Exact Decoding).

For nonempty $\mathcal{F}$ , the following are equivalent: $\mathcal{R}_{Q}^{\star}(e)=0$ ; the map $f\mapsto e(f(Q))$ is injective; and some state decoder satisfies $(a\circ e)(f(Q))=f$ for every $f\in\mathcal{F}$ .

Proof.

If $\mathcal{R}_{Q}^{\star}(e)=0$ , lemma A.2 gives $d_{\mathcal{U}}(f,g)=0$ whenever $e(f(Q))=e(g(Q))$ , so the map is injective. Its inverse on attainable learned states, extended by a fixed member of $\mathcal{F}$ elsewhere, is an exact decoder. Conversely, an exact decoder has zero error, so $\mathcal{R}_{Q}^{\star}(e)=0$ .
∎

## A.3 Ambiguity and Recovery

The common-readout construction now applies to all states compatible with an observation vector. Compactness will ensure that their ambiguity vanishes as separating queries accumulate.

Assumption A.4 (Compactness).

The ontic state space $(\mathcal{F},d_{\mathcal{U}})$ is nonempty and compact.

Lemma A.5 (Ambiguity and Recovery).

Assume $\mathcal{F}$ is nonempty. For every query set $Q\subseteq\mathcal{U}$ ,

 $\frac{1}{2}\omega_{Q}(0)\leq\boxed{\mathcal{E}_{Q}^{\star}}\leq\omega_{Q}(0).$ 

(42)

Proof.

By lemma A.1, $(\mathcal{F},d_{\mathcal{U}})$ is a metric space. Apply lemma A.2 with $T(f)=f(Q)$ , $G(f)=f$ and $(\mathcal{V},d)=(\mathcal{F},d_{\mathcal{U}})$ . Its fiber diameter is $\Delta=\omega_{Q}(0)$ , so equation 37 gives both bounds.

Proof of lemma 2.9.

Suppose the conclusion fails. There are $\varepsilon>0$ , increasing indices $m_{k}$ , and states $f_{k},g_{k}\in\mathcal{F}$ such that

 $d_{P_{m_{k}}}\bigl(f_{k}(P_{m_{k}}),g_{k}(P_{m_{k}})\bigr)\leq r_{m_{k}},\qquad d_{\mathcal{U}}(f_{k},g_{k})\geq\varepsilon.$ 

(43)

Compactness gives a common subsequence with $f_{k}\to f$ and $g_{k}\to g$ . Continuity of the metric gives $d_{\mathcal{U}}(f,g)\geq\varepsilon$ .

(47)

Embedding theory relates state distinguishability to the geometry preserved by observations (Sauer et al., 1991). Here, exact state recovery has a topological counterpart when the state space is compact and the map to learned states is continuous.

Corollary C.2 (Topology Preservation).

Under assumption A.4, fix a query set $Q$ and an encoder $e:\mathbb{R}^{Q}\to\mathcal{Z}=\mathbb{R}^{\ell}$ with a continuous map to learned states $f\mapsto e(f(Q))$ . If there exists a state decoder $a\in\mathcal{A}$ such that

 $(a\circ e)(f(Q))=f,\qquad\forall f\in\mathcal{F},$ 

(54)

then this map is a homeomorphism onto its image. In particular, if $\mathcal{F}$ is a topological manifold, possibly with boundary, its image under this map is a manifold of the same dimension.

Proof.

Injectivity. By lemma A.3, the map $f\mapsto e(f(Q))$ is injective. It is therefore a continuous bijection onto its image.

Continuity of the inverse. Every closed subset of the compact space $\mathcal{F}$ is compact. Its image is compact by continuity, and therefore closed in $\mathbb{R}^{\ell}$ . The bijection is thus a closed map, so its inverse is continuous. This proves that it is a homeomorphism onto its image.

Manifold structure. Composing each local chart of $\mathcal{F}$ with this inverse gives a local chart on the image, with the same dimension and boundary structure.

∎

## C.2 Low-Dimensional Case

The general case controls recovery through target ambiguity. In the low-dimensional case, covering and observability let us bound that ambiguity using finitely many queries, yielding the recovery and convergence results in theorems 3.4 and 3.5.

Lemma C.3 (Covering Queries).

Let $\mathcal{F}$ be nonempty and let $(\mathcal{F},Q)$ satisfy assumption 2.12 with constants $C,d,\alpha$ . Fix a covering radius $0<\varepsilon\leq 1$ and a query allowance $\tau>0$ .

There is a finite representative set $\mathcal{F}_{\varepsilon}\subseteq\mathcal{F}$ , with $N=|\mathcal{F}_{\varepsilon}|\leq C\varepsilon^{-d}$ , such that every state in $\mathcal{F}$ is within $d_{\mathcal{U}}$ -distance $\varepsilon$ of a representative.

There also exists a target set $P\subseteq\mathcal{U}\setminus Q$ , with $1\leq|P|\leq\max\{1,N(N-1)/2\}$ , that distinguishes these representatives: for every $f,g\in\mathcal{F}_{\varepsilon}$ ,

 $d_{P}\bigl(f(P),g(P)\bigr)\geq\alpha d_{\mathcal{U}}(f,g)-\tau.$ 

(55)

Equivalently,

 $d_{\mathcal{U}}(f,g)\leq\frac{1}{\alpha}d_{P}\bigl(f(P),g(P)\bigr)+\frac{\tau}{\alpha}.$ 

(56)

The representatives and targets are selected independently of the encoder.

Proof.

Choose the representatives. By equation 13, take an $\varepsilon$ -cover with centers $\mathcal{F}_{\varepsilon}\subseteq\mathcal{F}$ and $1\leq N=|\mathcal{F}_{\varepsilon}|\leq C\varepsilon^{-d}$ .

Distinguish each pair. For each unordered pair $\{f,g\}\subseteq\mathcal{F}_{\varepsilon}$ of distinct representatives, observability equation 14 and $\tau>0$ let us select $p_{\{f,g\}}\in\mathcal{U}\setminus Q$ such that

 $|f(p_{\{f,g\}})-g(p_{\{f,g\}})|\geq\alpha d_{\mathcal{U}}(f,g)-\tau.$ 

(57)

The positive allowance permits this choice even if no query attains the supremum.

Collect the queries. If $N\geq 2$ , let $P=\{p_{\{f,g\}}:f,g\in\mathcal{F}_{\varepsilon},\ f\neq g\}$ . Then

 $1\leq|P|\leq\frac{N(N-1)}{2}.$ 

(58)

For distinct $f,g\in\mathcal{F}_{\varepsilon}$ , their selected query belongs to $P$ , so

 $d_{P}\bigl(f(P),g(P)\bigr)\geq|f(p_{\{f,g\}})-g(p_{\{f,g\}})|\geq\alpha d_{\mathcal{U}}(f,g)-\tau.$ 

(59)

For $f=g$ , both distances are zero. This proves equation 55; rearranging gives equation 56.

If $N=1$ , take any singleton $P\subseteq\mathcal{U}\setminus Q$ , which exists by assumption 2.12; the distance bounds are immediate.
∎

We next extend the representative bound to arbitrary states.

Lemma C.4 (Decoding a Cover).

Let $\mathcal{F}_{\varepsilon}\subseteq\mathcal{F}$ be a finite $\varepsilon$ -cover, and let a nonempty finite target set $P$ satisfy equation 56 with constants $\alpha>0$ and $\tau\geq 0$ . For $y\in\mathbb{R}^{P}$ , choose a representative $g\in\operatorname*{arg\,min}_{h\in\mathcal{F}_{\varepsilon}}d_{P}(y,h(P))$ . Then, for every $f\in\mathcal{F}$ ,

 $d_{\mathcal{U}}(f,g)\leq\frac{2}{\alpha}d_{P}(y,f(P))+\frac{(2+\alpha)\varepsilon+\tau}{\alpha}.$ 

(60)

Proof.

Take $f_{\varepsilon}\in\mathcal{F}_{\varepsilon}$ with $d_{\mathcal{U}}(f,f_{\varepsilon})\leq\varepsilon$ . By equation 56, the minimizing property of $g$ , and restriction of the full metric,

 $\displaystyle d_{\mathcal{U}}(f,g)$ 
 $\displaystyle\leq d_{\mathcal{U}}(f,f_{\varepsilon})+d_{\mathcal{U}}(f_{\varepsilon},g)\leq\varepsilon+\frac{1}{\alpha}d_{P}(f_{\varepsilon}(P),g(P))+\frac{\tau}{\alpha}$ 

(61)

 $\displaystyle\leq\varepsilon+\frac{2}{\alpha}d_{P}(y,f_{\varepsilon}(P))+\frac{\tau}{\alpha}\leq\frac{2}{\alpha}d_{P}(y,f(P))+\frac{(2+\alpha)\varepsilon+\tau}{\alpha}.$ 

∎

To prove theorem 3.4, we fit this construction to the prescribed query budget and decode to a representative whose target observations are closest to the prediction.

Proof of theorem 3.4.

Decode to a representative. For radius $\varepsilon$ and allowance $\tau$ , specified below, lemma C.3 supplies a finite representative set $\mathcal{F}_{\varepsilon}$ and a target query set $P$ .  $a(z)\in\operatorname*{arg\,min}_{g\in\mathcal{F}_{\varepsilon}}d_{P}\bigl(b(z),g(P)\bigr),$ 

(62)

resolving ties by a fixed ordering.

(63)

(64)

(65)

(66)

## C.3 Budget Sharpness

We first prove the fixed-family result supporting theorem 3.7, then give a finite-query construction for comparison.

A fixed family at every budget. A multiscale arc places the obstruction inside a fixed family: finer blocks contain more distinctions, while their response amplitudes decrease. The encoder merges a pair whose distinguishing query was omitted, and the radius of that pair gives the recovery cost.

We construct the fixed family in lemma C.6, find a pair missed by the target set in lemma C.7, and merge that pair in lemma C.8. Combining their bounds proves lemma C.9.

Lemma C.6 (Multiscale Arc).

For every $d>1$ , there exist a countable query universe $\mathcal{U}$ , a singleton input set $Q$ , and a compact state family $\mathcal{F}$ homeomorphic to $[0,1]$ , of diameter $1$ . The input observation map is injective, and $(\mathcal{F},Q)$ satisfies assumption 2.12 with $C=C_{d}$ and $\alpha=1$ .
The covering constant is

 $C_{d}\coloneqq 1+\frac{12}{1-2^{1/d-1}}.$ 

(72)

Proof.

Construct the family. Fix $d>1$ . For $j\geq 1$ , put

 $\displaystyle N_{j}$ 
 $\displaystyle=8\cdot 2^{j-1},$ 
 $\displaystyle s_{j}$ 
 $\displaystyle=\frac{1}{2}\,2^{-(j-1)/d},$ 

(73)

 $\displaystyle\ell_{j}$ 
 $\displaystyle=2^{-j-1},$ 
 $\displaystyle T_{j}$ 
 $\displaystyle=1-2^{1-j}.$ 

(74)

Let $v_{1},\ldots,v_{N_{j}}$ denote the standard basis in $\mathbb{R}^{N_{j}}$ . On $[T_{j},T_{j}+\ell_{j}]$ , the vector $\lambda^{j}(t)$ follows the polygonal path $v_{1}\to\cdots\to v_{N_{j}}$ , spending equal time on each edge; the vectors in other blocks are zero. On $[T_{j}+\ell_{j},T_{j+1}]$ , join this block directly to the next: set $\lambda^{j}(t)=wv_{N_{j}}$ and $\lambda^{j+1}(t)=(1-w)v_{1}$ , where $w$ decreases linearly from $1$ to $0$ . At $t=1$ , all block vectors are zero. These intervals cover $[0,1)$ because $T_{j+1}-T_{j}=2\ell_{j}$ .

Take $Q=\{q_{0}\}$ . The remaining queries are a duplicate parameter query $p_{0}$ , a height query $p^{j}_{\mathrm{h}}$ for each block, and a private query $p^{j}_{ab}$ for each $1\leq a<b\leq N_{j}$ . Define the state $f_{t}$ , for $0\leq t\leq 1$ , by

 $\displaystyle f_{t}(q_{0})=f_{t}(p_{0})$ 
 $\displaystyle=t/2,$ 

(75)

 $\displaystyle f_{t}(p^{j}_{ab})$ 
 $\displaystyle=s_{j}\bigl(\lambda_{a}^{j}(t)-\lambda_{b}^{j}(t)\bigr),$ 

(76)

 $\displaystyle f_{t}(p^{j}_{\mathrm{h}})$ 
 $\displaystyle=2s_{j}\bigl(1-\|\lambda^{j}(t)\|_{1}\bigr).$ 

(77)

Let $\mathcal{F}=\{f_{t}:0\leq t\leq 1\}$ .

Geometry and observability. All responses are bounded. The parameter query makes $t\mapsto f_{t}$ injective, and its duplicate gives target observability with $\alpha=1$ . Each finite part of the path is continuous in the full response metric. From block $j$ onward, the distance to $f_{1}$ is at most $2s_{j}$ : active private coordinates have magnitude at most $s_{j}$ , height differences are at most $2s_{j}$ , and the parameter difference is at most $2^{-j}\leq s_{j}$ . Thus the path is also continuous at $1$ . Compactness and injectivity make it a homeomorphism onto $\mathcal{F}$ . Every coordinate has range at most $1$ , and two vertices in the first block differ by $2s_{1}=1$ , so the diameter is exactly $1$ .

The shrinking blocks accumulate at the endpoint.

Covering bound. Each edge within block $j$ is a straight response-space segment of length $2s_{j}$ , as is its outgoing connector. Indeed, a private coordinate attains this length on a block edge, and the height query $p^{j}_{\mathrm{h}}$ attains it on the connector; the parameter increment is smaller. The $N_{j}-1$ block edges and one outgoing connector give $N_{j}$ closed segments per block, including their endpoints. For $0<\varepsilon<1$ , let $J$ be the last index with $2s_{J}>\varepsilon$ . The tail beginning at block $J+1$ lies in the closed $\varepsilon$ -ball about $f_{1}$ . A segment of length $2s_{j}$ is covered by $\lceil s_{j}/\varepsilon\rceil$ closed balls centered on the segment. Consequently,

 $\displaystyle\mathcal{N}_{\mathcal{F}}(\varepsilon)$ 
 $\displaystyle\leq 1+\sum_{j\leq J}N_{j}\left(\frac{s_{j}}{\varepsilon}+1\right)\leq 1+\frac{3}{\varepsilon}\sum_{j\leq J}N_{j}s_{j},$ 

(78)

 $\displaystyle\sum_{j\leq J}N_{j}s_{j}$ 
 $\displaystyle\leq\frac{N_{J}s_{J}}{1-2^{1/d-1}}\leq\frac{4\varepsilon^{1-d}}{1-2^{1/d-1}}.$ 

This gives the stated $C_{d}\varepsilon^{-d}$ bound. At $\varepsilon=1$ , one ball suffices. Moreover, the $N_{j}$ vertices of block $j$ are mutually $2s_{j}$ apart. At radius $s_{j}/2$ , each covering ball contains at most one of them. Since $N_{j}=8(2s_{j})^{-d}$ , the covering exponent is exactly $d$ .
∎

The next two lemmas use the family and block notation constructed in the proof of lemma C.6.

Lemma C.7 (Omitted Pair).

For every integer $m\geq 1$ and nonempty $P\subseteq\mathcal{U}\setminus Q$ with $|P|\leq m$ , some block $j$ contains two nonadjacent vertices with parameters $t_{i},t_{k}$ such that

 $d_{P}(f_{t_{i}}(P),f_{t_{k}}(P))\leq s_{j},\qquad s_{j}\geq\frac{1}{2}m^{-1/(2d)}.$ 

(79)

Proof.

Fix $m$ and $P$ . Choose the smallest $j$ with $(N_{j}-1)(N_{j}-2)/2>m$ . This is the number of nonadjacent vertex pairs in block $j$ , so some pair $i<k$ , with $k-i\geq 2$ , has $p^{j}_{ik}\notin P$ . Write $t_{i},t_{k}$ for their parameter values. Their private query $p^{j}_{ik}$ has response gap $2s_{j}$ . Every other private query has gap at most $s_{j}$ , every height query has gap zero, and the parameter gap is at most $\ell_{j}/2\leq s_{j}/4$ . Hence

 $d_{P}(f_{t_{i}}(P),f_{t_{k}}(P))\leq s_{j}.$ 

(80)

When $j=1$ , $N_{j}=8\leq 8\sqrt{m}$ . Otherwise minimality of $j$ gives $(N_{j-1}-1)(N_{j-1}-2)/2\leq m$ . Hence $N_{j-1}\leq\sqrt{2m}+2$ and $N_{j}=2N_{j-1}\leq 8\sqrt{m}$ . It follows that

 $\frac{s_{j}}{3}=\frac{1}{6}(N_{j}/8)^{-1/d}\geq\frac{1}{6}m^{-1/(2d)}.$ 

(81)

∎

Lemma C.8 (Two-State Fiber).

Fix two nonadjacent vertices $f_{t_{i}},f_{t_{k}}$ with $i<k$ in block $j$ and a nonempty finite target set $P\subseteq\mathcal{U}\setminus Q$ . There is a globally Lipschitz encoder $e:\mathbb{R}^{Q}\to\mathbb{R}^{2}$ whose only non-singleton state fiber is this pair, with

 $\displaystyle\mathcal{L}_{Q,P}^{\star}(e)$ 
 $\displaystyle=\frac{1}{2}d_{P}(f_{t_{i}}(P),f_{t_{k}}(P)),$ 

(82)

 $\displaystyle\mathcal{R}_{Q}^{\star}(e)$ 
 $\displaystyle\geq\frac{4}{3}s_{j}.$ 

(83)

Proof.

A two-state fiber. Put $u_{i}=t_{i}/2$ and $u_{k}=t_{k}/2$ . Define

 $e(u)=\!\!\begin{cases}(u-u_{i},0),&u\leq u_{i},\\
(\sin\!\frac{2\pi(u-u_{i})}{u_{k}-u_{i}},1-\cos\!\frac{2\pi(u-u_{i})}{u_{k}-u_{i}}),&u_{i}\leq u\leq u_{k},\\
(u-u_{k},0),&u\geq u_{k}.\end{cases}$ 

(84)

The circular part has positive second coordinate in its interior, while the two tails lie on opposite halves of the horizontal axis. Thus the only merged input pair is $u_{i},u_{k}$ . The pieces agree at their endpoints, and the encoder is globally Lipschitz with constant at most $\max\{1,2\pi/(u_{k}-u_{i})\}$ . By lemma 3.1,

 $\mathcal{L}_{Q,P}^{\star}(e)=\frac{1}{2}d_{P}(f_{t_{i}}(P),f_{t_{k}}(P)).$ 

(85)

The admissible recovery center. Every singleton fiber can be decoded exactly. It remains to bound the radius of the pair about any $g\in\mathcal{F}$ .

For $g=f_{t}$ in block $j$ , the vector $\lambda^{j}(t)$ has mass one on at most two adjacent vertices. Exchange $i,k$ if necessary so that $\lambda_{i}^{j}(t)=0$ , and take a largest coordinate $\lambda_{b}^{j}(t)\geq 1/2$ . Then $b\neq i$ , and the private query indexed by $\{i,b\}$ gives response difference

 $s_{j}\bigl|1-\lambda_{i}^{j}(t)+\lambda_{b}^{j}(t)\bigr|=s_{j}\bigl(1+\lambda_{b}^{j}(t)\bigr)\geq\frac{3}{2}s_{j}.$ 

(86)

On an adjacent connector, the block vector is $w$ times an endpoint, giving private-coordinate error at least $s_{j}(1+w)$ and height error $2s_{j}(1-w)$ . Elsewhere, the block mass is zero and the height error is $2s_{j}$ . Thus

 $\frac{1}{s_{j}}\max\{d_{\mathcal{U}}(g,f_{t_{i}}),d_{\mathcal{U}}(g,f_{t_{k}})\}\geq\begin{cases}3/2,&\text{in block }j,\\
\max\{1+w,2(1-w)\},&\text{on a connector},\\
2,&\text{elsewhere}\end{cases}\geq\frac{4}{3}.$ 

(87)

The connector bound follows by minimizing over $0\leq w\leq 1$ , with equality at $w=1/3$ . Taking the infimum over common decoded states gives the recovery bound.
∎

The three lemmas now give the fixed-family lower bound.

Lemma C.9 (Fixed-Family Sharpness).

For every $d>1$ , there exist a fixed countable query universe $\mathcal{U}$ , a singleton input set $Q$ , and a compact state family $\mathcal{F}$ homeomorphic to $[0,1]$ , of diameter $1$ . The input observation map is injective, and $(\mathcal{F},Q)$ satisfies assumption 2.12 with $C=C_{d}$ and $\alpha=1$ .

For every integer $m\geq 1$ and every nonempty $P\subseteq\mathcal{U}\setminus Q$ with $|P|\leq m$ , there is a globally Lipschitz encoder $e:\mathbb{R}^{Q}\to\mathbb{R}^{2}$ such that

 $\mathcal{R}_{Q}^{\star}(e)-2\mathcal{L}_{Q,P}^{\star}(e)\geq\frac{1}{6}m^{-1/(2d)}.$ 

(88)

Proof.

Lemma C.6 supplies the fixed family and its geometric properties. For any admissible $m,P$ , take the pair from lemma C.7 and the encoder from lemma C.8. Then

 $\mathcal{R}_{Q}^{\star}(e)-2\mathcal{L}_{Q,P}^{\star}(e)\geq\frac{4}{3}s_{j}-d_{P}(f_{t_{i}}(P),f_{t_{k}}(P))\geq\frac{s_{j}}{3}\geq\frac{1}{6}m^{-1/(2d)}.$ 

(89)

∎

The uniform transfer residual. For the fixed family above, the uniform transfer residual in definition 3.6 measures the recovery cost of choosing targets before the encoder. The lower bound is supplied by lemma C.9; the upper bound follows from theorem 3.4.

Proof of theorem 3.7.

Use the fixed family in lemma C.9, and fix an integer $m\geq C_{d}^{2}/2$ .

Lower bound. For every admissible target set $P$ , lemma C.9 supplies a globally Lipschitz encoder witnessing

 $\sup_{e\in\mathcal{E}_{\mathrm{Lip}}}\bigl[\mathcal{R}_{Q}^{\star}(e)-2\mathcal{L}_{Q,P}^{\star}(e)\bigr]\geq\frac{1}{6}m^{-1/(2d)}.$ 

(90)

Taking the infimum over $P$ gives the lower bound for $\mathcal{T}_{m}(\mathcal{F},Q)$ .

Upper bound. Apply theorem 3.4 with $C=C_{d}$ and $\alpha=1$ . It supplies one admissible target set $P$ for which every encoder satisfies

 $\mathcal{R}_{Q}^{\star}(e)-2\mathcal{L}_{Q,P}^{\star}(e)\leq 3\left(\frac{C_{d}^{2}}{2m}\right)^{1/(2d)}.$ 

(91)

Taking the supremum over $\mathcal{E}_{\mathrm{Lip}}$ for this $P$ , then the infimum over all admissible target sets, gives the upper bound.

 $1$ -Lipschitz encoders. If $e$ has a Lipschitz bound $K\geq 1$ , then $e/K$ is $1$ -Lipschitz. Composing a readout with $z\mapsto Kz$ transfers it from $e$ to $e/K$ ; $z\mapsto z/K$ reverses this correspondence. Predictions and recovered states are preserved, so both optimal errors are unchanged. Every residual value is thus attained in the smaller class; inclusion gives the reverse inequality between suprema.
∎

Recovery and sampling. Classical optimal recovery describes the best readout from fixed information by the radius of its consistency sets (Traub et al., 1983, Chapters 1 and 3). Here the information is $e(f(Q))$ , and the same consistency set determines two errors: its radius in the admissible state family and its radius in the target observation space. The fixed arc makes their difference persist at every finite target budget.

Optimal sampling instead chooses queries together with a reconstruction map (Krieg and Ullrich, 2026, Sections 2 and 9.1). Write the arc as $\mathcal{F}=\{f_{t}:0\leq t\leq 1\}$ , with parameter query $p_{0}\in\mathcal{U}\setminus Q$ satisfying $f_{t}(p_{0})=t/2$ . This query determines the state exactly. With $a(y)=f_{2y}$ for $0\leq y\leq 1/2$ , extended by $f_{0}$ elsewhere,

 $\inf_{a:\mathbb{R}\to\mathcal{F}}\sup_{0\leq t\leq 1}d_{\mathcal{U}}\bigl(a(f_{t}(p_{0})),f_{t}\bigr)=0.$ 

(92)

The residual in equation 21 measures the budget needed to transfer prediction accuracy to recovery uniformly across encoders. On the constructed family, a residual tolerance $\varepsilon$ requires a budget of order $\varepsilon^{-2d}$ , while direct reconstruction from the parameter query is exact.

Uniform-norm discretization gives a related view of how finitely many queries preserve distinctions in a linear function space (Kosov and Temlyakov, 2024, Theorems 1.1 and 1.2). Its criterion is multiplicative norm preservation over that space. The criterion here couples prediction and state-valued recovery on a fixed nonlinear compact family. The covering bound controls the number of states needed at a given resolution; the pairwise witnesses in the construction determine the target budget.

Encoder regularity and target order. Theorem 3.7 gives a common encoder regularity bound. Keeping this bound fixed, we compare targets selected before and after the encoder.

Corollary C.10 (Target Selection Order).

On the fixed state family of lemma C.9, let $\mathcal{E}_{1}$ consist of the $1$ -Lipschitz maps $e:\mathbb{R}^{Q}\to\mathbb{R}^{2}$ . For every $e\in\mathcal{E}_{1}$ , there is a query $p\in\mathcal{U}\setminus Q$ such that $\mathcal{R}_{Q}^{\star}(e)\leq 2\mathcal{L}_{Q,\{p\}}^{\star}(e)$ . Consequently, for every integer $m\geq 1$ ,

 $\sup_{e\in\mathcal{E}_{1}}\inf_{\begin{subarray}{c}P\subseteq\mathcal{U}\setminus Q\\
1\leq|P|\leq m\end{subarray}}\bigl[\mathcal{R}_{Q}^{\star}(e)-2\mathcal{L}_{Q,P}^{\star}(e)\bigr]=0.$ 

(93)

Proof.

For a fixed $e\in\mathcal{E}_{1}$ , put

 $\Delta_{e}\coloneqq\max_{\begin{subarray}{c}f,g\in\mathcal{F}\\
e(f(Q))=e(g(Q))\end{subarray}}d_{\mathcal{U}}(f,g).$ 

(94)

The maximum exists: the map $f\mapsto e(f(Q))$ is continuous, so its equality set is a nonempty closed subset of $\mathcal{F}\times\mathcal{F}$ . By lemma A.2, a state-valued representative decoder gives $\mathcal{R}_{Q}^{\star}(e)\leq\Delta_{e}$ .

Each state on the arc has nonzero block mass in at most two blocks. For any pair, differences in private and height responses are confined to the finite union of their active blocks. The remaining differing coordinates are $q_{0},p_{0}$ , whose differences coincide. A query outside $Q$ therefore attains the full distance of the pair. Apply this to a pair attaining $\Delta_{e}$ , and call its query $p$ . The largest $p$ -response gap among pairs sharing encoder output equals $\Delta_{e}$ : this pair attains it, and every such gap is bounded by the full-state gap. By lemma 3.1,

 $\mathcal{R}_{Q}^{\star}(e)\leq\Delta_{e}=2\mathcal{L}_{Q,\{p\}}^{\star}(e).$ 

(95)

When $\Delta_{e}=0$ , the same conclusion holds with any available query. Each encoder thus has a singleton target giving a nonpositive residual. Conversely, $e(u)=(u,0)$ belongs to $\mathcal{E}_{1}$ , and the input observation identifies every state. For this encoder both optimal errors are zero for every target set. Taking the indicated infimum and supremum proves equation 93.
∎

A finite-query comparison. Allowing the family to depend on the budget yields a complementary construction: the encoder is linear, the query universe is finite, and the exponent range includes $d=1$ . The same order is attained at prediction-error coefficient $2$ and $\alpha=1$ .

Proposition C.11 (Budget Sharpness).

For every $d\geq 1$ , there is a constant $c_{d}>0$ such that, for each integer $m\geq 1$ , there exist a finite query universe $\mathcal{U}$ , a query set $Q$ , and a compact connected one-dimensional state manifold $\mathcal{F}$ of diameter $1$ , such that $(\mathcal{F},Q)$ satisfies assumption 2.12 with $C=3$ and $\alpha=1$ . The input observation map is injective. For every nonempty $P\subseteq\mathcal{U}\setminus Q$ with $|P|\leq m$ , there is a linear encoder into a Euclidean learned state space such that

 $\mathcal{R}_{Q}^{\star}(e)\geq 2\mathcal{L}_{Q,P}^{\star}(e)+c_{d}m^{-1/(2d)}.$ 

(96)

Proof.

State space. Fix $d\geq 1$ and $m\geq 1$ , and set

 $N\coloneqq\lceil\sqrt{2m}\rceil+3,\qquad s\coloneqq\frac{1}{2}N^{-1/d}.$ 

(97)

Let $v_{1},\ldots,v_{N}$ be the standard basis of $\mathbb{R}^{N}$ , with $v_{N+1}=v_{1}$ . On the polygonal cycle $\bigcup_{i=1}^{N}[v_{i},v_{i+1}]$ , let $H(\lambda)=2\min\{\lambda_{1},\lambda_{2}\}$ . This continuous function is zero off the edge $[v_{1},v_{2}]$ and reaches $1$ at its midpoint. Take $Q=\{q_{0},q_{1},\ldots,q_{N}\}$ and $\mathcal{U}\setminus Q=\{p_{0}\}\cup\{p_{ij}:1\leq i<j\leq N\}$ . For each $\lambda$ on the cycle, define, for $1\leq i\leq N$ and $1\leq i<j\leq N$ ,

 $f_{\lambda}(q_{i})\coloneqq s\lambda_{i},\qquad f_{\lambda}(p_{ij})\coloneqq s(\lambda_{i}-\lambda_{j}).$ 

(98)

Also set $f_{\lambda}(q_{0})=f_{\lambda}(p_{0})=H(\lambda)$ , lifting one edge while leaving all vertices unchanged. Let $\mathcal{F}$ consist of these states, and write $f_{i}=f_{v_{i}}$ . The map $\lambda\mapsto f_{\lambda}$ is continuous, with continuous inverse $\lambda_{i}=f_{\lambda}(q_{i})/s$ . Thus $\mathcal{F}$ is homeomorphic to the cycle, a compact connected one-dimensional manifold, and the input observation map is injective. Since $\sum_{i}\lambda_{i}=\sum_{i}\mu_{i}=1$ , we have

 $d_{\mathcal{U}}(f_{\lambda},f_{\mu})=\max\bigl\{s[\max_{k}(\lambda_{k}-\mu_{k})-\min_{k}(\lambda_{k}-\mu_{k})],|H(\lambda)-H(\mu)|\bigr\}.$ 

(99)

The target queries capture both terms, so target observability holds with $\alpha=1$ . Since $2s\leq 1$ and $H$ ranges from $0$ to $1$ , the diameter is exactly $1$ .

Covering bound. Each unlifted edge has length $2s$ in $d_{\mathcal{U}}$ . For $0<\varepsilon<s$ , the unlifted part can be covered by at most $N\lceil s/\varepsilon\rceil$ balls centered along these edges. Since $d\geq 1$ ,

 $N\lceil s/\varepsilon\rceil\leq\frac{2Ns}{\varepsilon}\leq 2Ns^{d}\varepsilon^{-d}=2^{1-d}\varepsilon^{-d}\leq\varepsilon^{-d}.$ 

(100)

For $s\leq\varepsilon<2s$ , the $N$ vertices cover the unlifted part and $N=(2s)^{-d}\leq\varepsilon^{-d}$ . For $2s\leq\varepsilon\leq 1$ , one ball centered at a vertex covers that part, and $1\leq\varepsilon^{-d}$ . The lifted edge consists of two segments of length $1$ each, so it admits a $1$ -Lipschitz parametrization on an interval of length $2$ . It can therefore be covered by $\lceil 1/\varepsilon\rceil\leq 2\varepsilon^{-1}$ additional balls centered along it. Consequently,

 $\mathcal{N}_{\mathcal{F}}(\varepsilon)\leq\varepsilon^{-d}+2\varepsilon^{-1}\leq 3\varepsilon^{-d},\qquad 0<\varepsilon\leq 1.$ 

(101)

Encoder construction. Fix any allowed $P$ . The cycle has $N(N-3)/2>m$ unordered nonadjacent vertex pairs, so some such pair $i<j$ has $p_{ij}\notin P$ . Define a linear encoder $e:\mathbb{R}^{Q}\to\mathcal{Z}=\mathbb{R}^{N}$ by

 $e(x)\coloneqq\bigl(x(q_{0}),\,x(q_{i})+x(q_{j}),\,(x(q_{k}))_{k\in\{1,\ldots,N\}\setminus\{i,j\}}\bigr).$ 

(102)

It combines the two corresponding input coordinates and retains all others. In particular, $f_{i}$ and $f_{j}$ have the same learned state. The diagram illustrates the nonadjacent pair and its common learned state.

Recovery lower bound. Any state decoder must give one output $g=f_{\lambda}\in\mathcal{F}$ to the common learned state of $f_{i},f_{j}$ . A point on the cycle has at most two nonzero coordinates, at adjacent vertices. Since $i,j$ are nonadjacent, at least one of $\lambda_{i},\lambda_{j}$ is zero. Also $\max_{k}\lambda_{k}\geq 1/2$ . By equation 99,

 $\max\{d_{\mathcal{U}}(f_{i},g),d_{\mathcal{U}}(f_{j},g)\}\geq s\bigl(1+\max_{k}\lambda_{k}\bigr)\geq\frac{3s}{2}.$ 

(103)

Thus every decoder has recovery error at least $3s/2$ , so $\mathcal{R}_{Q}^{\star}(e)\geq 3s/2$ .

Prediction upper bound. If $e(f_{\lambda}(Q))=e(f_{\mu}(Q))$ , then $\lambda-\mu=t(v_{i}-v_{j})$ for some $|t|\leq 1$ , and $H(\lambda)=H(\mu)$ . The query $p_{ij}$ differs by $2s|t|$ ; every other pair query differs by at most $s|t|$ , and $p_{0}$ has identical observations. Since $p_{ij}\notin P$ , lemma 3.1 gives

 $\mathcal{L}_{Q,P}^{\star}(e)\leq\frac{s}{2}.$ 

(104)

Combining the two error bounds and using $N\leq\sqrt{2m}+4\leq 6\sqrt{m}$ , we obtain

 $\mathcal{R}_{Q}^{\star}(e)-2\mathcal{L}_{Q,P}^{\star}(e)\geq\frac{s}{2}=\frac{1}{4}N^{-1/d}\geq\frac{1}{4\cdot 6^{1/d}}m^{-1/(2d)}.$ 

(105)

Taking $c_{d}=1/(4\cdot 6^{1/d})$ completes the proof.
∎

## Appendix D Fine-Tuning and Recovery

The preceding results start from prediction error over the entire state family. Fine-tuning instead gives an error on training observations. Coverage and prediction stability connect these quantities: a nearby training record controls the prediction at an unobserved state. The general and low-dimensional bounds then transfer that control to recovery.

## D.1 Fine-Tuning Setup

We work under assumption A.4. Fix disjoint query sets $Q,P$ and maps $e:\mathbb{R}^{Q}\to\mathcal{Z}$ , $b:\mathcal{Z}\to\mathbb{R}^{P}$ , where $\mathcal{Z}$ is nonempty. We first control this pair’s prediction error from its errors on the training records.

Use the recorded error and observation coverage radius from definition 3.8, together with assumption 3.9. By equation 33, $h_{n}$ is no larger than the coverage radius in the full ontic metric. The asymptotic results use a common stability modulus across the returned outputs.

Lemma D.1 (Record Extension).

Let $(\mathcal{F},d_{\mathcal{U}})$ be nonempty and compact, and let $f_{1},\ldots,f_{n}\in\mathcal{F}$ with $n\geq 1$ index the training records. For disjoint query sets $Q,P$ , every pair $(e,b)$ satisfying assumption 3.9 obeys

 $\widehat{\mathcal{L}}_{Q,P,n}(b;e)\leq\boxed{\mathcal{L}_{Q,P}(b;e)}\leq\widehat{\mathcal{L}}_{Q,P,n}(b;e)+\rho(h_{n})+h_{n},$ 

(106)

where $h_{n}$ is the observation coverage radius in equation 24.

Proof.

The empirical error is a maximum over states in $\mathcal{F}$ , so it cannot exceed the full-family error. For the upper bound, fix $f\in\mathcal{F}$ and choose a nearest training observation pair. Its generating state $f_{i}$ satisfies $d_{Q\cup P}(f(Q\cup P),f_{i}(Q\cup P))\leq h_{n}$ . Prediction stability and the triangle inequality give

 $\displaystyle d_{P}\bigl((b\circ e)(f(Q)),f(P)\bigr)$ 
 $\displaystyle\leq d_{P}\bigl((b\circ e)(f(Q)),(b\circ e)(f_{i}(Q))\bigr)+d_{P}\bigl((b\circ e)(f_{i}(Q)),f_{i}(P)\bigr)$ 

(107)

 $\displaystyle+d_{P}\bigl(f_{i}(P),f(P)\bigr)\leq\rho(h_{n})+\widehat{\mathcal{L}}_{Q,P,n}(b;e)+h_{n}.$ 

Taking the supremum over $f$ proves the upper bound. Both the empirical maximum and the coverage radius are finite, so the full-family error is finite as well.
∎

Proof of proposition 3.10.

Lemma D.1 gives the prediction bound. Since the optimal prediction error is no larger, theorems 3.2 and 3.4 and monotonicity of $\omega_{P}$ give the two recovery bounds.
∎

We now choose the pair by fine-tuning. Let $\mathcal{H}$ be the nonempty class of encoder–predictor pairs accessible from the initialization by changing the permitted parameters. The empirical error is defined in equation 23.

Definition D.2 (Fine-Tuning).

The optimal prediction error in the fine-tuning class is

 $\mathcal{L}_{Q,P}^{\mathcal{H},\star}\coloneqq\inf_{(e,b)\in\mathcal{H}}\mathcal{L}_{Q,P}(b;e).$ 

(108)

Given an optimization tolerance $\eta\geq 0$ , an $\eta$ -optimal fine-tuning output is a pair $(\hat{e},\hat{b})\in\mathcal{H}$ satisfying

 $\widehat{\mathcal{L}}_{Q,P,n}(\hat{b};\hat{e})\leq\inf_{(e,b)\in\mathcal{H}}\widehat{\mathcal{L}}_{Q,P,n}(b;e)+\eta.$ 

(109)

For every $\eta>0$ , an $\eta$ -optimal output exists by the definition of the infimum. At $\eta=0$ , the rule selects an empirical minimizer whenever the infimum is attained. The quantity $\mathcal{L}_{Q,P}^{\mathcal{H},\star}$ optimizes jointly over the permitted encoder–predictor pairs, while $\mathcal{L}_{Q,P}^{\star}(e)$ holds the encoder fixed.

For a fine-tuning output, the same lemma combines with empirical near-optimality to relate its prediction error to the best error in the model class.

Corollary D.3 (Fine-Tuning Consistency).

Every $\eta$ -optimal fine-tuning output satisfying assumption 3.9 obeys

 $\mathcal{L}_{Q,P}^{\mathcal{H},\star}\leq\boxed{\mathcal{L}_{Q,P}(\hat{b};\hat{e})}\leq\mathcal{L}_{Q,P}^{\mathcal{H},\star}+\eta+\rho(h_{n})+h_{n}.$ 

(110)

For stages $k\geq 1$ , allow the training data, query sets, model classes, and learned state spaces to vary, with a common modulus $\rho$ for the returned outputs. Let $(\hat{e}_{k},\hat{b}_{k})$ be $\eta_{k}$ -optimal outputs and let $h_{k}$ be the corresponding observation coverage radius. If

 $\mathcal{L}_{Q_{k},P_{k}}^{\mathcal{H}_{k},\star}+\eta_{k}+h_{k}\xrightarrow{k\to\infty}0,$ 

(111)

then

 $0\leq\mathcal{L}_{Q_{k},P_{k}}^{\star}(\hat{e}_{k})\leq\mathcal{L}_{Q_{k},P_{k}}(\hat{b}_{k};\hat{e}_{k})\xrightarrow{k\to\infty}0.$ 

(112)

Proof.

For every pair in $\mathcal{H}$ , the empirical error is no larger than its full-family error. Hence the fine-tuning rule gives

 $\widehat{\mathcal{L}}_{Q,P,n}(\hat{b};\hat{e})\leq\inf_{(e,b)\in\mathcal{H}}\widehat{\mathcal{L}}_{Q,P,n}(b;e)+\eta\leq\mathcal{L}_{Q,P}^{\mathcal{H},\star}+\eta.$ 

(113)

Apply lemma D.1 to the returned pair to obtain the upper bounds. The lower bound follows because $(\hat{e},\hat{b})\in\mathcal{H}$ .

Under equation 111, all three nonnegative terms tend to zero. In particular, $h_{k}\to 0$ , so $\rho(h_{k})\to 0$ . The same bound gives $\mathcal{L}_{Q_{k},P_{k}}(\hat{b}_{k};\hat{e}_{k})\to 0$ , and the optimal prediction error is no larger.
∎

## D.2 General Case

Theorem D.4 (General Fine-Tuning Bound).

Every $\eta$ -optimal fine-tuning output satisfying assumption 3.9 obeys

 $\mathcal{L}_{Q,P}^{\star}(\hat{e})\leq\boxed{\mathcal{R}_{Q}^{\star}(\hat{e})}\leq\omega_{P}\!\Bigl(2\bigl[\mathcal{L}_{Q,P}^{\mathcal{H},\star}+\eta+\rho(h_{n})+h_{n}\bigr]\Bigr).$ 

(114)

For stages $k\geq 1$ , allow the training states, query sets, model classes and learned state spaces to vary, with a common modulus $\rho$ for the returned outputs. Let $(\hat{e}_{k},\hat{b}_{k})$ denote the $\eta_{k}$ -optimal outputs. If $(P_{k})_{k\geq 1}$ is a query sequence separating states in $\mathcal{F}$ and

 $\mathcal{L}_{Q_{k},P_{k}}^{\mathcal{H}_{k},\star}+\eta_{k}+h_{k}\xrightarrow{k\to\infty}0,$ 

(115)

then $\mathcal{R}_{Q_{k}}^{\star}(\hat{e}_{k})\to 0$ . Here $h_{k}$ is the coverage radius of the training observations on $Q_{k}\cup P_{k}$ at stage $k$ , defined as in equation 24.

Proof.

Substitute equation 110 into theorem 3.2, using $\mathcal{L}_{Q,P}^{\star}(\hat{e})\leq\mathcal{L}_{Q,P}(\hat{b};\hat{e})$ and the monotonicity of $\omega_{P}$ .

For the asymptotic claim, corollary D.3 gives vanishing optimal prediction error. State separation and theorem 3.3 then give vanishing recovery error.
∎

## D.3 Low-Dimensional Case

Using the targets constructed in theorem 3.4 makes the query budget explicit under the same training rule and stability condition.

Theorem D.5 (Low-Dimensional Fine-Tuning Bound).

Suppose $(\mathcal{F},Q)$ satisfies assumption 2.12 with constants $C,d,\alpha$ . For every integer $m\geq C^{2}/2$ , choose $P\subseteq\mathcal{U}\setminus Q$ as in theorem 3.4, with $|P|\leq m$ . Every $\eta$ -optimal fine-tuning output satisfying assumption 3.9 obeys

 $\mathcal{L}_{Q,P}^{\star}(\hat{e})\leq\boxed{\mathcal{R}_{Q}^{\star}(\hat{e})}\leq\frac{2}{\alpha}\bigl[\mathcal{L}_{Q,P}^{\mathcal{H},\star}+\eta+\rho(h_{n})+h_{n}\bigr]+\frac{2+\alpha}{\alpha}\left(\frac{C^{2}}{2m}\right)^{\frac{1}{2d}}.$ 

(116)

For budgets $m\to\infty$ , allow the training states, input sets, model classes, and learned state spaces to vary, selecting each $P_{m}$ by the same construction. Let $(\hat{e}_{m},\hat{b}_{m})$ denote the $\eta_{m}$ -optimal outputs. If $C,d,\alpha$ and $\rho$ are common across budgets and

 $\mathcal{L}_{Q_{m},P_{m}}^{\mathcal{H}_{m},\star}+\eta_{m}+h_{m}\xrightarrow{m\to\infty}0,$ 

(117)

then $\mathcal{R}_{Q_{m}}^{\star}(\hat{e}_{m})\to 0$ . Here $h_{m}$ is the coverage radius of the training observations on $Q_{m}\cup P_{m}$ at budget $m$ , defined as in equation 24.

Proof.

Select $P$ by theorem 3.4, before the training class and output are specified. Substitute equation 110 into that theorem, using $\mathcal{L}_{Q,P}^{\star}(\hat{e})\leq\mathcal{L}_{Q,P}(\hat{b};\hat{e})$ .

Under the stated convergence condition, corollary D.3 gives vanishing optimal prediction error. Applying theorem 3.5 to the selected target sets gives vanishing recovery error.
∎

The bounds identify the contributions of the model class, optimization tolerance, training coverage, and prediction stability. The low-dimensional result also makes the target-query budget explicit: $n$ counts training records, while $m$ counts target queries.

## Appendix E Recovery from Noisy Observations

The construction in theorem 3.4 also applies when a query’s response is a conditional mean and its observation is noisy. The state specifies the mean response profile; the measurement law describes how a recording is drawn from it. Prediction error and measurement perturbation then enter the same distance to a covering center. Restricting the construction to a frequently encountered state family gives a probability guarantee and an integrated recovery bound.

Let $\mathcal{F}$ be compact with diameter $D$ , and let $G\subseteq\mathcal{F}$ be nonempty and compact. Suppose $(G,Q)$ satisfies assumption 2.12 with constants $C_{G},d,\alpha$ . For an integer $m\geq C_{G}^{2}/2$ , select $P$ and covering centers by theorem 3.4 on $G$ .

Let $\Phi=b\circ e$ be Borel measurable and $K$ -Lipschitz on the full input space, with prediction error at most $\ell$ on $G$ . Decode to the covering center closest to $b(z)$ on $P$ , resolving ties by index. This defines a state decoder $a(z)$ ; the composition $a\circ e$ is measurable because it is a finite selection determined by $\Phi$ .

Lemma E.1 (Recovery under Perturbation).

Under this setup, if $f\in G$ and $d_{Q}(x,f(Q))\leq\eta$ , then

 $d_{\mathcal{U}}((a\circ e)(x),f)\leq\frac{2}{\alpha}(\ell+K\eta)+\frac{2+\alpha}{\alpha}\left(\frac{C_{G}^{2}}{2m}\right)^{1/(2d)}.$ 

(118)

Proof.

The triangle inequality and input sensitivity give

 $d_{P}(\Phi(x),f(P))\leq d_{P}(\Phi(x),\Phi(f(Q)))+d_{P}(\Phi(f(Q)),f(P))\leq K\eta+\ell.$ 

(119)

Apply lemma C.4 on $G$ with $y=\Phi(x)$ and the radius and allowance fixed in theorem 3.4. Substitution gives equation 118.
∎

The pointwise bound becomes a probability guarantee when both the state and the measurement lie in their specified ranges.

Corollary E.2 (Recovery under Noise).

Under the preceding setup, let $F$ have a Borel law $\mu$ with $\mu(G)\geq 1-\delta$ , where $\delta\in[0,1)$ . Suppose the measured input $X$ satisfies, for every $f\in G$ ,

 $\Pr\bigl(d_{Q}(X,f(Q))\leq\eta\mid F=f\bigr)\geq 1-\zeta,$ 

(120)

where $\eta\geq 0$ and $\zeta\in(0,1)$ . With

 $B\coloneqq\min\left\{D,\frac{2}{\alpha}(\ell+K\eta)+\frac{2+\alpha}{\alpha}\left(\frac{C_{G}^{2}}{2m}\right)^{1/(2d)}\right\},$ 

(121)

the recovery error obeys

 $\displaystyle\Pr\bigl(d_{\mathcal{U}}((a\circ e)(X),F)\leq B\bigr)$ 
 $\displaystyle\geq 1-\delta-\zeta,$ 

(122)

 $\displaystyle\mathbb{E}\,d_{\mathcal{U}}((a\circ e)(X),F)^{2}$ 
 $\displaystyle\leq B^{2}+D^{2}(\delta+\zeta).$ 

(123)

Proof.

The event $F\in G$ and $d_{Q}(X,F(Q))\leq\eta$ has probability at least

 $\mu(G)(1-\zeta)\geq(1-\delta)(1-\zeta)\geq 1-\delta-\zeta.$ 

(124)

On this event, lemma E.1 and the diameter bound give error at most $B$ . Off it, the error is at most $D$ because both states lie in $\mathcal{F}$ . This proves the probability bound; splitting the squared-error expectation over the two events gives the second bound.
∎

Count observations. For a conditional Poisson measurement law, take $X_{q}=N_{q}/T$ , where $N_{q}\mid F=f$ has mean $Tf(q)$ and $0\leq f(q)\leq\Lambda$ on $G$ . Here $T$ is the exposure. A valid input-noise radius is

 $\eta(T,\zeta)=\sqrt{\frac{2\Lambda\log(2|Q|/\zeta)}{T}}+\frac{2\log(2|Q|/\zeta)}{3T}.$ 

(125)

Indeed, the centered Poisson moment-generating function obeys $\log\mathbb{E}e^{u(N_{q}-Tf(q))}=Tf(q)(e^{u}-1-u)$ . The bound $e^{u}-1-u\leq u^{2}/[2(1-u/3)]$ for $0\leq u<3$ , and the corresponding lower-tail bound, give

 $\Pr\left(\left|N_{q}-Tf(q)\right|>\sqrt{2T\Lambda v}+\frac{2v}{3}\,\middle|\,F=f\right)\leq 2e^{-v}.$ 

(126)

Choose $v=\log(2|Q|/\zeta)$ and take a union bound. This uses each channel’s conditional Poisson law and permits dependence between channels. Exposure controls the measurement contribution to recovery, through $K\eta(T,\zeta)$ .

Prediction sensitivity. For a continuously differentiable predictor composition, a sufficient full-input constant is

 $K\geq\sup_{x\in\mathbb{R}^{Q}}\|J_{\Phi}(x)\|_{\infty\to\infty}=\sup_{x\in\mathbb{R}^{Q}}\max_{p\in P}\sum_{q\in Q}\left|\frac{\partial\Phi_{p}(x)}{\partial x_{q}}\right|.$ 

(127)

The derivative bound may instead be taken on a convex domain containing every input and intervening segment used in the guarantee.

Functional observability. Functional observers recover selected state coordinates in structured dynamical networks; algebraic and graph conditions characterize which targets are accessible (Montanari et al., 2022; Montanari et al., 2023). Observability also guides the eigenstructure and sparsity of neural state-space architectures (Gracyk, 2026; Hamdan et al., 2024). Here, the state is specified by its complete query-response profile, and quantitative target observability compares its full metric with the remaining responses. The query-budget construction uses this comparison to turn target prediction into a state-valued recovery map. Retracing adds cycle consistency to predictive state learning in reinforcement learning (Yu et al., 2022); our bounds concern the distinctions preserved by a fixed encoder and the error of recovering its response profile.

## F.3 Assumption Checks

Observability. Write $r$ for the number of ambient latent coordinates: $d+1$ for the sphere, $2d$ for the torus, and $D$ for the box. Let $I(P)=\{i(j):(j,k)\in P\}$ . For the observation law in equation 30,

 $P\text{ separates }\mathcal{F}\quad\Longleftrightarrow\quad I(P)=\{1,\ldots,r\}.$ 

(128)

Full coordinate coverage gives separation by proposition 4.1. Conversely, each latent domain is invariant under changing the sign of one coordinate and contains a state with that coordinate nonzero. Reflecting an unobserved coordinate therefore gives two distinct states with identical target responses. Their full profiles differ because the query universe observes every coordinate.

Proof of proposition 4.1.

Bound each channel. Fix $f=f_{x}$ and $g=f_{x^{\prime}}$ in $\mathcal{F}$ . For every channel $(j,k)$ and $|t|\leq 1$ ,

 $a_{jk}\operatorname{sech}^{2}(a_{jk}+|c_{jk}|)\leq\left|\frac{d}{dt}\tanh(a_{jk}s_{j}t+c_{jk})\right|\leq a_{jk}.$ 

(129)

The mean value theorem, followed by maximization over the selected target channels and over all channels, respectively, gives

 $d_{P}(f,g)\geq\max_{i}\ell_{i}|x_{i}-x_{i}^{\prime}|,\qquad d_{\mathcal{U}}(f,g)\leq\max_{i}A_{i}|x_{i}-x_{i}^{\prime}|.$ 

(130)

A single increasing channel turns coordinate separation into response separation:

Compare the distances. Every coordinate has a target channel with positive slope magnitude, so $\ell_{i}>0$ and $A_{i}>0$ . There are finitely many coordinates, hence $\alpha_{P}=\min_{i}\ell_{i}/A_{i}>0$ . Since $\ell_{i}\geq\alpha_{P}A_{i}$ for every $i$ ,

 $d_{P}(f,g)\geq\max_{i}\ell_{i}|x_{i}-x_{i}^{\prime}|\geq\alpha_{P}\max_{i}A_{i}|x_{i}-x_{i}^{\prime}|\geq\alpha_{P}d_{\mathcal{U}}(f,g).$ 

(131)

This proves equation 32.
∎

For each certified target set, we recompute this constant and the test-error transfer. The input and candidate-target pools cover all latent coordinates.

Query budget. The actual target sampler permits a finite-budget calculation. Let $M$ be the target-pool size, and let $n_{i}$ count its channels observing latent coordinate $i$ . A uniform subset of size $m$ misses coordinate $i$ with probability $\binom{M-n_{i}}{m}/\binom{M}{m}$ . Hence

 $\Pr\{P\text{ fails to separate }\mathcal{F}\}\leq\min\left\{1,\sum_{i=1}^{r}\frac{\binom{M-n_{i}}{m}}{\binom{M}{m}}\right\},$ 

(132)

where a binomial coefficient is zero when its lower argument exceeds its upper argument. On the complementary event, the global error transfer holds simultaneously for every predictor and every state, using the corresponding $\alpha_{P}$ . In particular, this event is determined before predictive training. Each term in the sum is at most $\exp(-m\min_{i}n_{i}/M)$ . Thus $m\geq(M/\min_{i}n_{i})\log(r/\eta)$ suffices for failure probability at most $\eta$ whenever this budget is available; querying the full pool always separates. For the repeated-coordinate low-dimensional families, $M/\min_{i}n_{i}$ is of the order of $r$ , giving a budget of order $r\log(r/\eta)$ .

We evaluate the without-replacement bound using the actual channel counts (table 7). The low-dimensional families repeat each latent coordinate across many channels, so their sufficient budgets are much smaller. These are family-specific sampling guarantees; the general covering theorem accommodates arbitrary admissible response laws.

## F.4 Error Transfer

When every latent coordinate has a target channel, equation 32 supplies the global observability constant $\alpha_{P}$ .
For the ideal GT map, the true state is a feasible candidate, so the fitted target residual is at most the prediction error. For a numerical output $g\in\mathcal{F}$ whose target residual is within $\xi\geq 0$ of the minimum, observability and the triangle inequality give

 $\alpha_{P}d_{\mathcal{U}}(g,f)\leq d_{P}(g(P),y)+d_{P}(y,f(P))\leq 2d_{P}(y,f(P))+\xi.$ 

(134)

The exact map has $\xi=0$ . With exact feasibility tests and feasible-point construction, $44$ bisections of $[0,\|y\|_{\infty}+1]$ , followed by a $10^{-10}$ feasibility expansion, give $\xi\leq 2^{-44}(\|y\|_{\infty}+1)+10^{-10}$ . For a feasible Float64 output, $\xi$ also includes arithmetic effects on the target residual. Finite-test plots compare the numerical recovery errors with the exact-map benchmark $2\widehat{L}/\alpha_{P}$ , where $\widehat{L}$ is the maximum test prediction error. ## F.5 Uniform Prediction and Recovery

The preceding transfer checks use test states. The coordinatewise architecture also permits a bound over the entire known family. For a target $t=(j,k)$ , put $v=s_{j}x_{i(j)}$ and write $h_{t}(v)$ for the predicted observation minus $\tanh(a_{jk}v+c_{jk})$ . Writing $e_{\rm sh}$ and $b_{\rm sh}$ for the shared MLPs in table 6, the implemented coordinatewise composition is

 $\displaystyle h_{t}(v)={}$ 
 $\displaystyle b_{\rm sh}\!\Bigl(e_{\rm sh}\bigl(\tanh(a_{j1}v+c_{j1}),\tanh(a_{j2}v+c_{j2}),a_{j1},a_{j2},c_{j1},c_{j2}\bigr),a_{jk},c_{jk}\Bigr)$ 

(135)

 $\displaystyle-\tanh(a_{jk}v+c_{jk}).$ 

Thus each target prediction depends only on $v$ and its query coefficients. Each latent coordinate ranges over $[-1,1]$ in every family, so

 $\mathcal{L}_{Q,P}(b;e)=\max_{t\in P}\sup_{v\in[-1,1]}|h_{t}(v)|.$ 

(136)

The supremum commutes with the finite maximum: each target’s extremum can be attained at a state of its own. Agreement between the network forward pass and its scalar form checks this reduction before the domain audit.

We bound prediction sensitivity in the full input-observation norm using the trained weights. Let $W_{1},\ldots,W_{6}$ be the successive encoder and predictor matrices, $w_{1},w_{2}$ the varying observation columns of $W_{1}$ , and $W_{4,h}$ the hidden-state columns of the first predictor matrix. Using the GELU derivative bound $1.13$ , a valid constant is

 $K=1.13^{4}\|W_{6}\|_{2}\|W_{5}\|_{2}\|W_{4,h}\|_{2}\cdot\|W_{3}\|_{2}\|W_{2}\|_{2}\max_{\sigma\in\{-1,1\}}\|w_{1}+\sigma w_{2}\|_{2}.$ 

(137)

Every varying input observation enters this calculation. The encoder–predictor composition therefore satisfies assumption 3.9 with $\rho(t)=Kt$ . The scalar error has Lipschitz constant $H_{t}=K\max(a_{j1},a_{j2})+a_{jk}$ , since $\tanh$ is Lipschitz with constant one.

On a regular grid $v_{\ell}=-1+2\ell/N$ , let $M_{t}=\max_{0\leq\ell\leq N}|h_{t}(v_{\ell})|$ . Every point of the interval lies within $1/N$ of the grid. Thus

 $\max_{t\in P}M_{t}\leq\boxed{\mathcal{L}_{Q,P}(b;e)}\leq\max_{t\in P}\left(M_{t}+\frac{H_{t}}{N}\right).$ 

(138)

For the reported numerical values, let $\widetilde{M}_{t}$ be the Float64 grid maximum and use the arithmetic allowance $10^{-6}$ . We use

 $\underline{L}=\max\{0,\max_{t\in P}\widetilde{M}_{t}-10^{-6}\},\qquad\overline{L}=\max_{t\in P}(\widetilde{M}_{t}+H_{t}/N)+10^{-6}.$ 

(139)

The numerical enclosure assumes that $10^{-6}$ covers grid-evaluation and enclosure-arithmetic error, and that the evaluated $H_{t}$ remain valid Lipschitz upper bounds. Recovery additionally assumes that the evaluated $\alpha_{P}>0$ remains a valid observability lower bound. Tables report Float64 evaluations of the resulting conditional analytic bounds at the stated display precision; rounding the final quotient and its displayed value is separate from the analytic inequality. The implementation uses high-precision spot checks and ordinary Float64 arithmetic. Table 9 records the allowance and checks.

The grid is an offline domain audit of the fixed predictor. Its resolution is determined by the weight bound and a preset interpolation tolerance. Under the arithmetic conditions above, the ideal GT map in equation 31 obeys

 $\sup_{f\in\mathcal{F}}d_{\mathcal{U}}\bigl(\widehat{f}((b\circ e)(f(Q))),f\bigr)\leq\frac{2\overline{L}}{\alpha_{P}},$ 

(140)

where $\overline{L}$ denotes the numerical upper enclosure. For feasible numerical outputs in $\mathcal{F}$ , a uniform residual slack $\xi$ adds $\xi/\alpha_{P}$ by equation 134.

## Appendix G Joint-Query Calibration

This joint-query family makes the mechanism in theorem 3.2 explicit: target separation converts prediction error into recovery of the full state. Its linear inverse link lets records at known latent coordinates control global prediction error directly.

For the calibration certificate below, each query depends on the whole latent configuration. For $x\in\mathbb{S}^{r-1}$ , define $f_{x}(q)=\tanh(a_{q}^{\top}x)$ . The input matrix $A_{Q}$ and base target matrix $A_{P}$ have independently drawn unit rows. Target sets vary through $A_{\lambda}=A_{P}\operatorname{diag}(1,\ldots,1,\lambda)$ with $0\leq\lambda\leq 1$ , so every row has Euclidean norm at most one; the query universe contains the input rows and every target variant. This keeps the ontic state family fixed while changing the distinctions available to prediction.

Consider an encoder applying the inverse response link and a matrix, followed by a joint predictor:

 $(b\circ e)(f_{x}(Q))=\tanh\bigl(W_{P}W_{E}\operatorname{arctanh}(f_{x}(Q))\bigr).$ 

(141)

Inputs are clipped to the valid observation range before applying the inverse link. The resulting full-input prediction map is Lipschitz with constant at most $\cosh^{2}(1)\|W_{P}W_{E}\|_{\infty\to\infty}$ .

We obtain prediction, observability and recovery bounds from the same calibration records below. Throughout this section, $\sigma_{\min}(A)=\inf_{\|v\|_{2}=1}\|Av\|_{2}$ , so positivity means full column rank.

## G.1 From Training Residuals to a Global Bound

Calibration records connect prediction error to recovery in three steps: they bound the global prediction error, certify that the targets distinguish states, and determine a recovery map.

For the joint-query family, set $A_{P}=A_{\lambda}$ and $M=W_{P}W_{E}$ . Let the calibration matrix $X\in\mathbb{R}^{n\times r}$ have full column rank, with $\sigma=\sigma_{\min}(X)>0$ . The inverse-link records $U\in\mathbb{R}^{n\times|Q|}$ and $V\in\mathbb{R}^{n\times|P|}$ approximate $XA_{Q}^{\top}$ and $XA_{P}^{\top}$ with entrywise errors at most $\eta_{Q}$ and $\eta_{P}$ , respectively. The weights may be fitted to these records.

Lemma G.1 (Calibration Error).

Under the calibration setup, let $Y\in\mathbb{R}^{n\times k}$ and $B\in\mathbb{R}^{r\times k}$ satisfy $|(Y-XB)_{ij}|\leq\eta$ . Then

 $\max_{j}\|(X^{\dagger}Y-B)_{\cdot j}\|_{2}\leq\frac{\sqrt{n}\eta}{\sigma},\qquad\|X^{\dagger}Y-B\|_{2\to 2}\leq\frac{\sqrt{nk}\eta}{\sigma}.$ 

(142)

Proof.

Since $X^{\dagger}X=I$ ,

 $X^{\dagger}Y-B=X^{\dagger}(Y-XB).$ 

(143)

Each column of $Y-XB$ has norm at most $\sqrt{n}\eta$ , and its Frobenius norm is at most $\sqrt{nk}\eta$ . Multiplication by $X^{\dagger}$ , whose operator norm is $1/\sigma$ , gives both bounds.
∎

Lemma G.2 (Calibrated Prediction).

Define the residual and its global error bound by

 $\displaystyle R$ 
 $\displaystyle\coloneqq UM^{\top}-V,$ 

(144)

 $\displaystyle\Delta$ 
 $\displaystyle\coloneqq\max_{p\in P}\|X^{\dagger}R_{\cdot p}\|_{2}+\frac{\sqrt{n}}{\sigma}\bigl(\|M\|_{\infty\to\infty}\eta_{Q}+\eta_{P}\bigr).$ 

(145)

Then

 $\mathcal{L}_{Q,P}(b;e)\leq\max_{p\in P}\|(MA_{Q}-A_{P})_{p}\|_{2}\leq\Delta.$ 

(146)

For exact records, $\eta_{Q}=\eta_{P}=0$ , the second inequality is an equality.

Proof.

The residual satisfies

 $R-X(MA_{Q}-A_{P})^{\top}=(U-XA_{Q}^{\top})M^{\top}-(V-XA_{P}^{\top}).$ 

(147)

Its entries have magnitude at most $\|M\|_{\infty\to\infty}\eta_{Q}+\eta_{P}$ . Apply lemma G.1 with $Y=R$ and $B=(MA_{Q}-A_{P})^{\top}$ ; the column bound and triangle inequality give the bound $\Delta$ on every row. The $1$ -Lipschitz link $\tanh$ gives the prediction bound. With exact records, $R=X(MA_{Q}-A_{P})^{\top}$ , so $X^{\dagger}R=(MA_{Q}-A_{P})^{\top}$ and the second inequality is an equality.
∎

The same records estimate the target matrix. Its smallest singular value measures whether the targets retain every latent direction.

Lemma G.3 (Calibrated Observability).

Define

 $\displaystyle\widehat{A}_{P}$ 
 $\displaystyle\coloneqq(X^{\dagger}V)^{\top},\qquad\tau\coloneqq\frac{\sqrt{n|P|}\eta_{P}}{\sigma},$ 

(148)

 $\displaystyle\widehat{\alpha}_{P}$ 
 $\displaystyle\coloneqq\frac{\operatorname{sech}^{2}(1)}{\sqrt{|P|}}\bigl(\sigma_{\min}(\widehat{A}_{P})-\tau\bigr)_{+}.$ 

(149)

Then $\|\widehat{A}_{P}-A_{P}\|_{2\to 2}\leq\tau$ and

 $d_{P}(f,g)\geq\widehat{\alpha}_{P}d_{\mathcal{U}}(f,g),\qquad f,g\in\mathcal{F}.$ 

(150)

Thus $\widehat{\alpha}_{P}>0$ certifies separation. For exact target records, $\widehat{A}_{P}=A_{P}$ .

Proof.

Apply lemma G.1 with $Y=V$ , $B=A_{P}^{\top}$ and $\eta=\eta_{P}$ . The operator-norm bound gives $\|\widehat{A}_{P}-A_{P}\|_{2\to 2}\leq\tau$ , hence

 $\sigma_{\min}(A_{P})\geq\bigl(\sigma_{\min}(\widehat{A}_{P})-\tau\bigr)_{+}.$ 

(151)

All query rows have norm at most one, so $d_{\mathcal{U}}(f_{x},f_{x^{\prime}})\leq\|x-x^{\prime}\|_{2}$ for unit $x,x^{\prime}$ . The derivative of $\tanh$ on $[-1,1]$ is at least $\operatorname{sech}^{2}(1)$ ; hence

 $\displaystyle d_{P}(f_{x},f_{x^{\prime}})$ 
 $\displaystyle\geq\operatorname{sech}^{2}(1)\|A_{P}(x-x^{\prime})\|_{\infty}$ 

(152)

 $\displaystyle\geq\frac{\operatorname{sech}^{2}(1)\sigma_{\min}(A_{P})}{\sqrt{|P|}}\|x-x^{\prime}\|_{2}\geq\widehat{\alpha}_{P}d_{\mathcal{U}}(f_{x},f_{x^{\prime}}).$ 

This proves equation 150. For exact target records, $V=XA_{P}^{\top}$ gives $\widehat{A}_{P}=A_{P}$ .
∎

When this certificate is positive, the calibrated inverse estimates the latent vector. Normalization returns that estimate to the sphere.

Proposition G.4 (Calibrated Recovery).

Use $\Delta$ , $\widehat{A}_{P}$ and $\tau$ from lemmas G.2 and G.3, and assume $\sigma_{\min}(\widehat{A}_{P})>\tau$ . Let $\nu$ normalize nonzero vectors to the sphere and send zero to the first coordinate vector. Define

 $\displaystyle c(y)$ 
 $\displaystyle\coloneqq\operatorname{arctanh}\!\left(\operatorname{clip}_{[-\tanh(1),\tanh(1)]}(y)\right),$ 

(153)

 $\displaystyle\widehat{x}(y)$ 
 $\displaystyle\coloneqq\nu\!\left(\widehat{A}_{P}^{\dagger}c(y)\right).$ 

(154)

This readout satisfies

 $\sup_{x\in\mathbb{S}^{r-1}}d_{\mathcal{U}}\bigl(f_{\widehat{x}((b\circ e)(f_{x}(Q)))},f_{x}\bigr)\leq\frac{2\bigl(\sqrt{|P|}\Delta+\tau\bigr)}{\sigma_{\min}(\widehat{A}_{P})}.$ 

(155)

Proof.

Fix a unit $x$ and write $y=(b\circ e)(f_{x}(Q))=\tanh(MA_{Q}x)$ . Since $c(y)=\operatorname{clip}_{[-1,1]}(MA_{Q}x)$ and $A_{P}x\in[-1,1]^{|P|}$ , clipping and lemmas G.2 and G.3 give

 $\|c(y)-\widehat{A}_{P}x\|_{2}\leq\|c(y)-A_{P}x\|_{2}+\|(A_{P}-\widehat{A}_{P})x\|_{2}\leq\sqrt{|P|}\Delta+\tau.$ 

(156)

For a unit $x$ , normalization is a nearest-point projection onto the sphere, including at zero. Thus, for every vector $v$ ,

 $\|\nu(v)-x\|_{2}\leq\|\nu(v)-v\|_{2}+\|v-x\|_{2}\leq 2\|v-x\|_{2}.$ 

(157)

Since $\widehat{A}_{P}$ has full column rank and all query rows have norm at most one,

 $d_{\mathcal{U}}(f_{\widehat{x}(y)},f_{x})\leq 2\|\widehat{A}_{P}^{\dagger}c(y)-x\|_{2}\leq\frac{2\|c(y)-\widehat{A}_{P}x\|_{2}}{\sigma_{\min}(\widehat{A}_{P})}\leq\frac{2\bigl(\sqrt{|P|}\Delta+\tau\bigr)}{\sigma_{\min}(\widehat{A}_{P})}.$ 

(158)

Taking the supremum over $x$ proves equation 155.
∎

Computational cost. 
For $n$ sampled observations of $u$ units, forming the maximum-coordinate distance matrix costs $O(n^{2}u)$ time and $O(n^{2})$ memory. Time-shift replicates repeat these operations, with shifts preserving each unit’s empirical marginal. The sample cap and number of controls are fixed in tables 12 and 15.

Training choices. 
The reference architecture and $200$ -epoch endpoint were fixed after preliminary training checks and then shared by every session, target budget, and repetition. The small model reduces depth, width, and learned-token count while retaining the same observation task. These architecture settings are design choices, not quantities selected separately on the final test block. AdamW uses weight decay $10^{-4}$ , moments $(.9,.999)$ , and stabilizer $10^{-8}$ ; gradients are clipped to norm $1$ . Training uses Float32, with TF32 disabled and deterministic PyTorch operations. The loss is the batch mean of the maximum absolute target error. The cosine schedule, chronological split, and fixed final epoch are given in table 18; all remaining initialization and library settings are specified in the archived implementation.

Attention cost. 
Let $q=|Q|$ , $p=|P|$ , $t$ be the learned-token count, and $h$ the hidden width. Per observation and layer, the dense attention and projection operations cost $O((q+p+t)h^{2}+(t^{2}+tq+p^{2}+pt)h)$ time. Materialized attention matrices require $O(t^{2}+tq+p^{2}+pt)$ storage for a fixed number of heads, alongside the token activations. Batch size and layer count multiply these costs; the unit-embedding table adds storage linear in the number of recorded units and $h$ . The tables specify each architecture and the supplied manifests give the session-dependent query counts.

Prediction score. The prediction score averages the maximum absolute target-observation error across test windows. The constant baseline is the coordinatewise training median on the same target set. Relative gain is one minus the ratio of model error to baseline error. We average seed-level gains within each session, then weight sessions equally. Session-to-session spread is descriptive because recordings within an animal share biological variation. Different budgets evaluate different target sets, each with its own matched baseline.

Reference state. The ontic-state surrogate is the large encoder’s complete post-normalization token state, flattened into a reference vector. For each session and seed, the full-target large model is held fixed. Its training objective uses target observations. After predictive training, the reference states determine the recovery maps and their evaluation. Local recovery. For a held-out input, we locate the nearest neighbors of its learned state in the small encoder’s training-state library and average their reference states. Distances use Euclidean coordinates, centered by the training mean and divided by a common training root-mean-square scale. This scalar normalization preserves neighbor order. A neighbor’s weight is proportional to the exponential of its negative squared distance divided by the squared distance of the furthest selected neighbor, with a numerical floor. At test time, these training neighbors and their distance-based weights directly determine the recovered reference state.

Selection and cost. 
The neighborhood grid spans individual neighbors through broader local averages. The count minimizing validation mean squared error is selected separately for the trained and initial representations; ties retain the first count in ascending order. Evaluation uses the fixed final test block. For a library of $n$ training states with $s$ learned coordinates, a batch of $B$ queries requires $O(Bns)$ distance computation. Neighbor selection adds the cost of selecting the smallest $k$ distances per query; averaging reference vectors of dimension $r$ costs $O(Bkr)$ . Batches of $128$ bound the distance workspace to $O(128n)$ entries, in addition to stored learned and reference states. No gradient updates are used to fit this local recovery map.

Recovery score. We score all reference coordinates together using squared reconstruction error divided by the squared error of the training-mean reference state; the reported $R^{2}$ is one minus this ratio. Both conditions use this same baseline. We first average paired seeds within each session and then weight sessions equally. Seeds change the query partition and the independently trained model pair. Animal groups follow recording metadata; recording-name prefixes can differ from animal identities.
