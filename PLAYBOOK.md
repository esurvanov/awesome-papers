# Как сделать ролик по научной статье

**Ядро** репозитория: общий путь от ссылки на статью до готового видео с голосом — так, как он сложился на ролике
про разрыв соотношений (arXiv 2610.23637, октябрь 2026, ~25 замечаний автора). Команды запускаются из корня репозитория.
Прикладное — то, что верно только для конкретной статьи, — лежит в `papers/<папка>/NOTES.md`.

## 🗺 Флоу

```
статья ─► разбор ─► 📘 паспорт ─► 👤 сверка с автором ─► 🎬 сцены ─► 🤖 проверка ─► 🖼 кадры глазами
                                                                                       │
        ✅ ролик ◄─ 👤 просмотр автором ◄─ 🔊 сборка с голосом ◄─ 👤 голос на слух ◄────┘
```

| # | Шаг | Кто | Команда / файл | Выход |

| 2 | 💡 Придумать **один** образ-мир и сюжет в три акта | Claude | — | замысел (выбрать самому, не спрашивать «какую идею») |

## 📜 Законы сценария

Именно их нарушения давали замечания «не выкупить контекст», «не ясно, как всё связано», «почему игра такая».

| # | Закон | Как выглядит | Проверка |
|---|---|---|---|
| 1 | 🎬 **Завязка до терминов** | первые ~20 с: о чём вообще речь (область), вопрос, ставка («50 лет не знали») | 👤 |
| 2 | 🧾 **Карточка статьи** сразу после вступления | название (оригинал + перевод), авторы, дата, суть одной фразой — только словами из вступления | 👤 |
| 3 | 🗺 **Единство места** | один мир-образ на весь ролик; бытовые аналогии-миры (носок, выписка, кубик) **не добавлять** — они множат контексты | 👤 |
| 4 | 🔫 **Ружьё Чехова** | понятие вводится до первого употребления и потом «стреляет»; **зачем объект устроен так** — отдельной сценой «каждая деталь понадобится» | 🤖 |
| 5 | 🔤 **≤ 2 новых понятия на сцену**, слово не переименовывать | одно слово — один смысл во всём ролике | 🤖 |
| 6 | 🔗 **«Но / поэтому» на стыках** | сцена начинается со связки или подхватывает слово из прошлой | 🤖 |
| 7 | 🎭 **Три акта с возвратом** | вопрос и мир → ответ и почему → развязка, где звучит вопрос из начала | 👤 |
| 8 | 📍 **Полоса «мы здесь»** | станции по актам внизу каждого кадра | код (`story_base`) |
| 9 | ⚖️ **Старшинство при конфликте** | математическая правда → нить → единство места → мало понятий → минимум текста | 👤 |

## 📎 Приложение в конце ролика

После развязки — отдельный мир «формально» (вход через переходник «образ → формула»): тот же путь ещё раз, **по карточке на шаг**.

| Элемент карточки | Как |
|---|---|
| слева | тот же значок, что в рассказе (связь двух описаний одного объекта) |
| по центру | элементарная формула: `x^6 = 1`, `r + s = s + r`, `НОД(3, 2) = 1` |
| под ней | пояснение одной строкой |
| внизу | `≈ аналогия` из жизни (повороты на 60°, выписка, монеты в 3 и 2 рубля) |

Дальше: карточка «как это закодировать» (несколько строк в GAP, моноширинный шрифт `Menlo`) и последняя —
«где это встречается»: пометки **прямо** / **аналогия**, честно; общий урок одной плашкой. Затем «кто и когда».
Формальные слова («группа», «соотношение») вводятся только в приложении; в паспорте у приложения и практики —
`FREE_WORLDS` (там разрешены буквы и формулы из запрещённого списка). Справка может цитировать название статьи до объяснения слов.

## 🎨 Визуальные правила

| Правило | Как |
|---|---|
| Образ вместо формул | ходы и объекты — словами («шаг», «лифт», «крюк»); буквенная запись — один раз мелко в справке |
| Один цвет — один смысл | цвета только из паспорта, в коде — смысловые имена (`C_STEP`, `C_BOOK`…), не `C_BLUE` |
| Одна мысль на сцену | если сцена несёт 3–4 мысли — делить |
| Миниатюры с карты | значки понятий — уменьшенные куски того же образа, **со стрелками хода** (петля по кругу, два пути в одну точку, смесь «петля + петля»); не перекрашивать и не заливать дуги — получаются «закорючки» |
| Переходник на смене мира | объект старого мира превращается в объект нового на глазах (`ReplacementTransform`) |
| Подписи | внизу — `note()` над полосой; ничего не налезает; проверять листами кадров |
| Честность образа | в справке: что образ точный, что аналогия; что доказано, что условно |
| Степени | `tx("x^6")` — верхний индекс без LaTeX (LaTeX на машине нет) |

## 🎙 Голос

| Вариант | Качество (оценка автора) | Цена за ролик ~5 тыс. знаков | Нужно |
|---|---|---|---|
| **Silero `xenia`** (по умолчанию) | лучший из бесплатных; женские голоса хорошие, мужские (`aidar`, `eugene`) — плохие | 0 | ничего, считается на Маке |
| OpenAI `gpt-realtime-2.1` / `cedar` | «лучше, но пафосно», потом «гнусаво» — тембр OpenAI в русском | ≈ $0,64 | ключ, баланс, согласие на отправку |
| OpenAI синтезатор `gpt-4o-mini-tts` | хуже живой модели | ≈ $0,12 | то же |
| Яндекс SpeechKit | не пробовали; обучен на русском | ≈ 5–7 ₽ | аккаунт Yandex Cloud, ключ, согласие |
| ElevenLabs | не пробовали; считается самым живым | образцы бесплатно, дальше $5–6/мес | ключ, согласие |
| Милена (macOS `say`) | плохо — только как временная заглушка, и **прямо говорить, что заглушка** | 0 | — |

Подача, которую хочет автор: **по-свойски**, разговорный регистр, узкая мелодика, фразы спокойно вниз, одно лёгкое выделение на фразу,
без пафоса и восклицательной интонации, не высокий голос, ~115–155 слов/мин.

| Ручка | Где | Что делает | Урок |
|---|---|---|---|
| Инструкция голосу | `core/pipeline/voice.py` `VOICE_STYLE` | регистр, мелодика, темп, паузы | работает только у OpenAI |
| Ударения RUAccent | `core/pipeline/voice.py` `stress`, поправки `STRESS_FIX` | знаки ударения и «ё» | OpenAI помогает; **Silero делает роботизированнее** — у Silero выключено |
| Чистка «песка» | `core/pipeline/voice.py` `CLEAN`, `--clean 0…3` | де-эссер шипящих, срез верхов, шумоподавление | шумоподавление даёт металл — по умолчанию 1 (только шипящие) |
| Темп | `--wpm` | ускоряет медленную запись без смены высоты | ×1,4 — «очень быстро»; потолок ×1,3 |
| Высота | `--pitch` | сдвиг в полутонах | «писклявость/гнусавость» тембра не лечит |
| Дословность | `core/pipeline/build.py` `heard_ok` | обратное распознавание, сверка текста | только для OpenAI (обрывает последнюю короткую фразу ~1 раз из 7) |

Термины для разговора о голосе: **регистр** (дикторский ↔ разговорный), **просодия** (мелодика, ударения, паузы),
**интонационные конструкции** Брызгуновой (ИК-1 спокойная ↔ ИК-2/ИК-5 выделительная/восклицательная = «пафос»),
**сибилянты** («шипит» — резкие с/ш/щ/ч, лечит де-эссер), **артефакты вокодера** («фонит», «песок», «металл»),
**тембр** («писклявый», «гнусавый» — не лечится настройками, только сменой голоса).

## 🔊 Сборка (`core/pipeline/build.py`)

Для каждой сцены из `ORDER`: озвучить → (OpenAI: сверить на слух) → привести темп → черновик анимации при `SLOW=1`
(длина запоминается) → чистовик с `SLOW` = длина речи / длина анимации → наложить звук → склеить.

| Флаг | Смысл |
|---|---|
| `--engine silero\|realtime\|speech\|chat\|say` | движок голоса (по умолчанию `silero`) |
| `--voice`, `--model` | голос и модель движка |
| `--clean 0…3`, `--wpm`, `--pitch`, `--stress/--no-stress` | ручки голоса, см. выше |
| `--only A05 A09` | пересобрать только эти сцены |

Кэш: озвучка — `videos/<папка>/audio/` (по хешу текста и настроек голоса), сцены со звуком — `videos/<папка>/voiced/`
(пропускаются, если та же запись и тот же код сцен), длины черновиков — `base_durations.json`.
Правка одной фразы пересобирает одну сцену. Полный ролик ~12 сцен — ~10–20 минут.

## 🧯 Проблемы и решения

| Симптом | Причина | Решение |
|---|---|---|
| «Игра… сколько правил?! О чём это» | вопрос раньше мира, нет завязки | закон 1: область, вопрос, ставка в первые 20 с |
| «Не ясно, как всё связано» | ролик построен от понятий, а не от рассказа; подводки рвут нить | законы 3–7, паспорт, полоса «мы здесь» |
| «Почему игра такая» | детали объекта не мотивированы | сцена «каждая деталь понадобится» + выстрелы в объяснении |
| Множатся контексты | бытовые аналогии и второй мир (фигуры) | всё на одном образе; второй мир — одной строкой в развязке |
| Термины рвутся на стыках | одно слово в двух смыслах («петля», «запись», «счёт», «шаг») | словарь паспорта + проверка |
| Неясно, как связаны два хода | ходы нарисованы отдельными картинками | общая карта, где оба хода видны вместе |
| Голос «стрёмный» по кругу | выбор из одного поставщика по короткой фразе | образцы разных поставщиков, длинный кусок, решает автор |
| Голос OpenAI гнусавый | тембр OpenAI в русском (известная жалоба на форуме) | менять источник голоса, не крутить ручки |
| Silero роботизированный | разметка RUAccent + шумоподавление | без разметки, чистка 1 |
| OpenAI 401 / «баланс исчерпан» | ключ перевыпущен / нет денег | `.env.local`, пополнить; пока — Silero |
| Запрос OpenAI висит | сеть | таймаут + 4 повтора (`_post`) |
| Голос OpenAI оборвал фразу | особенность модели | обратное распознавание и повтор (`heard_ok`) |
| RUAccent падает на предложении | ошибка его модели омографов | по предложениям, сбойное — без разметки |
| «три шага́» | ошибка RUAccent после числительных | `STRESS_FIX` |
| `x⁶` рисуется криво, нет «⁻» | шрифт без надстрочных | `tx("x^6")` → `MarkupText <sup>` |
| `Brace` падает | нужен LaTeX, его нет | рисовать скобку линиями |
| Залитые серым круги | `set_opacity` красит и заливку | приглушать через `op` при построении |
| Подписи налезают | позиции на глаз | листы кадров и правка до сборки |
| Цикл в zsh не делит «файл сцена» | zsh не разбивает переменную | `${=s}` |
| Все кадры из ffmpeg одинаковые | несколько выходов берут один вход | по одной команде на кадр |
| Сборка переозвучила, но не наложила | готовность сцены сверялась по тексту | ключ готовности — хеш самой записи |
| Silero молчит на «OpenAI», «ChatGPT», «GAP» | русский Silero читает только кириллицу, латиницу пропускает | словарь произношений `SAY_LATIN` в `core/pipeline/voice.py`; сборка падает, если латиница осталась |
| Сборщик путал имя `SCENES` | список сцен и путь к файлу под одним именем | путь — `SCENE_FILE` |
| Запись файла «изменён после чтения» | правки скриптом между чтением и записью | перечитать перед записью |
| `cross() missing 2 required positional arguments` | модуль в `manimkit` со `from manimlib import *` переэкспортировал `cross` из manimlib поверх значка | в модулях `manimkit` задавать `__all__` |
| Правка файла сцен ломает идущую сборку | сборщик перечитывает файл сцен на каждой сцене | не править сцены, пока идёт сборка |
| После сбоя сборки «открылся ролик» | открылся старый файл с прошлой сборки | открывать ролик только после строки «Готово» |

## ✅ Чек-лист нового ролика

- [ ] статья прочитана целиком, выкладки ключевого места пересчитаны, роль ИИ и условные места выписаны
- [ ] один образ-мир, сюжет в три акта, вопрос понятен без терминов
- [ ] паспорт и текст диктора, `check_passport.py` — 0 нарушений
- [ ] сценарий (`make_scenario.py`) показан автору **до** отрисовки
- [ ] сцены нарисованы, листы кадров просмотрены, наложений нет
- [ ] голос выбран автором на слух по длинному образцу; согласие на отправку текста внешним сервисам — если не Silero
- [ ] сборка, громкость по всей длине, ролик открыт автору
- [ ] строка в таблице роликов `README.md`; запись в историю — когда автор доволен
