# Как сделать ролик по научной статье

**Ядро** репозитория: общий путь от ссылки на статью до готового видео с голосом — так, как он сложился на ролике
про разрыв соотношений (arXiv 2610.23637, октябрь 2026, ~25 замечаний автора). Команды запускаются из корня репозитория.
Прикладное — то, что верно только для конкретной статьи, — лежит в `papers/<папка>/NOTES.md`.

## 🗺 Флоу

Идём от зрителя и от дешёвых проверок к дорогим: «непонятно» должно ловиться на абзаце текста или раскадровке, а не на готовом ролике.

```
📄 статья ─► 👤 зритель и пересказ ─► 🚂 мир с задачей ─► 📖 словарь «слово → картинка» ─► 🗣 текст вслух
   ─► 👤 сверка с автором ─► 🎙 черновая озвучка ─► 🎞 раскадровка под голос ─► 🧪 новый зритель
   ─► 🎬 сцены по фразам ─► 🔊 сборка ─► 🖥 просмотр в полном размере ─► 👤 автор ─► ✅
```

| # | Шаг | Кто | Команда / файл | Выход |
|---|---|---|---|---|
| 1 | 📄 Прочитать статью целиком, пересчитать ключевые выкладки | Claude | `curl -L arxiv.org/pdf/<id>` → `pdftotext` | что доказано, что условно, роль ИИ |
| 1а | 🔎 Исследование вокруг статьи (STORM) — с согласия автора | программа | `uv run python core/pipeline/research.py papers/<папка>` | контекст, «что было до»; факты сверять со статьёй |
| 1б | 🕰 Статус после статьи: шесть мест поиска | Claude | `STATUS` в паспорте, раздел «Статус после статьи» | у каждого утверждения — ступень, источник, дата |
| 2 | 👤 **Пересказ зрителя — первым**: три фразы, которые зритель скажет другу после ролика | Claude | `RETELL` в паспорте | цель ролика; с ней сверяется всё остальное |
| 3 | 🚂 **Мир с задачей**: кто, что делает и зачем ему худший случай; проба — 20 секунд без единого термина | Claude | `PITCH`, `WORLDS` | вещь из жизни с целью, а не абстракция математики |
| 4 | 📖 **Словарь-договор**: слово → бытовой смысл → какая картинка его показывает; число → как оно видно | Claude | `WORDS` (третье поле), `NUMBERS` | ни одного слова и числа без картинки |
| 5 | 🗺 Сюжет в три акта, обзор — вопросами зрителя, станции со значками | Claude | `SCENES`, `STATIONS`, значки `ICONS` в сценах | значки живут в полосе «мы здесь» во всех сценах |
| 6 | 🗣 **Текст как речь**: проговорить вслух, как другу | Claude | `narration.py` | без канцелярита и обрывков конспекта |
| 6а | 🧹 Признаки ИИ-текста | программа + Claude | `uv run python core/pipeline/humanize.py papers/<папка>` | правки вручную |
| 7 | 📋 Раскадровка: на каждую фразу — что в кадре, **картинкой** (инфографика из элементов мира, без анимации) | Claude | `STORYBOARD` (описание) + `storyboard.py` статьи на `storyboard_base`, `self.snap()` на фразу | схематичный кадр на фразу |
| 8 | 👤 **Сверка паспорта, текста и раскадровки с автором** | автор | `uv run python core/pipeline/make_scenario.py papers/<папка>` | `scenario.md`: фраза → кадр |
| 9 | 🎙 Черновая озвучка | программа | `uv run python core/pipeline/build.py papers/<папка> --voice-only` | записи фраз; время фраз — по паузам (`timing.py`) |
| 10 | 🎞 Раскадровка под голос | программа | `uv run python core/pipeline/animatic.py papers/<папка> --draw` | `videos/<папка>/<папка>_animatic.mp4` — ролик целиком за минуты |
| 11 | 🧪 **Новый зритель** смотрит раскадровку и отвечает: что такое каждое слово, зачем всё это | человек, не знающий темы (модель — с согласия автора) | `VIEWER_TEST` | не понял → переделать текст и кадры (назад к 3–7) |
| 12 | 🎬 Сцены: картинка каждой фразы — после `self.beat(k)`, в конце `self.pad(…)` | Claude | `scenes.py` на `story_base3d` / `story_base` | синхрон по построению |
| 13 | 🤖 Проверка паспорта | программа | `uv run python core/pipeline/check_passport.py papers/<папка>` | 0 нарушений |
| 14 | 🔊 Сборка | программа | `uv run python core/pipeline/build.py papers/<папка>` | `videos/<папка>/<папка>_<движок>.mp4`; растяжка ×2–3 |
| 15 | 🖥 **Просмотр в полном размере**: видео целиком и кадры каждой фразы | Claude | `uv run python core/pipeline/sync_sheet.py papers/<папка>` → `sync/<сцена>/фраза-N.png` | обрезка, смещения, «сказанное видно» |
| 16 | 👤 Просмотр автором | автор | — | замечания → к шагу, где ошибка родилась, а не точечный патч |

**Две разные проверки.** Конечное — есть ли у слова и числа картинка, совпадает ли время, влезает ли в кадр — проверяет программа
(`check_passport`, `timing`, кадры в полном размере). Бесконечное — понятно ли, звучит ли по-человечески, видна ли цель — списком
не закрыть: это новый зритель на раскадровке (шаг 11) и автор (шаги 8, 16).

**Цена ошибки:** пересказ или словарь — минуты; раскадровка — час; готовый ролик — полдня и пересборка.

**Где схема не закрывает:** удачен ли образ (схема отбрасывает плохие, хороший нужно придумать); насколько «нов» зритель (знающий
тему не споткнётся там, где споткнётся настоящий); интересно ли смотреть — только просмотр автором.
Если для статьи нет вещи из жизни (абстрактная математика), мир — игра с правилами или история людей, решавших задачу;
статья о данных — мир прибора и того, что он видит; проба та же — 20 секунд без терминов.

## 📜 Законы сценария

Именно их нарушения давали замечания «не выкупить контекст», «не ясно, как всё связано», «почему игра такая».

| # | Закон | Как выглядит | Проверка |
|---|---|---|---|
| 1 | 🎬 **Завязка до терминов** | первые ~20 с: о чём вообще речь (область), вопрос, ставка («50 лет не знали») | 👤 |
| 2 | 🧾 **Карточка статьи** сразу после вступления | название (оригинал + перевод), авторы, дата, суть одной фразой — только словами из вступления | 👤 |
| 3 | 🗺 **Единство места** | один мир-образ на весь ролик; бытовые аналогии-миры (носок, выписка, кубик) **не добавлять** — они множат контексты | 👤 |
| 4 | 🔫 **Ружьё Чехова** | понятие вводится до первого употребления и потом «стреляет»; **зачем объект устроен так** — отдельной сценой «каждая деталь понадобится» | 🤖 |
| 5 | 🔤 **≤ 2 новых понятия на сцену**, слово не переименовывать | одно слово — один смысл во всём ролике | 🤖 |
| 6 | 🔗 **«Но / поэтому» на стыках** | сцена начинается со связки или подхватывает слово из прошлой | 🤖 |
| 7 | 🎭 **Три акта с возвратом** | вопрос и мир → ответ и почему → развязка, где звучит вопрос из начала | 👤 |
| 8 | 📍 **Полоса «мы здесь»** | станции по актам внизу каждого кадра, над точкой — значок станции (тот же, что в обзоре); полоса целиком в кадре | код (`story_base`, `story_base3d`) |
| 9 | 👁 **Сказанное — видно, и видно честно** | каждое число и утверждение диктора есть в кадре в момент фразы; откуда число — показано (8 уголков × 12 рёбер, а не «43 квинтиллиона» с потолка); схема подписана как схема; числа схемы не выдаются за результат статьи; название, которое зрителю ничего не говорит (Каггл, DeepCubeA), заменяется тем, что оно значит | 👤 + лист сверки |
| 10 | 🎬 **История, а не голые числа** | число — итог маленькой сцены, где что-то происходит: 98 из 100 загораются, две фишки бегут к выходу, счётчик крутится до 4,3·10¹⁹, «перебор с 2025 до 3395 года»; график и таблица — только в приложении. Числа — не больше ~10 % речи | 🤖 ≤ 8 чисел и ≤ 80 слов на сцену (`check_passport`), ⚠ «картинка стоит» при растяжке > ×3 (`build`); интересно ли — 👤 |
| 11 | ⚖️ **Старшинство при конфликте** | математическая правда → понятно зрителю → нить → единство места → мало понятий → минимум текста | 👤 |
| 12 | 🚂 **Мир с задачей** | у образа есть кто-то с целью и худший случай, который ему важен; голая абстракция (шарики на линии) не годится | 👤 + `PITCH` |
| 13 | 📖 **Слово и число — с картинкой** | новое слово звучит в момент, когда его видно; число — с тем, откуда оно и с чем сравнить | 🤖 `WORDS`, `NUMBERS` |
| 14 | 🗺 **Обзор — вопросами зрителя** | остановки обзора — вопросы бытовыми словами, а не ярлыки станций | 👤 |
| 15 | 🎬 **Ролик сам по себе** | о прошлых роликах не говорим: ни «как в прошлом ролике», ни «компас из прошлых роликов»; понятие вводится заново, как будто зритель видит его впервые. Связь со статьями той же команды — только фактом в карточке статьи («та же команда раньше …») | 👤 + 🤖 `check_passport` (везде, включая справку) |
| 16 | 📐 **Кадр без наездов** | всё внутри кадра и выше полосы «мы здесь»; текст не на тексте и не через рамку; отдельные элементы не налезают друг на друга частично (пометки — стрелки, рамки подсветки, рельсы, контуры — можно) | 🤖 `layout_problems` на каждом кадре раскадровки и сцены; раскадровка не собирается, пока есть проблемы |
| 17 | 🔤 **Обзор и полоса — известными словами** | подписи станций и вопросы обзора — только словами, которые зритель знает из завязки; «Ритм», «Журнал» в обзоре — нельзя, «Можно ли посчитать ответ формулой?» — можно | 🤖 `check_passport`: слова паспорта в `STATIONS` и на экране обзора до их введения; исключения — только `REF_EXEMPT` (карточка статьи) |
| 18 | 🚂 **Законы мира — правилами, а не на глаз** (3D) | у мира есть физика: вагон стоит колёсами на головке рельса, едет только по ломаной пути через стрелки, вагоны на одном пути не пересекаются; модель поворачивается вокруг своей середины | 🤖 `station.drive` (только по путям), посадка по колёсам в `station.model`, `station.collisions` перед рендером — с ошибкой не рендерится |
| 19 | 🎙 **Числа в озвучке сверяются отдельно** | каждое число текста должно найтись в распознанной речи; трудные числа (годы) — лучше словами-образами («больше полувека назад»), число — на экране | 🤖 `build.heard_ok` (числа), 👤 слух |
| 20 | 🖼 **Образцовый кадр до массового рендера** | окружение, свет, фон — вкус, списком не закрыть: несколько неподвижных кадров сцены (`--still=`) — автору до рендера анимации | 👤 |
| 21 | 🧵 **Одна идея и сквозные сущности** | у ролика есть общая идея одной фразой (`IDEA`) и 3–6 сквозных сущностей (`ENTITIES`): один и тот же объект на экране от первой сцены до последней, меняется на глазах, а не заменяется новым; каждый стык описан тремя вещами — связка в тексте, что сломалось и что чиним, что в кадре остаётся и что меняется (`LINKS`) | 🤖 `check_passport`: идея есть, сущностей ≥ 3 и их сцены существуют, у каждого стыка запись, связка стыка = начало сцены; 👤 «держит ли это ролик вместе» |
| 22 | 🧱 **Понятно без подготовки** | зритель знает только школьный график; каждый объект при первом появлении получает имя, живой пример на знакомой картинке и подпись «это что»; картинка раньше слова, одно новое понятие за раз; горизонталь, вертикаль и цвет всегда означают одно и то же; сквозные сущности вводятся по одной, с подписью-именем, а не панелью целиком; значок, которого не называет диктор, не показываем; кадр читается без звука за три секунды | 🤖 `check_passport`: слово не звучит раньше введения, ≤ 2 новых на сцену, слова станций известны к первой сцене; 👤 **тест немого кадра**: кадр без звука показывают человеку, не знающему тему, он называет каждый элемент — у такого свойства нет конечного списка признаков |
| 23 | 📅 **История — по датам** | исторические имена и события идут строго по возрастанию дат; отступление — только с явной меткой (плашка с годом, лента времени); имя нового человека — сцена или кадр с датой на экране | 🤖 даты упомянутых людей в тексте и плашках по возрастанию; 👤 понятность отступлений |
| 24 | 🔀 **Переходы: что во что превращается** | превращается (Transform) только однотипное с общей меткой; текст гаснет полностью и появляется заново, без кросс-фейда; сквозные сущности меняются по частям — меняется только та, у которой изменилось значение; рамка-кольцо у вновь введённой сущности запрещена (вместо неё подпись с именем до конца сцены); подпись появляется после завершения превращения; на один смысл — одна панель | 🤖 в `Film.show`: тег `None` ни с чем не совпадает, разнородное не превращается; 👤 «понятно ли, что во что превращается» |
| 25 | 🔢 **Число — рядом и из рисунка** | число стоит под объектом, который измеряет, и считается из того же рисунка (в коде `psum`, `msum`, `lowsum`); число не гаснет между значениями — меняется на месте; значения в конечных нарезках не выдаются за предел | 🤖 числа на экране вычисляются кодом; 👤 привязка |
| 26 | 🧊 **3D — только если третье измерение несёт смысл** | 3D оправдан, если выполнено всё: третья ось несёт смысл (этажи слоёв, ветви дерева), на вопрос кадра отвечает именно поворот камеры, вход и выход плоские (вид спереди совпадает с плоской сценой), подписи читаются при любом ракурсе, нет прозрачности и касающихся граней (тела непрозрачные, зазоры, shading ≤ 0,2). Столбик «с глубиной» — вред. Из 25 сцен ролика про интегралы объёмны три: A12, A13, A24 | 👤 проверка «убери 3D — пропала ли мысль»; 🤖 непрозрачность и зазоры |
| 27 | 🎙 **Чтение вслух по спецификации** | ударение каждой формы слова — по орфоэпической норме (реестр форм `core/lang/stress_registry.tsv` + реестр ролика, закон 32); на конце повествовательной фразы тон падает (ИК-1), подъём — только в вопросе; паузы внутри фразы короткие, между фразами длиннее; годы и числа читаются словами по норме (порядковое числительное, склоняется последнее слово); буквы-обозначения («А и Б») вслух не читаем | 🤖 `speech_check.py` (подъём на конце > 1,5 пт = брак, пересинтез), `heard_ok`; 👤 слух по списку трудных слов |
| 28 | 📝 **Текст на слух** | разные связки (не больше ~60% сцен начинаются со связки), имена людей — на экране, в речи не больше трёх на фразу; формулы вслух не читаем; двоеточие в тексте диктора не ставим (на слух его нет); цепочки родительных и причастные обороты разбиваем; 1–2 новых понятия на сцену | 🤖 чек-лист риторики (длина фразы ≤ 20 слов, доля начал с одной связки); 👤 слух |
| 29 | 🎯 **Названное = нарисованное** | каждое слово-якорь фразы указывает на объект в кадре; если рисуется образ, а не сам предмет (полоска вместо треугольника), рядом подпись-связка и пунктир, а в речи — фраза-мост; крупный план — увеличенный кусок той же картинки, а не отдельный рисунок | 🤖 кадров = фраз (STORYBOARD); 👤 смысл связки |
| 30 | ⏱ **Точный синхрон** | кадр фразы начинается за 0,15 с до её первого слова (окно −0,2…+0,5 с); анимации идут в своём темпе, растяжки нет; движение — на словах о движении; конец анимации совпадает с началом следующего кадра (без скачков); имена плавности manimlib не затенять | 🤖 SYNC = "abs", журнал опозданий в frame_check/*.json (> 0,5 с — ошибка) |
| 31 | 🖼 **Кадр** | текст не на цветной заливке (иначе тёмная плашка), контраст ≥ 4,5:1; размерные стрелки на выносных пунктирах и не пересекают данные; слои по типу: заливка → столбики → ось → график → точки → подписи; две панели связаны общей точкой, пунктиром и цветом; числа стоят у того, что измеряют, и считаются из рисунка; без сквозных значков, которых диктор не называет | 🤖 layout_problems после каждого кадра сцены; 👤 вкус |
| 32 | 🔤 **Ударения по реестру** | каждая форма слова текста есть в реестре (stress_registry.tsv) с двумя источниками; омографы — с выбором по контексту; без записи в реестре озвучка не стартует | 🤖 text_check.py; 👤 слух |
| 33 | 🗣 **Текст для голоса** | экранный текст орфографический, голосу — фонетическая запись трудных мест («што́бы», «щита́ли», «коне́шно»); опасные стыки («так считали») переписываются; указание голосу: ровный регистр, громкость и темп на всю фразу, ИК-1 на конце | 🤖 voice.for_voice, speech_check.py |
| 34 | 🗨 **Обыденный язык** | реестр лексики (lexicon.tsv): запрещённые книжные слова с заменами, термины — не раньше своей сцены; глагол вместо отглагольного существительного, короткое слово вместо длинного | 🤖 text_check.py |
| 35 | 🌉 **Мостики** | на каждом стыке частей и сцен — фраза-мост в речи и общий объект в кадре, который остаётся и меняется; сцена начинается с последнего кадра предыдущей | 🤖 LINKS со связкой = начало сцены; 👤 удачность |

## 📎 Приложение в конце ролика

После развязки — отдельный мир «формально» (вход через переходник «образ → формула»): тот же путь ещё раз, **по карточке на шаг**.

| Элемент карточки | Как |
|---|---|
| слева | тот же значок, что в рассказе (связь двух описаний одного объекта) |
| по центру | элементарная формула: `x^6 = 1`, `r + s = s + r`, `НОД(3, 2) = 1` |
| под ней | пояснение одной строкой |
| внизу | `≈ аналогия` из жизни (повороты на 60°, выписка, монеты в 3 и 2 рубля) |

Дальше: карточка «как это закодировать» (несколько строк в GAP, моноширинный шрифт `Menlo`) и последняя —
«где это встречается»: пометки **прямо** / **аналогия**, честно; общий урок одной плашкой. Затем «кто и когда».
Формальные слова («группа», «соотношение») вводятся только в приложении; в паспорте у приложения и практики —
`FREE_WORLDS` (там разрешены буквы и формулы из запрещённого списка). Справка может цитировать название статьи до объяснения слов.

## 🎨 Визуальные правила

| Правило | Как |
|---|---|
| Образ вместо формул | ходы и объекты — словами («шаг», «лифт», «крюк»); буквенная запись — один раз мелко в справке |
| Один цвет — один смысл | цвета только из паспорта, в коде — смысловые имена (`C_STEP`, `C_BOOK`…), не `C_BLUE` |
| Одна мысль на сцену | если сцена несёт 3–4 мысли — делить |
| Миниатюры с карты | значки понятий — уменьшенные куски того же образа, **со стрелками хода** (петля по кругу, два пути в одну точку, смесь «петля + петля»); не перекрашивать и не заливать дуги — получаются «закорючки» |
| Переходник на смене мира | объект старого мира превращается в объект нового на глазах (`ReplacementTransform`) |
| Подписи | внизу — `note()` над полосой; ничего не налезает; проверять листами кадров |
| Честность образа | в справке: что образ точный, что аналогия; что доказано, что условно |
| Степени | `tx("x^6")` — верхний индекс без LaTeX (LaTeX на машине нет) |
| 🧊 3D-сцены — по умолчанию для рассказа (замечание 38) | класс на `ThreeDScene` с тем же темпом (`SLOW`) и полосой «мы здесь» `fix_in_frame()` (пример — `Base3D` в `papers/2502.13266-rubik/scenes.py`); подписи — `fix_in_frame()`; смена подписи — сначала убрать старую, потом показать новую |
| 🔀 Стык 3D → 2D | 3D-сцена заканчивается камерой сверху (`reorient(0, 0)`, исходная высота кадра) и плоскими объектами в тех же координатах, что в 2D-сценах дальше — склейка не видна |
| ✍️ Рисунок от руки | `BOARD = {"A03": ("СлойСцены", ["слово", …])}` в `narration.py`: слой — сцена, где по порядку добавлены только части рисунка; каждая рисуется Animator под своё слово диктора поверх тёмной сцены (`core/pipeline/board.py` `hand_overlay`). Animator рисует часть ≤ 1,6 с — дробить на части под слова |
| 🧹 Текст без «привкуса ИИ» | `core/pipeline/humanize.py --llm` → `humanize.md`; модель перестраховывается — правки отбирать вручную |

Подача, которую хочет автор: **по-свойски**, разговорный регистр, узкая мелодика, фразы спокойно вниз, одно лёгкое выделение на фразу,
без пафоса и восклицательной интонации, не высокий голос, ~115–155 слов/мин.

### 🧱 Указание голосу — блоки (`core/pipeline/voice.py` `VOICE_PARTS`)

| Блок | Что задаёт | Почему так (замечание автора) |
|---|---|---|
| `voice` | носитель, московское произношение | — |
| `register` | уверенный рассказчик научпопа, без пафоса | «пафосно» → «по-свойски» → «мягкость на уровне предложения» |
| `rhythm` | ударные слоги упругие, безударные с редукцией | «акценты чётче ставить в волне речи» |
| `phrase` | куски по 3–6 слов, один акцент на ключевом слове | то же |
| `tempo` | ~130 слов/мин | — |
| `delivery` | собранно, без улыбки и придыхания | «нет объёма», «мягкость» |
| `consonants` | твёрдые согласные твёрдо | «звуки твёрже, без смягчения» |
| `stress` | по знакам ударения в тексте | «ударения правильно» |
| `intonation`, `intonation_en` | ИК-1, конец фразы вниз; дубль по-английски | «голос идёт вверх в конце» |

Под другой ролик или манеру — заменить блок, не переписывая остальное: `VOICE_OVERRIDE = {"tempo": "Темп: …"}` в `narration.py`
статьи (пустая строка убирает блок). Сборщик и доска берут указание через `voice.voice_style(**VOICE_OVERRIDE)`.
⚠️ Замер 21.10.2026: подъём тона в конце фразы у 24–35 % фраз при любых формулировках — интонацию модель указаниями почти не держит;
следующий шаг, если мешает, — выправлять высоту после озвучки или голос с разметкой интонации (Яндекс SpeechKit).

| Ручка | Где | Что делает | Урок |
|---|---|---|---|
| Инструкция голосу | `core/pipeline/voice.py` `VOICE_STYLE` | регистр, мелодика, темп, паузы | работает только у OpenAI |
| Ударения RUAccent | `core/pipeline/voice.py` `stress`, поправки `STRESS_FIX` | знаки ударения и «ё» | OpenAI помогает; **Silero делает роботизированнее** — у Silero выключено |
| Чистка «песка» | `core/pipeline/voice.py` `CLEAN`, `--clean 0…3` | де-эссер шипящих, срез верхов, шумоподавление | шумоподавление даёт металл — по умолчанию 1 (только шипящие) |
| Темп | `--wpm` | ускоряет медленную запись без смены высоты | ×1,4 — «очень быстро»; потолок ×1,3 |
| Высота | `--pitch` | сдвиг в полутонах | «писклявость/гнусавость» тембра не лечит |
| Дословность | `core/pipeline/build.py` `heard_ok` | обратное распознавание, сверка текста | только для OpenAI (обрывает последнюю короткую фразу ~1 раз из 7) |

Термины для разговора о голосе: **регистр** (дикторский ↔ разговорный), **просодия** (мелодика, ударения, паузы),
**интонационные конструкции** Брызгуновой (ИК-1 спокойная ↔ ИК-2/ИК-5 выделительная/восклицательная = «пафос»),
**сибилянты** («шипит» — резкие с/ш/щ/ч, лечит де-эссер), **артефакты вокодера** («фонит», «песок», «металл»),
**тембр** («писклявый», «гнусавый» — не лечится настройками, только сменой голоса).

## 🔊 Сборка (`core/pipeline/build.py`)

Для каждой сцены из `ORDER`: озвучить → (OpenAI: сверить на слух) → привести темп → черновик анимации при `SLOW=1`
(длина запоминается) → чистовик с `SLOW` = длина речи / длина анимации → наложить звук → склеить.

| Флаг | Смысл |
|---|---|
| `--engine silero\|realtime\|speech\|chat\|say` | движок голоса (по умолчанию `silero`) |
| `--voice`, `--model` | голос и модель движка |
| `--clean 0…3`, `--wpm`, `--pitch`, `--stress/--no-stress` | ручки голоса, см. выше |
| `--only A05 A09` | пересобрать только эти сцены |

Кэш: озвучка — `videos/<папка>/audio/` (по хешу текста и настроек голоса), сцены со звуком — `videos/<папка>/voiced/`
(пропускаются, если та же запись и тот же код сцен), длины черновиков — `base_durations.json`.
Правка одной фразы пересобирает одну сцену. Полный ролик ~12 сцен — ~10–20 минут.

## 🧯 Проблемы и решения

| Симптом | Причина | Решение |
|---|---|---|
| «Игра… сколько правил?! О чём это» | вопрос раньше мира, нет завязки | закон 1: область, вопрос, ставка в первые 20 с |
| «Не ясно, как всё связано» | ролик построен от понятий, а не от рассказа; подводки рвут нить | законы 3–7, паспорт, полоса «мы здесь» |
| «Почему игра такая» | детали объекта не мотивированы | сцена «каждая деталь понадобится» + выстрелы в объяснении |
| Множатся контексты | бытовые аналогии и второй мир (фигуры) | всё на одном образе; второй мир — одной строкой в развязке |
| Термины рвутся на стыках | одно слово в двух смыслах («петля», «запись», «счёт», «шаг») | словарь паспорта + проверка |
| Неясно, как связаны два хода | ходы нарисованы отдельными картинками | общая карта, где оба хода видны вместе |
| Голос «стрёмный» по кругу | выбор из одного поставщика по короткой фразе | образцы разных поставщиков, длинный кусок, решает автор |
| Голос OpenAI гнусавый | тембр OpenAI в русском (известная жалоба на форуме) | менять источник голоса, не крутить ручки |
| Silero роботизированный | разметка RUAccent + шумоподавление | без разметки, чистка 1 |
| OpenAI 401 / «баланс исчерпан» | ключ перевыпущен / нет денег | `.env.local`, пополнить; пока — Silero |
| Запрос OpenAI висит | сеть | таймаут + 4 повтора (`_post`) |
| Голос OpenAI оборвал фразу | особенность модели | обратное распознавание и повтор (`heard_ok`) |
| RUAccent падает на предложении | ошибка его модели омографов | по предложениям, сбойное — без разметки |
| «три шага́» | ошибка RUAccent после числительных | `STRESS_FIX` |
| `x⁶` рисуется криво, нет «⁻» | шрифт без надстрочных | `tx("x^6")` → `MarkupText <sup>` |
| `Brace` падает | нужен LaTeX, его нет | рисовать скобку линиями |
| Залитые серым круги | `set_opacity` красит и заливку | приглушать через `op` при построении |
| Подписи налезают | позиции на глаз | листы кадров и правка до сборки |
| Цикл в zsh не делит «файл сцена» | zsh не разбивает переменную | `${=s}` |
| Все кадры из ffmpeg одинаковые | несколько выходов берут один вход | по одной команде на кадр |
| Сборка переозвучила, но не наложила | готовность сцены сверялась по тексту | ключ готовности — хеш самой записи |
| Silero молчит на «OpenAI», «ChatGPT», «GAP» | русский Silero читает только кириллицу, латиницу пропускает | словарь произношений `SAY_LATIN` в `core/pipeline/voice.py`; сборка падает, если латиница осталась |
| Сборщик путал имя `SCENES` | список сцен и путь к файлу под одним именем | путь — `SCENE_FILE` |
| Запись файла «изменён после чтения» | правки скриптом между чтением и записью | перечитать перед записью |
| `cross() missing 2 required positional arguments` | модуль в `manimkit` со `from manimlib import *` переэкспортировал `cross` из manimlib поверх значка | в модулях `manimkit` задавать `__all__` |
| Правка файла сцен ломает идущую сборку | сборщик перечитывает файл сцен на каждой сцене | не править сцены, пока идёт сборка |
| Весь текст белый, хотя в `tx()` задан цвет | `Text(..., color=…)` в этой версии ManimGL молча игнорирует цвет | `tx()` красит через `.set_color()` (исправлено 21.10.2026 на ролике про кубики; ролик про разрыв соотношений собран ещё с белым текстом) |
| «Голос трижды прочитал фразу не так» на сцене с числами | распознавание пишет числа цифрами, имена — латиницей, сходство с текстом падает | сверка без числительных с обеих сторон + подсказка распознаванию «числа словами, имена как в тексте» (`build.py` `heard_ok`) |
| Рука рисует весь кадр сразу | камера ManimGL (`self.frame`) попадала в выгрузку объектов как область во весь кадр | камера исключена в `story_base.tear_down` |
| Проверка паспорта ловит латиницу в описании 3D-сцены | многострочное описание класса не совпадало с `ast.get_docstring` (тот чистит отступы) | описание берётся как есть (`check_passport.py`) |
| На Маке итог затёр исходник | `demo3d.mp4` и `Demo3D.mp4` — один файл | имена итогов не совпадают с именами сцен без учёта регистра |
| После сбоя сборки «открылся ролик» | открылся старый файл с прошлой сборки | открывать ролик только после строки «Готово» |
| «Картинка стоит» в приложении и справке второй ролик подряд | число движений в сцене задано заранее, а длина фразы — нет; проверка ловила это только после озвучки | `beat(scene, k)` перед картинкой фразы k — ждёт точку «доля текста до фразы × длина готовой озвучки / 2,4»; `pad` в конце добирает движения до конца речи. Фраза и её кадр совпадают по построению (пример — `papers/2509.19162-growth/scenes.py`; перенести в `core/manimkit`) |
